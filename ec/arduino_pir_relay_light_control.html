📖 系統導論與控制規格

在智慧走廊、樓梯間與玄關節能照明中，最具實用價值的控制模式為「感應即時點亮、離場非阻塞延遲熄滅」。本專案使用 Arduino 微控制器，結合被動式紅外線人體感測器（PIR Sensor）與電磁繼電器模組（Relay Module），達成安全可靠的自動照明。

📌 接線與控制需求定義

  • 感測器輸入 (Pin 7)：連接 HC-SR501 PIR 感測器輸出腳位。偵測到人體移動時輸出高電位（HIGH），離開無活動時輸出低電位（LOW）。
  • 繼電器輸出 (Pin 8)：連接繼電器模組信號端（IN），內部接通電燈火線回路。
  • 5 秒延遲關燈：當人離開感應範圍（Pin 7 降為 LOW）時，電燈維持常亮並啟動 5 秒倒數；5 秒期間若無人再次進入，則關閉電燈。
  • 防頻繁跳脫（防閃爍）機制：倒數 5 秒期間若有人再度走動，系統立即重置計時並維持點亮，徹底避免電燈開開關關造成的視覺不適與繼電器接點損耗。

🔬 一、核心概念剖析 (Core Concepts)

1.1 被動式紅外線感測器 (PIR) 與維恩位移定律

人體或溫血動物正常體溫為 $36^\circ\text{C} \sim 37^\circ\text{C}$（約 $310.15\text{ K}$）。依據黑體輻射的維恩位移定律 (Wien's Displacement Law)：

$$\lambda_{max} = \frac{b}{T} \approx \frac{2.8977 \times 10^{-3}\text{ m}\cdot\text{K}}{310\text{ K}} \approx 9.35\,\mu\text{m}$$

人體釋放的熱能峰值落在 $9 \sim 10\,\mu\text{m}$ 的紅外線光譜。HC-SR501 模組利用外層白色半球形的菲涅耳透鏡 (Fresnel Lens) 將空間劃分成數十個明暗交錯的敏感區與盲區，並由內部的雙熱釋電晶片（Pyroelectric Detector）進行差動放大。唯有目標在空間中發生位置位移，破壞熱平衡時才會觸發信號輸出，避免了環境整體均勻升溫造成的誤報。

1.2 電磁繼電器驅動、光耦隔離與反馳反電動勢

微控制器 ATmega328P 輸出腳位額定電流僅約 20mA，無法直接驅動需要 70~100mA 的繼電器電磁線圈，更不可直接接觸 AC 110V/220V 市電。

標準繼電器模組採用 PC817 光電耦合器，控制端（DC 5V）與輸出負載（AC 110V）在實體電氣上達到了完全的電氣隔離 (Galvanic Isolation)。此外，針對線圈斷電瞬間釋放的巨大感應反電動勢：

$$V_{back} = -L \frac{di}{dt}$$

模組並聯了反馳續流二極體 (Flyback Diode)，為電感逆向放電提供封閉迴路，防止數百伏特之突波脈衝擊穿驅動電晶體。

1.3 微控制器非阻塞時序控制 (Non-blocking millis)

初學者常誤用 delay(5000)。但在延遲期間 CPU 會徹底凍結，無法響應任何感測器信號；若有人在第 2 秒折返，燈光依然會在第 5 秒強制熄滅！

採用 millis() 的狀態機輪詢架構：

$$\Delta t = (t_{current} - t_{lastMotion}) \ge 5000\text{ ms}$$

即使微控制器運行 49.7 天後 unsigned long 產生溢位歸零，依據 C/C++ 無符號模運算（Modulo $2^{32}$）特性，差值運算依然精準無誤，系統具備極高的工業級穩定度。

2.2 完整 Arduino 生產級程式碼 (非阻塞式狀態機)

/**
 * ============================================================================
 * 專案名稱: Arduino PIR 人體感測與繼電器延遲照明控制系統
 * 腳位配置:
 *   - Pin 7 : PIR 紅外線感測器 (HC-SR501 OUT)
 *   - Pin 8 : 繼電器模組信號輸入端 (Relay IN)
 *   - Pin 13: 內建狀態指示燈 (與電燈開關同步)
 * 控制邏輯:
 *   - 感應到人體移動 -> 燈開，重置計時
 *   - 人離開後 -> 維持亮燈，開始 5 秒倒數
 *   - 倒數期間若有人再次進入 -> 重置計時維持常亮
 *   - 5 秒倒數結束且無人 -> 關閉繼電器熄滅電燈
 * ============================================================================
 */

// --------------------------- 硬體腳位常數定義 ---------------------------
const uint8_t PIR_PIN   = 7;    // 紅外線感測器輸入腳位
const uint8_t RELAY_PIN = 8;    // 繼電器控制輸出腳位
const uint8_t LED_PIN   = 13;   // 板載指示燈 (方便無接繼電器時觀察)

// --------------------------- 繼電器電平設定 ---------------------------
// 提示: 市售繼電器模組多為「低電平觸發」(Active LOW) 或「高電平觸發」(Active HIGH)
const uint8_t RELAY_ON  = LOW;  // 大多數光耦模組 LOW 為吸合導通 (若為高電平觸發請改 HIGH)
const uint8_t RELAY_OFF = HIGH; // 斷開關閉 (若為高電平觸發請改 LOW)

// --------------------------- 系統延遲常數 ---------------------------
const unsigned long OFF_DELAY_TIME = 5000UL; // 離開後延遲關閉時間: 5000 毫秒 (5 秒)

// --------------------------- 狀態變數 ---------------------------
bool lightState = false;                     // 目前電燈/繼電器狀態 (true=開燈, false=關燈)
unsigned long lastMotionTime = 0;            // 最後一次感應到人體的時間戳記 (millis)
int lastPirReading = LOW;                    // 前一次感測器讀值 (用於偵測邊緣變化)

void setup() {
    Serial.begin(115200);
    while (!Serial) { ; }

    Serial.println(F("=================================================="));
    Serial.println(F("⚡ Arduino PIR 紅外線感應繼電器電燈控制系統啟動 ⚡"));
    Serial.println(F("延遲關閉時間設定: 5 秒 (5000ms)"));
    Serial.println(F("=================================================="));

    pinMode(PIR_PIN, INPUT);
    pinMode(RELAY_PIN, OUTPUT);
    pinMode(LED_PIN, OUTPUT);

    // 初始狀態：預設關閉繼電器與指示燈
    digitalWrite(RELAY_PIN, RELAY_OFF);
    digitalWrite(LED_PIN, LOW);
    lightState = false;

    Serial.println(F("📌 注意: PIR 感測器開機可能需要約 10~30 秒進行環境校準..."));
}

void loop() {
    unsigned long currentMillis = millis();
    int pirValue = digitalRead(PIR_PIN);

    // 狀態變化偵測輸出
    if (pirValue != lastPirReading) {
        if (pirValue == HIGH) {
            Serial.println(F("[感應事件] 🚨 偵測到人體移動！"));
        } else {
            Serial.println(F("[感應事件] 🍃 人已離開感測範圍，啟動 5 秒倒數計時..."));
        }
        lastPirReading = pirValue;
    }

    // 核心開關與計時邏輯
    if (pirValue == HIGH) {
        // --- 情況 A: 感應範圍內有人 ---
        lastMotionTime = currentMillis; // 持續刷新活動時間戳記

        if (!lightState) {
            digitalWrite(RELAY_PIN, RELAY_ON);
            digitalWrite(LED_PIN, HIGH);
            lightState = true;
            Serial.println(F("[電源控制] 💡 電燈已點亮 (繼電器閉合)"));
        }
    } else {
        // --- 情況 B: 感測器無人 (LOW) ---
        if (lightState) {
            unsigned long elapsedTime = currentMillis - lastMotionTime;

            if (elapsedTime >= OFF_DELAY_TIME) {
                // 超過 5 秒，正式關燈
                digitalWrite(RELAY_PIN, RELAY_OFF);
                digitalWrite(LED_PIN, LOW);
                lightState = false;
                Serial.println(F("[電源控制] 🌑 延遲 5 秒已滿，電燈熄滅 (繼電器斷開)"));
            } else {
                // 倒數狀態印出 (每秒印出一次剩餘秒數)
                static unsigned long lastLogTime = 0;
                if (currentMillis - lastLogTime >= 1000) {
                    lastLogTime = currentMillis;
                    unsigned long remaining = (OFF_DELAY_TIME - elapsedTime + 999) / 1000;
                    Serial.print(F("[倒數計時] 關燈倒數中... 剩餘: "));
                    Serial.print(remaining);
                    Serial.println(F(" 秒"));
                }
            }
        }
    }

    delay(10); // 微休 10ms，防止緊密空轉並具備軟體消抖作用
}

🚀 三、延伸思考與進階主題 (Extensions & Advanced Topics)

3.1 CDS 光敏電阻晝夜判斷節能設計

白天採光充足時開燈會造成電力浪費。可透過 HC-SR501 板載 CDS 接孔或外接光敏電阻模組於 A0：

int ambientLight = analogRead(A0); // 數值小於 400 代表環境昏暗
if (pirValue == HIGH && ambientLight < 400) {
    // 唯有「有人」且「天黑」時才開燈，白天完全不亮
}

3.2 RC 突波吸收迴路 (Snubber Circuit) 保護繼電器

當繼電器切斷交流電燈瞬間，觸點會產生高壓拉弧。在繼電器 NO 與 COM 端並聯一組 $0.1\,\mu\text{F}$ 400V 薄膜電容與 $100\,\Omega$ 1W 電阻，能有效消除火花，將繼電器使用壽命延長 5 倍以上。
