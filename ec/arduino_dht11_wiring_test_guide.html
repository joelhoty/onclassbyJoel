1.1 DHT11 模組 3-Pin 接線對照表

DHT11 引腳標示 訊號定義 Arduino Uno 對應腳位 照片導線顏色 功能說明

🔬 二、DHT11 單線式 (Single-Bus) 通訊協定時序剖析

DHT11 採用專屬的單線雙向協定，微控制器與感測器之間完全仰賴精準的微秒（μs）脈衝電位交握：

sequenceDiagram autonumber participant Arduino as Arduino Uno (Pin 7) participant DHT as DHT11 感測器 Note over Arduino,DHT: 匯流排平時由上拉電阻拉至 HIGH Arduino->>DHT: 主機拉低電位 (LOW) 至少 18ms (發送起始訊號) Arduino->>DHT: 主機釋放匯流排拉高 (HIGH) 20~40μs 等待響應 DHT->>Arduino: 感測器響應：拉低 80μs (Response LOW) DHT->>Arduino: 感測器準備：拉高 80μs (Response HIGH) Note over DHT,Arduino: 感測器連續輸出 40-Bit (5 Bytes) 數據 DHT-->>Arduino: 傳送 16-bit 濕度 (整數 + 小數) DHT-->>Arduino: 傳送 16-bit 溫度 (整數 + 小數) DHT-->>Arduino: 傳送 8-bit 校驗和 (Checksum) Note over Arduino,DHT: 傳輸完畢，感測器釋放匯流排恢復為 HIGH

2.1 40-Bit 封包結構與校驗公式

  • Byte 0：相對濕度整數部分（如 41%）
  • Byte 1：相對濕度小數部分（DHT11 為 0）
  • Byte 2：攝氏溫度整數部分（如 27°C）
  • Byte 3：攝氏溫度小數部分（如 9）
  • Byte 4：校驗和（$\text{Checksum} = (\text{Byte 0} + \text{Byte 1} + \text{Byte 2} + \text{Byte 3}) \ \& \ \text{0xFF}$）

3.2 課堂實測原始碼 (`DHT_Unified_Sensor.ino`)

// 檔案路徑: D:\CLASS_NOTE\ec\arduino_dht11_unified_test.ino
#include <Adafruit_Sensor.h>
#include <DHT.h>
#include <DHT_U.h>

// 定義 DHT11 訊號腳連接至 Arduino 數位腳 7
#define DHTPIN 7     

// 選擇感測器型號
#define DHTTYPE DHT11

DHT_Unified dht(DHTPIN, DHTTYPE);

uint32_t delayMS;

void setup() {
  Serial.begin(9600);
  while (!Serial);

  Serial.println(F("DHT11 Unified Sensor 測試啟動"));

  // 初始化 DHT 感測器
  dht.begin();

  // 取得感測器硬體規格與建議最小取樣間隔
  sensor_t sensor;
  dht.temperature().getSensor(&sensor);
  dht.humidity().getSensor(&sensor);
  
  // 設定採樣間隔 (DHT11 至少間隔 1 秒)
  delayMS = sensor.min_delay / 1000;
  if (delayMS < 1000) delayMS = 1000;
}

void loop() {
  // 保持物理採樣週期
  delay(delayMS);

  // 讀取溫度事件
  sensors_event_t event;
  dht.temperature().getEvent(&event);
  if (isnan(event.temperature)) {
    Serial.println(F("✖ 溫度讀取失敗！"));
  } else {
    Serial.print(F("Temperature: "));
    Serial.print(event.temperature, 2);
    Serial.println(F("°C"));
  }

  // 讀取相對濕度事件
  dht.humidity().getEvent(&event);
  if (isnan(event.relative_humidity)) {
    Serial.println(F("✖ 濕度讀取失敗！"));
  } else {
    Serial.print(F("Humidity: "));
    Serial.print(event.relative_humidity, 2);
    Serial.println(F("%"));
  }
}

採樣週期物理限制提醒： DHT11 的內部電阻式感濕元件與熱敏電阻需要時間恢復熱平衡，最小採樣頻率為 1 次 / 秒 (1 Hz)。不可在 loop 中使用過短的延遲（如 delay(50)），否則會因自體發熱導致測量值失準或直接回傳 NaN 錯誤。
