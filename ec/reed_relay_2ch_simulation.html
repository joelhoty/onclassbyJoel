🧲 1. 通電螺線管線圈電磁場生成與安培右手定則 (Energized Solenoid Field Simulator)

所有電磁繼電器運作的根本物理起點，在於電流所伴隨的電磁效應（畢奧-沙伐定律與安培定律）。當電流流經密繞螺旋銅導線時，各匝線圈所建立的微觀環形磁場在螺線管軸向疊加，形成均勻強大的軸向磁場，進而磁化內部的導磁介質（如坡莫合金簧片）。

📐 1. 畢奧-沙伐定律與螺線管軸向磁場

單匝環形導線在軸心產生的磁場為 $dB = \frac{\mu_0 I R^2}{2(R^2+z^2)^{3/2}}$。將長度為 $L$、總匝數為 $N$ 的螺線管沿軸向積分，內部中心處磁通密度為：

$$B = \mu_0 \mu_r \frac{N}{L} I = \mu_0 \mu_r n I$$

其中 $\mu_0 = 4\pi \times 10^{-7}\ \text{T}\cdot\text{m/A}$ 為真空磁導率，$n = N/L$ 為單位長度線圈匝數密度。

✋ 2. 安培右手定則 (右手螺旋定則)

定則口訣：以右手四指彎曲指向導線中電流 $I$ 的流動方向（從正極流向負極），此時大拇指所指向的一端即為螺線管內部的磁力線方向，亦即螺線管對外表現的 N 極 (北極)！

🔹 電流反向：四指反向彎曲，大拇指指向反轉，N/S 極立即對調！
🧲 3. 導磁芯介質與磁化增強效應

在線圈內部放入高導磁率軟磁材料（如坡莫合金 Permalloy，$\mu_r \approx 5000\sim 100000$），金屬內部無序排列的磁疇（Magnetic Domains）會在外部線圈磁場下瞬間同向轉動，使總磁通密度 $B$ 猛增數千倍！

這正是為什麼磁簧開關只需要微弱的線圈電流（$10\sim 20\text{ mA}$），就能產生足夠強大的磁吸引力閉合金屬接點。

💡 5. 雙通道模擬動畫深度解構與觀察指南 (2-Channel Simulation Breakdown)

2 路磁簧繼電器動態模擬器整合了多層次的電磁學、微機電物理運動與即時儀表響應。在進行互動測試時，推薦重點觀察以下 6 大物理現象與工程指標：

🌀 1. 激磁安匝數 (AT) 與磁力線密度動態

調節電壓滑桿時，線圈電流按歐姆定律 $I = V / R_{\text{coil}}$ 變化。安匝數 $AT = N \times I$ 是驅動磁化的根本力量。在 SVG 動畫中，藍/綠色磁力線的發光不透明度 (Opacity) 與流動速度會隨 $AT$ 線性增強，視覺化呈現玻璃管內部空間磁通密度 $B$ 的增長過程。

📐 2. 非線性突跳位移 (Snap Action)

緩慢拖動電壓滑桿（如 0V 升至 3.5V），會發現接點間隙僅緩慢微幅縮小；然而一旦達到 Pull-in 臨界門檻 (4.0V / 20 AT)，磁吸力 $F_m \propto 1/x^2$ 的非線性陡增徹底壓倒彈簧線性恢復力 $F_k \propto x$，簧片瞬間以微秒級速度吸合 (Snap Action)，接點間隙自 $0.25\text{ mm}$ 驟降為 $0\text{ mm}$！

⚡ 3. 示波器視圖：微秒級接觸彈跳 (Contact Bounce)

點擊開關導通通道 1 時，觀察下方示波器畫布的藍色負載電壓波形 ($V_{\text{contact}}$)：在躍升至 24V 的瞬間，會出現 $2\sim 3$ 次微小毛邊震盪（持續約 $100\sim 200\ \mu\text{s}$）。這精確再現了簧片高速撞擊時金屬彈性碰撞的接觸彈跳現象。

🔄 4. 磁滯曲線 (Hysteresis Loop) 動態軌跡追蹤

觀察右側磁滯曲線畫布上的即時藍色動態指示點：
• 升壓過程：指示點沿著下方 OFF 基準線向右移動，直到穿越 $20\text{ AT}$ (Pull-in) 垂直躍升至 ON 頂部。
• 降壓過程：指示點在頂部向左折返，穿越 $20\text{ AT}$ 時依然保持導通，直到降至 $9\text{ AT}$ (Drop-out) 才會向下跳回 OFF！

🛡️ 5. 雙通道防磁串擾屏蔽 (Magnetic Shielding)

在雙通道獨立模式下，將通道 1 電壓開至最大 (12V / 48 AT)，通道 2 依然能保持穩定的 OFF 狀態。這是因為模組內部各通道均包裹了高導磁率坡莫合金磁屏蔽罩 (Permalloy Shield)，將絕大部分漏磁通束縛在各自通道內，避免相鄰線圈相互誤觸發。

💡 6. 雙通道負載差異化表現

• 通道 1 (功率控制)：導通時右下方黃色高亮 LED 劇烈發光，模擬 $24\text{V} / 20\text{mA}$ 指示燈負載。
• 通道 2 (微弱類比訊號)：導通時藍色精密儀表指示燈點亮，接觸電阻降至 $45\text{ m}\Omega$，展現磁簧繼電器在精密量測與音訊無損切換中的超低接觸熱電勢優勢。

🔬 6. 磁簧繼電器核心概念與工作原理 (Core Concepts)

6.1 什麼是磁簧開關與磁簧繼電器？

磁簧開關 (Reed Switch) 是由 W. B. Ellwood 於 1936 年在貝爾實驗室發明的純被動磁控機械開關。將磁簧開關置於電磁線圈 (Coil) 中心，利用線圈通電產生的電磁場控制接點閉合與斷開，即構成了磁簧繼電器 (Reed Relay)。

🧪 內部微觀結構材料科學
  • 簧片基體：採用 52 鐵鎳合金 (Permalloy 52: 52% Ni, 48% Fe)，兼具高導磁率（極易被磁化）與優異的彈簧機械剛性。
  • 接點鍍層：在簧片重疊接觸區真空電鍍 銠 (Rhodium, Rh)、釕 (Ruthenium, Ru) 或 金 (Gold, Au)，提供極高的抗電弧燒蝕硬度與低至 $30\sim 50\text{ m}\Omega$ 的接觸電阻。
  • 密封環境：管內充填 高純度乾燥氮氣 (97% N₂) 與氦氣 (3% He) 或抽至高真空 ($10^{-5}\text{ Torr}$)，徹底隔絕外部氧氣、濕氣、硫化物對接點的氧化侵蝕。
⚡ 電氣與切換優勢特徵
  • 極致切換速度：簧片質量極輕（數毫克），動作時間僅需 $0.2 \sim 1.0\text{ ms}$，比傳統電磁繼電器 (EMR, $5\sim 15\text{ ms}$) 快 10~50 倍。
  • 超長機械壽命：在低電平訊號 (Cold Switching) 下壽命可達 $10^8 \sim 10^9$ 次 (十億次)。
  • 極致絕緣與低漏電：斷開時接點間絕緣阻抗高達 $> 10^{12}\ \Omega\ (1\text{ T}\Omega)$，漏電流 $< 1\text{ pA}$，寄生電容 $< 0.5\text{ pF}$。

📐 7. 電磁吸合與安匝數 (AT) 數學模型 (Mathematical Model)

磁簧繼電器的吸合與釋放由電磁吸力 (Magnetic Pull Force) 與簧片懸臂梁機械恢復力 (Mechanical Restoring Force) 之間的動態力平衡決定：

🧲 1. 電磁吸力模型 (Maxwell Magnetic Force)

根據馬克士威應力張量，接點間隙處由磁場產生的垂直吸力 $F_m$ 為：

$$F_m = \frac{\Phi^2}{2\mu_0 A} = \frac{B^2 A}{2\mu_0} = \frac{\mu_0 A (N I)^2}{2 (2 x + l_m / \mu_r)^2} \propto \frac{(N I)^2}{x^2}$$

其中 $\Phi$ 為穿過接點的磁通量，$A$ 為接點重疊截面積，$NI$ 為安匝數，$x$ 為接點當時間隙。吸力與間隙平方成反比，這導致了強烈的正回授加速吸合特性。

📏 2. 懸臂梁機械彈簧恢復力

簧片可視為一端固定、一端受力的彈性懸臂梁，其恢復力 $F_k$ 與位移 $\Delta x$ 呈線性關係（虎克定律）：

$$F_k = k \cdot \Delta x = \left( \frac{E \cdot w \cdot t^3}{4 L^3} \right) \cdot (x_0 - x)$$

其中 $E$ 為材料楊氏模數（Permalloy $\approx 150\text{ GPa}$），$w, t, L$ 分別為簧片寬度、厚度與長度，$x_0$ 為初始靜態間隙 ($0.8\text{ mm}$)。

🔌 8. 2路硬體驅動電路與微控制器實作 (Circuit & Firmware)

微控制器 (如 Arduino, ESP32, STM32) 的 GPIO 輸出電流一般為 $5\sim 20\text{ mA}$，且電磁線圈在切斷瞬間會產生數十伏特至上百伏特的反向感應電動勢 ($V = -L \frac{di}{dt}$)。因此，模組必須配置專用的開關電晶體與續流二極體 (Flyback Diode)： 

// ==============================================================================
// ⚡ 2路磁簧繼電器 (2-Channel Reed Relay) Arduino / ESP32 雙通道控制範例
// ==============================================================================
const int REED_CH1_PIN = 4;   // 控制通道 1 (GPIO 4 -> Q1 NPN Base / Gate)
const int REED_CH2_PIN = 5;   // 控制通道 2 (GPIO 5 -> Q2 NPN Base / Gate)

void setup() {
  Serial.begin(115200);
  pinMode(REED_CH1_PIN, OUTPUT);
  pinMode(REED_CH2_PIN, OUTPUT);
  
  digitalWrite(REED_CH1_PIN, LOW);
  digitalWrite(REED_CH2_PIN, LOW);
  Serial.println("2-Channel Reed Relay Module Initialized.");
}

void loop() {
  // 模式 1: 通道 1 導通 (24V 負載工作)，通道 2 隔離
  Serial.println("[CH1 ON] Activating Channel 1 (Power Load)...");
  digitalWrite(REED_CH1_PIN, HIGH);
  digitalWrite(REED_CH2_PIN, LOW);
  delay(1000);

  // 模式 2: 通道 2 導通 (微弱音訊訊號切換)，通道 1 斷開
  Serial.println("[CH2 ON] Activating Channel 2 (Sensor Signal)...");
  digitalWrite(REED_CH1_PIN, LOW);
  digitalWrite(REED_CH2_PIN, HIGH);
  delay(1000);
}

📊 9. 繼電器三劍客 (Reed Relay vs EMR vs SSR) 設計架構與工作原理深度對比

在現代電子工程中，磁簧繼電器 (Reed Relay)、傳統電磁繼電器 (EMR, Electromechanical Relay) 與固態繼電器 (SSR, Solid-State Relay) 各自具備截然不同的物理設計與適用場景：

評比維度 / 指標 🧲 磁簧繼電器 (Reed Relay) ⚙️ 傳統電磁繼電器 (EMR) 💡 固態繼電器 (SSR)
核心切換機制 真空玻殼內軟磁金屬簧片自感應吸合 外部線圈吸引活動銜鐵帶動機械接點桿 光電耦合 (Optocoupler) 驅動半導體 (MOSFET/Triac)
