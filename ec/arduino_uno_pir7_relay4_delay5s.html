在自動化感應開關與智慧節能系統中，本設計實現經典的「**人來燈亮、人走延遲 5 秒自動熄滅**」控制模式。使用 Arduino Uno 作為核心控制器，透過 Pin 7 讀取 PIR 人體紅外線感應器信號，透過 Pin 4 輸出控制信號驅動電磁繼電器模組。

繼電器 NC ➔ NO 切換的核心物理意義：
電磁繼電器具有一個共同端（COM）、一個常閉端（NC）以及一個常開端（NO）。
  • 未感應/待機時（Pin 4 = LOW）：線圈不激磁，接點靠彈簧拉向 NC（Normally Closed）。負載接於 COM 與 NO 之間，此時為開路，負載電燈關閉。
  • 感應到移動時（Pin 4 = HIGH）：線圈通電產生磁力吸合銜鐵，接點由 NC 切換至 NO（Normally Open）。COM 與 NO 導通形成迴路，負載電燈點亮。
  • 人走延遲 5 秒後（Pin 4 = LOW）：線圈斷電去磁，接點由 NO 切換回 NC，COM 與 NO 斷開，電燈熄滅。

🔬 一、核心概念剖析 (Core Concepts)

1.1 被動紅外人體感測器 (PIR) 的物理機制

人體或溫血動物的正常體溫約為 \(36^\circ\text{C} \sim 37^\circ\text{C}\)（約 \(310\text{ K}\)）。依據維恩位移定律 (Wien's Displacement Law)：

$$\lambda_{\max} = \frac{b}{T} \approx \frac{2.898 \times 10^{-3}\,\text{m}\cdot\text{K}}{310\,\text{K}} \approx 9.35\,\mu\text{m}$$

人體輻射熱能量峰值集中於長波紅外線（LWIR，約 \(8 \sim 14\,\mu\text{m}\)）區間。PIR 感測器核心由菲涅耳透鏡 (Fresnel Lens)、雙差動熱釋電晶體 (Pyroelectric Element) 與 BISS0001 專用訊號處理晶片構成：

  • 雙差動抗干擾設計：感測晶片內部將兩組熱釋電薄膜反向串聯。當全域環境氣溫均勻受熱時，兩者產生的皮安（pA）級電荷相互抵消；唯有目標移動依序穿越兩區域時，才會產生動態交變電壓脈衝。
  • 菲涅耳透鏡同心圓聚光：將空間劃分為交錯的「敏感感應區」與「盲區」，使人員步行時不斷產生光強突變，倍增偵測距離（達 3~7 公尺）。
  • H 模式（可重複觸發，推薦）：將感測板上的跳線帽插在 H 檔。當人員持續在感應範圍內晃動時，OUT 信號持續維持 HIGH，直到人員完全停止或離開才開始計算硬體保持時間。

1.2 繼電器接點邏輯：為何由 NC 切換至 NO？

繼電器（Relay）本質為微型電磁機械開關：

  • COM (Common 共同端)：動接點，為電源電流輸入端。
  • NC (Normally Closed 常閉端)：線圈未通電時，內部彈簧拉住接點，保持 COM-NC 閉合導通。
  • NO (Normally Open 常開端)：線圈通電產生磁力時，銜鐵被吸合克服彈簧拉力，使接點脫離 NC 並切換至 NO，造成 COM-NO 閉合導通。
  • 失效安全原則 (Fail-Safe)：若將燈具接於 NC，在 Arduino 故障或斷電時電燈將持續點亮無法關閉；而將燈具接於 COM 與 NO，系統當機或斷電時會自動彈回 NC，確保負載斷電關閉，符合工業自動化安全設計規範。

2.2 工業級標準非阻塞式程式碼 (推薦實務採用)

採用 millis() 時間戳記非阻塞架構，主迴圈完全不被卡死，具備動態刷新與中途回跳防閃爍機制：

/**
 * @file arduino_uno_pir7_relay4_delay5s.ino
 * @brief Arduino Uno PIR 感應器 (Pin 7) 控制繼電器 (Pin 4) 延遲 5 秒系統
 * @details 當 Pin 7 感應到移動時，Pin 4 輸出 HIGH 使繼電器切換至 NO (常開導通)；
 *          人體離開後非阻塞延遲 5 秒關閉 (切換回 NC)。
 */

// ================= 引腳定義 =================
const int PIR_PIN   = 7; // 連接 PIR 紅外線人體感測器信號輸出 (OUT)
const int RELAY_PIN = 4; // 連接 繼電器模組控制輸入端 (IN)

// ================= 時間參數設定 =================
const unsigned long OFF_DELAY_TIME = 5000; // 人員離開後的延遲關閉時間 (毫秒，5000ms = 5秒)

// ================= 系統全域變數 =================
unsigned long lastMotionTime = 0; // 記錄最後一次偵測到人體動態的時間戳記 (毫秒)
bool relayActive = false;         // 記錄當前繼電器狀態 (true: 切換至 NO 導通 / false: 釋放回 NC 斷開)
int lastPirState = LOW;           // 記錄前一次 PIR 讀取狀態，用於狀態變更提示

void setup() {
    // 啟用序列埠通訊，鮑率 9600，方便電腦即時監控與除錯
    Serial.begin(9600);
    Serial.println(F("=================================================="));
    Serial.println(F("💡 Arduino Uno PIR (Pin 7) + 繼電器 (Pin 4) 控制系統啟動"));
    Serial.println(F("=================================================="));

    // 設定引腳模式
    pinMode(PIR_PIN, INPUT);    // Pin 7 設定為數位輸入 (接收 PIR 訊號)
    pinMode(RELAY_PIN, OUTPUT); // Pin 4 設定為數位輸出 (控制繼電器線圈)

    // 初始狀態配置：繼電器預設關閉 (LOW)，保持在常閉端 (NC) 狀態，負載斷電
    digitalWrite(RELAY_PIN, LOW);
    relayActive = false;

    Serial.println(F("[系統狀態] 系統就緒！繼電器初始狀態：NC (Pin 4 = LOW, 負載關閉)"));
    Serial.println(F("[工程提示] PIR 模組上電後通常需 30~60 秒預熱穩定期，期間若有短暫誤觸發屬正常現象。"));
}

void loop() {
    unsigned long currentMillis = millis(); // 取得自開機以來的當前毫秒數
    int pirValue = digitalRead(PIR_PIN);   // 讀取 Pin 7 的紅外線感測狀態 (HIGH 或 LOW)

    // ----------- 1. 偵測狀態變化事件輸出至 Serial Monitor -----------
    if (pirValue != lastPirState) {
        if (pirValue == HIGH) {
            Serial.println(F("\n[事件通知] 🚨 Pin 7 偵測到人體移動！準備切換繼電器至 NO..."));
        } else {
            Serial.println(F("\n[事件通知] 🍃 Pin 7 信號降為 LOW (人員離開)，啟動 5 秒離去延遲計時..."));
        }
        lastPirState = pirValue;
    }

    // ----------- 2. 核心時序控制邏輯 -----------
    if (pirValue == HIGH) {
        // 【狀況 A：感應到移動】
        lastMotionTime = currentMillis; // 持續刷新最後動態時間基準

        if (!relayActive) {
            // 原本處於 NC 狀態 ──► 激磁吸合切換至 NO 端
            digitalWrite(RELAY_PIN, HIGH);
            relayActive = true;
            Serial.println(F("[動作執行] ⚡ Pin 4 輸出 HIGH ➔ 繼電器吸合切換至 NO (常開導通) ➔ 💡 負載電燈開啟！"));
        }
    } else {
        // 【狀況 B：無人 (Pin 7 = LOW)】
        if (relayActive) {
            // 目前繼電器仍維持在 NO 導通狀態，計算無人經過的經過時間
            unsigned long elapsedTime = currentMillis - lastMotionTime;

            if (elapsedTime >= OFF_DELAY_TIME) {
                // 已超過設定的 5 秒延遲 ──► 釋放繼電器切換回 NC 端
                digitalWrite(RELAY_PIN, LOW);
                relayActive = false;
                Serial.println(F("[動作執行] ⏰ 延遲 5 秒已滿！Pin 4 輸出 LOW ➔ 繼電器切回 NC ➔ 🌑 負載電燈關閉！"));
            } else {
                // 尚在 5 秒倒數中，每隔 1 秒印出倒數提醒
                static unsigned long lastCountLog = 0;
                if (currentMillis - lastCountLog >= 1000) {
                    lastCountLog = currentMillis;
                    unsigned long remainingSeconds = (OFF_DELAY_TIME - elapsedTime + 999) / 1000;
                    Serial.print(F("[倒數計時中] 距離關閉還剩: "));
                    Serial.print(remainingSeconds);
                    Serial.println(F(" 秒..."));
                }
            }
        }
    }

    // 微幅延遲 20 毫秒，降低微控制器 CPU 輪詢負載 (每秒輪詢約 50 次)
    delay(20);
}

2.3 簡易版程式碼 (適合新手快速體驗)

若僅用於初學課堂演示與功能快速驗證，可採用直觀之條件判斷寫法：

/**
 * @file arduino_uno_pir7_relay4_simple.ino
 * @brief 簡易版 PIR (Pin 7) 控制繼電器 (Pin 4) 延遲 5 秒程式
 * @note 使用 delay() 實作，程式碼直觀，但在 5 秒延遲期間無法中斷接收新的動態訊號。
 */

void setup() {
    pinMode(7, INPUT);  // Pin 7 連接 PIR 感測器輸出
    pinMode(4, OUTPUT); // Pin 4 連接 繼電器 IN 控制端
    digitalWrite(4, LOW); // 預設處於 NC 狀態 (關閉)
}

void loop() {
    // 讀取 Pin 7
    if (digitalRead(7) == HIGH) {
        digitalWrite(4, HIGH); // 偵測到人體移動：切換至 NO (開啟負載)
    } else {
        delay(5000);           // 無人時暫停等待 5 秒 (阻塞式)
        digitalWrite(4, LOW);  // 5 秒結束後：切換回 NC (關閉負載)
    }
}

⚡ 三、延伸思考與進階工程主題 (Extensions & Safety)

3.1 非阻塞式 (millis()) vs 阻塞式 (delay()) 深度比較

比較維度 簡易版 (delay(5000)) 工業非阻塞版 (millis())
CPU 運行狀態 程式在 delay(5000) 時被完全卡死，暫停任何輪詢 CPU 維持高速循環（每 20ms 一圈），隨時可回應新事件
人體中途折返 若人在第 2 秒折返，感測不到訊號，燈光仍會在第 5 秒強行熄滅 約 20ms 內即時捕捉到 Pin 7 變 HIGH，立即重設倒數並維持常亮
多工擴充能力 極差，無法同時讀取其他感測器或進行通訊 極佳，可輕鬆擴充光敏電阻 CDS、溫濕度計或 Wi-Fi/MQTT

3.2 繼電器線圈保護：Back-EMF 與續流二極體 (Flyback Diode)

繼電器線圈具有電感特性。當 Pin 4 控制端瞬間轉為 LOW 斷電時，線圈產生極高反向感應電壓（\(V = -L \frac{di}{dt}\)），可高達上百伏特，足以擊穿微控制器 GPIO 或驅動三極管：

⚠️
硬體工程注意事項：
商用繼電器模組通常在 PCB 上已並聯 1N4007 / 1N4148 續流二極體 與 NPN 電晶體。若自行在麵包板搭接單顆繼電器，務必於線圈兩端反向並聯續流二極體，且不可直接用 Pin 4 推動線圈（單片機腳位最大僅 20mA，線圈需約 70~90mA）。

3.3 負載接點火花防護：RC 吸收迴路 (Snubber Network)

當繼電器接點（COM 與 NO）用於開關市電交流 110V/220V 的日光燈、風扇或 LED 驅動器時：

  • 湧浪電流 (Inrush Current)：LED 電源供應器前端濾波電容充電瞬間會產生高達數十安培的湧浪電流，易造成接點金屬熔焊黏死（Contact Welding）。
  • 斷開電弧 (Arcing)：電感性負載斷開瞬間會在接點氣隙跳火，導致表面氧化燒蝕。
  • 對策：在繼電器 COM 與 NO 接點兩端並聯一組 RC 突波吸收迴路（0.1μF 400V 薄膜電容 + 100Ω 電阻） 或 壓敏電阻 (MOV)，能有效吸收火花並倍增繼電器壽命。
