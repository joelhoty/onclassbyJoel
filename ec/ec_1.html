1 元件基礎與規格參數 (Specifications)

💡 為什麼 LED 必須串聯限流電阻？

發光二極體 (LED) 具備指數型伏安特性 (I-V Curve)。當外加順向偏壓超過導通門檻 VF 後，電壓只要微幅增加 0.1V，通過的電流便會成倍暴增。若直接跨接於固定電壓源，電流將失控暴增、過熱燒毀。限流電阻的作用即在於吸收多餘電壓並穩定工作電流。

2 基本單燈電路設計（基準：3V 電源 + 紅色 LED）

[單顆 LED 基礎電路] V+ (3.0V 電源) ──── [ 限流電阻 R ] ──── (陽極 A) 紅色 LED (陰極 K) ──── GND (負極) │ VF ≈ 2.0V
核心設計公式（歐姆定律）
R = (V電源 - VF) / IF
分壓分配：VR = 3.0V - 2.0V = 1.0V，由電阻承擔剩餘的 1.0V 電壓。

⚡ 功率瓦數檢查 (Power Rating)

以 10mA、分壓 1.0V 計算：
P = VR × IF = 1.0V × 0.01A = 0.01W (10 mW)
市面上最常見的 1/4W (0.25W = 250mW) 或 1/8W (125mW) 碳膜電阻負載率僅 4%~8%，發熱極微，安全耐久。

🔋 電池供電內阻特性

• 2 顆乾電池 (AA/AAA 串聯, ~3V)：內阻極小 (<1Ω)，嚴格依照 100 Ω 設計。
• CR2032 鈕扣鋰電池 (3V)：自身內阻較大（約 10~30Ω），會分擔部分電壓，接 100Ω 依然可亮，若嫌偏暗可降為 47Ω~68Ω。

3 串聯拓撲與 3V 電源限制 (Series Connection)

⚠️ 核心工程盲點：為什麼 3V 電源無法直接串聯 2 顆紅色 LED？

• 串聯總順向導通電壓：
兩顆紅色 LED 串聯，總壓降為 VLED_總 = VF1 + VF2 = 2.0V + 2.0V = 4.0V（即使以極限低壓 1.8V 估計，亦需 3.6V）。
• 電壓不足困境：
若電源維持原本的 3.0V，因 3.0V < 3.6V ~ 4.0V，電源電壓小於 LED 導通電位障壁，兩顆 LED 完全無法點亮！

串聯解決方案：提高電源電壓至 5.0V（USB 5V 或 4 顆電池 6V）

升壓串聯
[2 顆 LED 串聯架構 (5V 供電)] V+ (5.0V) ──── [ 限流電阻 R ] ──── (A) LED 1 (K) ──── (A) LED 2 (K) ──── GND │ │ VF1 = 2.0V VF2 = 2.0V
  1. 確認已知參數： VCC = 5.0V，VF_total = 4.0V，目標電流 IF = 10 mA = 0.01 A。
  2. 計算電阻分壓 (KVL)： VR = 5.0V - 4.0V = 1.0V。
  3. 歐姆定律阻值： R = 1.0V / 0.01A = 100 Ω（E24 標準阻值：100 Ω，棕黑棕金）。
  4. 電阻功耗： PR = 1.0V × 0.01A = 10 mW（選用 1/4W 碳膜電阻極度安全）。

4 LED 並聯專題討論與電路設計 (Parallel Connection)

💡 為什麼「並聯 (Parallel)」是 3V 電源驅動多顆 LED 的唯一解答？

在並聯電路中，所有支路跨接相同電源電壓 (VCC = 3.0V)。由於單顆紅色 LED 導通電壓僅 2.0V，只要 VCC > VF (3.0V > 2.0V)，無論並聯 2 顆、3 顆甚至 10 顆 LED，每條支路都能獲得足夠電壓順利導通！

⚠️ 嚴肅警示：共用單一限流電阻的「熱失控 (Thermal Runaway)」陷阱

初學者常試圖將兩顆 LED 直接並聯，然後只串聯「一顆」50Ω 電阻。這在電子工程中屬於嚴重失誤！

[❌ 錯誤並聯做法 - 共用單一電阻 (高風險熱失控)] ┌─── (A) LED 1 (K) ───┐ V+ (3V) ── [ 50Ω 共用電阻 ] ──┼ ├─── GND └─── (A) LED 2 (K) ───┘
  • 製程微小壓降公差：即便同型號 LED，導通電壓 VF 仍有微小差異（如 LED1 = 1.95V, LED2 = 2.05V）。
  • 指數型搶電流：由於二極體 I-V 特性呈指數陡升，VF 較低的 LED 1 會搶走 80% 以上電流，造成兩顆亮度嚴重不均。
  • 負溫度係數惡性循環：LED 1 因電流大而發熱，其 VF 隨溫度升高進一步降低 (約 -2mV/°C)，進一步吸收更多電流，最終過熱擊穿燒毀！LED 1 燒毀開路後，全部電流改流經 LED 2（本例共用 50Ω 時約 20 mA，已達額定上限；若電阻更小或並聯更多顆，就可能連鎖燒毀）！

✅ 工程標準做法：獨立限流電阻並聯架構 (Independent Branch Resistors)

工程黃金法則：「每條 LED 支路必須擁有自己專屬的限流電阻」。

[✅ 正確工程並聯架構 (3.0V 電源推動 2 顆或 N 顆 LED)] ┌──── [ R1: 100Ω ] ──── (A) LED 1 (K) ────┐ ├──── [ R2: 100Ω ] ──── (A) LED 2 (K) ────┤ V+ (3.0V) ─────┼──── [ R3: 100Ω ] ──── (A) LED 3 (K) ────┼───── GND │ │ └──── [ Rn: 100Ω ] ──── (A) LED n (K) ────┘
📐 獨立並聯計算公式與範例（3V 電源推動 3 顆紅色 LED）：
  • 每支路電阻計算： R1 = R2 = R3 = (3.0V - 2.0V) / 0.01A = 100 Ω（市售 100Ω，色碼：棕黑棕金）。
  • 每支路電流 (Ibranch)： 保持為獨立的 10 mA，亮度完全均勻一致。
  • 電源總輸出電流 (Itotal)： 根據克希荷夫電流定律 (KCL)：
    Itotal = IF1 + IF2 + IF3 = 10mA + 10mA + 10mA = 30 mA (0.03A)
  • 電源總功耗 (Ptotal)： Ptotal = VCC × Itotal = 3.0V × 0.03A = 90 mW (0.09W)。
  • 電池續航試算： 以 2 顆 AA 乾電池 (容量約 2000 mAh) 供電：
    續航時間 ≈ 2000 mAh / 30 mA ≈ 66.7 小時。

📌 串聯現象總結（Series Key Takeaways）

• 好處： 節省總電流（只需 10mA），能效極高，且兩顆電流絕對相等，亮度百分百一致。
• 代價： 電壓需求高（2 × 2.0V = 4.0V），在 3V 電源下必定熄滅。

📌 正確並聯現象總結（Parallel Key Takeaways）

• 好處： 3.0V 低壓即可完美點亮兩顆，且獨立支路互不干擾，一顆壞掉另一顆依然正常工作。
• 代價： 電源總電流倍增為 20mA（耗電翻倍），且需使用 2 顆獨立電阻。

🌟 工程點評與優缺點總結

👍 優秀設計亮點
  1. 完全符合黃金規範：兩顆 LED 各自擁有獨立限流電阻，避免熱失控與搶電流。
  2. 接線清晰規範：極性 (長腳陽極 / 短腳陰極) 插接正確，跳線分佈合理。
  3. 模組化擴充性高：若要增加第 3 顆 LED，只需在空餘列重複相同配線即可。
💡 進一步優化建議
  1. 若覺亮度偏低，可將阻值由 1 kΩ 降至 390Ω 或 470Ω。
  2. 麵包板電源軌建議加上標籤或使用不同顏色 jumper 區分正負極。
