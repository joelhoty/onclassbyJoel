⚖️ 電磁機械繼電器 (EMR) vs 磁簧繼電器 (Reed Relay) 深度對比

評估項目 電磁機械繼電器 (EMR) 磁簧繼電器 (Reed Relay)
機械結構 線圈、外露鐵芯、擺動銜鐵、拉簧與分立接點 充填惰性氣體密封玻璃管＋雙金屬鐵鎳合金彈性簧片
切換反應速度 較慢（約 5 ms ~ 20 ms），受較重銜鐵慣性限制 極快（約 0.2 ms ~ 1.0 ms），簧片質量極輕
接點彈跳 (Bounce) 彈跳時間顯著（約 1 ms ~ 5 ms），需防突波設計 微秒級極小彈跳（< 0.5 ms），訊號失真極低
耐候與防爆特性 接點易受空氣中濕度氧化、硫化，通斷電弧有粉塵風險 完全氣密（Hermetically Sealed），耐腐蝕、防爆、耐震動
驅動功耗 較大（約 200 mW ~ 600 mW，需三極管推動） 極低（約 10 mW ~ 50 mW，許多微控制器可直接驅動）
最大負載容量 極高（可達 10A ~ 30A，250VAC，適合動力機械） 較小（通常 < 1A ~ 2A，30VDC，主要用於精密訊號量測）

🤖 Arduino 微控制器自動化繼電器控制與程式深度解析

微控制器（如 Arduino Uno）可以藉由程式輸出精準的毫秒級邏輯電位，達成完全自動化的負載排程切換：

圖 2：Tinkercad 平台上的 Arduino Uno 控制 5V 繼電器雙色燈自動化切換系統

1. 系統接線架構說明

  • 控制訊號端 (Arduino)：
    • Pin 13（板載 LED_BUILTIN）連接至繼電器線圈正極輸入端（綠線）。
    • GND 連接至繼電器線圈接地負極端（綠線），構成單晶片低壓控制迴路。
  • 外部受控負載端 (麵包板 + 直流電源)：
    • 直流穩壓電源設定為 5.00 V，負載輸出顯示為 12.7 mA。
    • 電源正極接至繼電器 COM (Common) 共用端。
    • 繼電器 NC (常閉端) 串接電阻至紅色 LED；NO (常開端) 串接電阻至綠色 LED。

2. Arduino C++ 原始程式碼清單與逐行解析

// C++ code - Arduino Uno 繼電器自動週期切換

void setup()
{
  // 設定數位腳位 13 (LED_BUILTIN) 為輸出模式 (OUTPUT)
  pinMode(LED_BUILTIN, OUTPUT);
}

void loop()
{
  // 【階段一：線圈通電激磁】輸出 5V 高電位，繼電器吸合至 NO
  digitalWrite(LED_BUILTIN, HIGH);
  
  // 維持通電狀態 3000 毫秒 (3 秒) ➔ 綠燈亮、紅燈滅
  delay(3000); 

  // 【階段二：線圈釋放斷電】輸出 0V 低電位，繼電器彈簧拉回 NC
  digitalWrite(LED_BUILTIN, LOW);
  
  // 維持斷電狀態 1000 毫秒 (1 秒) ➔ 紅燈亮、綠燈滅
  delay(1000); 
}

Phase 2 1.0 秒 LOW (0V) 斷電釋放 彈簧拉回 NC 🔴 點亮 (ON) 🟢 熄滅 (OFF) 12.7 mA 系統待機中 (STOP)

🛡️ 工程級硬體防護：單晶片驅動繼電器的標準規範

⚠️ 為什麼真實硬體絕對不能用 Arduino Pin 直接連接繼電器線圈？

  1. GPIO 腳位電流超載 (Overcurrent)：ATmega328P 每個引腳安全電流上限為 20 mA，而 5V 繼電器線圈電阻約 70Ω，工作電流高達 71.4 mA，直接驅動會造成引腳過熱燒熔。
  2. 反向電動勢高壓突波 (Back-EMF Kickback)：線圈為電感負載，在斷電瞬間依 V = -L(di/dt) 若以電晶體驅動且無續流二極體，集極端會出現高達 數十至上百伏特 的反向脈衝；由腳位直驅時，反向感應電流則會強迫流經 MCU 內部 ESD 防護二極體，反覆承受可能損毀腳位。

設計要素重點：

  • 三極管 (2N2222 / S8050)：作為低側開關 (Low-side Switch)，MCU 只需微弱的 1mA 基極電流，即能安全推動 70mA 的線圈電流。
  • 飛輪二極體 (1N4007 / 1N4148)：反向並聯在線圈兩端。斷電瞬間，感應突波經二極體順向導通吸收，將線圈反向電壓箝位在約 0.7V（集極電壓不超過 VCC + 0.7V）。
