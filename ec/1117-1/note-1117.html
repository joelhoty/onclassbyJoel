1. 系統整體架構與硬體接線圖

本系統以 NodeMCU-32S (ESP32) 為控制核心，透過單匯流排讀取 DHT22 溫溼度感測器、使用 12-bit ADC1 讀取 SEN0159 (MG-811) 二氧化碳感測器，並同時將環境數據與 DHCP 取得的 IP 顯示於 SSD1306 128x64 OLED。在網頁端更採用前後端分離之 AJAX 無刷新架構（GET / + GET /data），支援每 2 秒即時同步數據、數值變動黃色脈衝高亮提示，以及零外部 CDN 依賴的原生 HTML5 Canvas 雙 Y 軸動態歷史折線圖。

2. 各個元件的工作原理

2.1 DHT22 電容式溼度與熱敏電阻測溫原理

DHT22 (AM2302) 內部由高分子電容式感溼元件與NTC 熱敏電阻組成，並內建一顆 8-bit 微控制器負責將類比電容/電阻值轉換為數位訊號。

  • 單匯流排協定 (Single-Wire)：MCU 發出起始低電位脈衝後，DHT22 連續輸出 40 bits 資料（16-bit 溼度 + 16-bit 溫度 + 8-bit Checksum）。
  • Adafruit Unified Sensor 架構：程式中透過 dht.temperature().getEvent(&event) 與 dht.humidity().getEvent(&event) 取得標準化的 sensors_event_t 結構。

2.2 SSD1306 OLED 與 U8g2 圖形庫

SSD1306 控制晶片內建 128 × 64 bits 的 GDDRAM，分為 8 個 Page（每個 Page 高 8 pixels）。

  • U8G2_SSD1306_128X64_NONAME_1_HW_I2C：建構子中的 _1_ 表示使用 1 Page Buffer (128 Bytes)，由 firstPage() / nextPage() 分 8 次掃描傳送至螢幕，兼具低記憶體消耗與高穩定性。
  • u8g2.enableUTF8Print()：啟用 UTF-8 解碼，使 u8g2.print("°C") 能正確繪製度數符號。

2.3 DFRobot SEN0159 (MG-811) 固態電化學原理

MG-811 為固態電解質（NASICON）加熱型二氧化碳感測器，其本質是一顆固態電化學濃差電池（Potentiometric Concentration Cell）。當內部加熱器維持在工作溫度（約 200~300°C）時，電極與 CO2 發生可逆電化學反應，輸出電動勢（EMF）遵循能斯特方程式 (Nernst Equation)：CO2 濃度越高，感測器輸出電壓越低，且電壓與 log10(CO2 ppm) 呈線性反比關係。

2.4 深入補充：SEN0159 (MG-811) 電化學機制與模組內部硬體電路

圖 2-2：MG-811 固態電解質濃差電池結構與 SEN0159 內部升壓/高阻抗放大電路訊號流向圖

(1) 固態濃差電池結構與電極反應式

MG-811 的電池結構可表示為：
Air, Au | NASICON | Li₂CO₃-BaCO₃ | Au, Air, CO₂

  • 陰極反應（感測電極）：
    2Li⁺ + CO₂ + ½O₂ + 2e⁻ ⇌ Li₂CO₃
  • 陽極反應（參考電極）：
    2Na⁺ + ½O₂ + 2e⁻ ⇌ Na₂O
  • 電池總反應：
    Li₂CO₃ + 2Na⁺ ⇌ Na₂O + 2Li⁺ + CO₂

當環境中的 CO₂ 濃度升高時，化學平衡向右或向左移動，改變兩極間的離子活度，進而產生對應的電動勢變化。

(2) 能斯特方程式 (Nernst Equation) 與熱力學關係

感測器輸出的原始電動勢 EMF 遵循能斯特方程式：

EMF = Ec - [ (R × T) / (2 × F) ] × ln( P_CO2 )
  • Ec：電池標準電位常數；R：氣體常數；F：法拉第常數。
  • T：絕對溫度 (K)。因為 T 直接影響斜率，且 NASICON 須在 200~300°C 下才具高離子導電率，故必須由板載 5V 升 6V 電路持續提供 6.0V (約 200mA / 1.2W) 恆溫加熱。
  • 為什麼需要 100~1000 GΩ 超高輸入阻抗與 8.5 倍放大？
    固態電解質電池內阻極高，任何大於 1 pA 的漏電流都會導致電極極化失準；因此 SEN0159 先以超高阻抗 Op-Amp 緩衝，再放大 8.5 倍 (DC_GAIN) 後送往 GPIO 32。

4. 程式碼核心架構與關鍵函式解說

4.1 非阻塞式排程架構 (Non-Blocking Loop)

為了讓 WebServer 隨時保持高速響應，loop() 中不使用長秒數的 delay(2000)，而是透過 millis() - lastReadTime >= delayMS 判斷是否到達 2 秒取樣週期： 

void loop(void) {
  // 1. 每次迴圈立即處理瀏覽器 HTTP 請求，確保網頁秒開不卡頓
  server.handleClient();

  // 2. 非阻塞式檢查：每滿 2000ms 才讀取一次 DHT22 / SEN0159 並刷新 OLED
  updateSensorData();
}

4.2 SEN0159 電壓取樣與對數換算 (MGRead & MGGetPercentage)

// 連續取樣 5 次取平均，並將 ESP32 12-bit ADC (0~4095) 換算為電壓 (0~3.3V)
float MGRead(int mg_pin) {
  float v = 0.0;
  for (int i = 0; i < READ_SAMPLE_TIMES; i++) {
    v += analogRead(mg_pin);
    delay(READ_SAMPLE_INTERVAL);
  }
  v = (v / READ_SAMPLE_TIMES) * 3.3 / 4095.0;
  return v;
}

// 根據 CO2Curve 對數斜率換算 ppm 濃度
int MGGetPercentage(float volts, float *pcurve) {
  if ((volts / DC_GAIN) >= ZERO_POINT_VOLTAGE) {
    return -1; // 電壓高於 400ppm 基準點，代表 < 400 ppm 或預熱中
  } else {
    float ppm = pow(10, ((volts / DC_GAIN) - pcurve[1]) / pcurve[2] + pcurve[0]);
    if (ppm > 10000.0) ppm = 10000.0; // 上限保護
    return (int)ppm;
  }
}

4.3 CO2 濃度五級警語設計 (getCO2Warning)

CO2 濃度 (ppm) 等級標籤 網頁動態警語內容
< 400 ppm (-1) 空氣清新 (< 400 ppm) ✅ 空氣品質極佳（濃度低於 400 ppm 或感測器預熱中），室內環境非常清新。
400 ~ 800 ppm 空氣品質良好 (正常) 🟢 室內二氧化碳濃度正常，空氣流通良好，適合長時間學習與辦公。
801 ~ 1000 ppm 空氣品質普通 (建議通風) 🟡 提醒：CO2 濃度略微上升，空氣開始變悶，建議適度開啟門窗或啟動換氣扇。
1001 ~ 2000 ppm 空氣渾濁 (中度警告) 🟠 警告：CO2 濃度偏高！容易導致嗜睡、精神不濟與注意力下降，請立即開窗通風！
> 2000 ppm 嚴重超標 (危險警報) 🔴 危險警報：CO2 濃度嚴重超標！可能引發頭痛、暈眩、心悸與缺氧不適，請立即強制排風換氣或離開密閉空間！

5. 實務注意事項與硬體排錯指南

⚠️ 注意事項 1：SEN0159 (MG-811) 預熱時間與基準點校準 (ZERO_POINT_VOLTAGE)
MG-811 屬於加熱型電化學感測器，剛上電時需要預熱使內部固態電解質達到化學平衡。若剛通電時顯示 < 400 ppm 屬於正常現象。若要進行精準校準，請將感測器置於室外潔淨空氣（約 400 ppm）預熱穩定後，查看網頁上的「感測器輸出電壓 (GPIO 32)」，將該電壓除以 8.5 後更新至程式碼中的 #define ZERO_POINT_VOLTAGE。
💡 注意事項 2：為什麼 CO2 感測器必須接在 GPIO 32 (ADC1)？
ESP32 內建 ADC1 (GPIO 32~39) 與 ADC2。一旦啟動 WiFi.begin()，ESP32 的 Wi-Fi 射頻硬體會獨佔 ADC2，導致 ADC2 腳位無法正常讀取類比值。因此整合 Wi-Fi WebServer 時，類比感測器務必連接至 ADC1 腳位（本程式使用 GPIO 32）。
🔌 注意事項 3：SEN0159 加熱器電源供應
SEN0159 模組上的加熱線圈耗電量約 150~200mA，請將其 VCC 連接至 NodeMCU-32S 的 5V (VIN) 腳位，並確保 USB 供電充足，避免與其他高耗電元件共用 3.3V 輸出造成電壓不穩。

6. 系統改善方向與實務延伸應用

🚀 軟硬體進階改善方向

  1. ESP32 端歷史資料持久化 (LittleFS / Ring Buffer)：目前 30 筆折線圖歷史儲存在瀏覽器端，可在 ESP32 內部建立環狀緩衝區或寫入 Flash 檔案系統（LittleFS），讓重新整理網頁或新連線的裝置也能立即載入過去數小時的完整曲線。
  2. mDNS 區域網路固定網域與自動重連：引入 <ESPmDNS.h> 設定 MDNS.begin("esp32-env")，即可直接使用 http://esp32-env.local 連線，並啟用 WiFi.setAutoReconnect(true)。
  3. 溫溼度交叉補償或升級 NDIR 感測器：利用 DHT22 溫度數據對 MG-811 進行軟體溫漂補償，或升級為免預熱的 NDIR 紅外線 CO2 感測器（如 MH-Z19B、SCD40）。

🏢 實務延伸應用場景

  1. 智慧教室與會議室新風連動控制：當 CO2 > 1000 ppm 時，自動透過 GPIO 觸發繼電器啟動換氣扇或全熱交換機，提升學習與會議效率。
  2. 智慧農業溫室與蕈菇栽培環控：結合 MQTT 協定將溫溼度與 CO2 上傳至 Home Assistant、Node-RED 或 InfluxDB 進行全天候紀錄。
  3. 即時通訊軟體推播預警：當環境達危險等級（如 CO2 > 2000 ppm 或高溫警報）時，透過 LINE Messaging API、Telegram Bot 或 Discord Webhook 發送警報至手機。
