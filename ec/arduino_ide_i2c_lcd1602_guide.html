下圖為您目前桌面上實際接線的硬體配置（Arduino Uno + I2C LCD 1602 模組）：

▲ 圖 1：實體接線照片，LCD 1602 透過背後焊接的 PCF8574 轉接板，僅需 4 根杜邦線即可與 Arduino Uno 完成通訊

🔌 實體 4-Pin 導線連接清單

I2C 轉接板引腳 訊號意義 Arduino Uno 對應腳位 配線重點與說明
GND 系統接地 (0V) GND (POWER 排針) 黑色/棕色導線，連接電源排針任一 GND 孔
VCC 工作電源 (+5V) 5V (POWER 排針) 紅色/紫色導線，務必接 5V（若誤接 3.3V 液晶對比度會嚴重不足）
SDA 串列資料線 (Serial Data) 類比 Pin A4 雙向資料通訊（亦可接數位排針 AREF 旁邊標示的專屬 SDA 孔）
SCL 串列時脈線 (Serial Clock) 類比 Pin A5 同步時脈傳輸（亦可接數位排針 AREF 旁邊標示的專屬 SCL 孔）
💡 硬體物理知識：為什麼 Uno 的 SDA 是 A4、SCL 是 A5？
Arduino Uno 核心晶片 ATmega328P 的內部硬體 TWI (I2C) 模組，物理線路就是硬體綁定在 PC4 (A4) 與 PC5 (A5)。數位排針右上角的專屬 SDA/SCL 腳位，在 PCB 底層走線上是直接與 A4、A5 貫通的，兩者接哪一個效果完全相同！

🖥️ 2. Arduino IDE 2.x 開發環境速成手冊

Arduino IDE 是撰寫、編譯並將程式碼燒錄至單晶片的官方整合開發環境。以下為新手上機的 4 大關鍵步驟：

1

選擇正確的開發板

將 USB 線插入電腦後，在頂部下拉選單選擇 "Arduino Uno"。

2

選擇正確的通訊埠 (COM Port)

選取標有 (Arduino Uno) 的通訊埠（如 COM3、COM4）。切勿選擇主機板內建的 COM1。

3

安裝 LiquidCrystal_I2C 庫

按下 Ctrl+Shift+I 開啟 Library Manager，搜尋並安裝 LiquidCrystal I2C (by Frank de Brabander)。

4

編譯 (✔) 與 上傳 (➔)

按 Ctrl+R 驗證語法，按 Ctrl+U 燒錄進板子；按 Ctrl+Shift+M 打開序列埠監視器除錯。

⚠️ 3. 實體硬體上機三大天坑除錯指南（95% 初學者必看！）

很多時候程式碼完全正確且上傳成功，但實體 LCD 螢幕卻一片空白，請立刻依序檢查以下 3 個地方：

💥 坑 1：I2C 設備位址不符（Tinkercad 是 0x20，實體板 95% 是 0x27 或 0x3F！）
• 在 Tinkercad 模擬中，PCF8574 位址被手動設為 0x20 (十進制 32)。
• 但在市面上購買的實體模組中，轉接板背面的 A0/A1/A2 跳線預設都是未焊開路，晶片型號為 PCF8574T 時預設位址為 0x27；若晶片型號帶 A (PCF8574AT) 則為 0x3F！
👉 解法：先燒錄下方第 4 節的「I2C Scanner」，1 秒自動查出您的真實位址！
🪛 坑 2：背部「藍色十字可變電阻」未調整（對比度過高/過低）
• 轉接板背後有一個藍色的小方塊，中間有一顆十字螺絲。
• 對比太淡：背光亮著但字跡全隱形，看起來像壞掉。
• 對比太濃：第一行顯示 16 個實心黑方塊。
👉 解法：拿小十字螺絲起子慢慢旋轉該藍色旋鈕，直到黑方塊淡化、清晰文字浮現！
🔌 坑 3：背光跳線帽（Jumper Cap）鬆脫或未插
• 轉接板側邊有兩根排針，上面插著一個黑色或黃色的小跳線帽。
• 這是背光電源的硬體開關，若跳線帽遺失，背光 LED 就不會點亮，螢幕會顯得極為昏暗。

🚀 4. 實體驗證兩部曲（程式碼清單）

步驟一：燒錄「I2C Scanner 位址自動偵測器」

上傳以下程式碼，開啟序列埠監視器（9600 baud），它會自動列印出您這塊 LCD 轉接板的真實十六進制位址：

#include <Wire.h>

void setup() {
  Wire.begin();
  Serial.begin(9600);
  while (!Serial); // 等待序列埠連線
  Serial.println(F("\n================================="));
  Serial.println(F("🔍 I2C 匯流排位址自動掃描開始..."));
  Serial.println(F("================================="));
  
  byte count = 0;
  for (byte address = 1; address < 127; address++) {
    Wire.beginTransmission(address);
    byte error = Wire.endTransmission();

    if (error == 0) {
      Serial.print(F("✅ 找到 I2C 裝置！位址為: 0x"));
      if (address < 16) Serial.print("0");
      Serial.println(address, HEX);
      count++;
    } else if (error == 4) {
      Serial.print(F("⚠️ 位址 0x"));
      if (address < 16) Serial.print("0");
      Serial.println(address, HEX);
      Serial.println(F(" 發生不明錯誤"));
    }
  }

  if (count == 0) {
    Serial.println(F("❌ 未找到任何 I2C 裝置！請檢查 5V/GND/SDA/SCL 接線。"));
  } else {
    Serial.print(F("🎉 掃描完成！共找到 "));
    Serial.print(count);
    Serial.println(F(" 個裝置。"));
  }
}

void loop() {}

步驟二：燒錄「實體 LCD 1602 文字顯示測試」

將上一步偵測到的位址（通常是 0x27）填入第 4 行，上傳後即可看見螢幕清晰顯示兩行字：

#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// ⚠️ 若剛才 Scanner 掃出來是 0x3F 或 0x20，請將 0x27 改為該位址
LiquidCrystal_I2C lcd(0x27, 16, 2);

void setup() {
  // 1. 初始化 LCD
  lcd.init();
  
  // 2. 開啟 LCD 背光
  lcd.backlight();

  // 3. 游標移至第 0 列第 0 格 (第一行)
  lcd.setCursor(0, 0);
  lcd.print("Arduino Uno I2C");

  // 4. 游標移至第 1 列第 0 格 (第二行)
  lcd.setCursor(0, 1);
  lcd.print("LCD 1602 Ready!");
}

void loop() {
  // 靜態展示
}
