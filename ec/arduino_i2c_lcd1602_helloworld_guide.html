1.1 實體 4-Pin 連接腳位對照表

I2C 轉接板腳位 訊號定義 Arduino Uno 對應腳位 照片導線對應 核心作用解析
GND 地線 GND (電源排針) 棕色 / 黑色線 系統共地迴路，基準電位。
VCC 電源 5V 5V (電源排針) 紅色 / 橙色線 驅動 HD44780、PCF8574 及 LCD 背光 LED。請勿接 3.3V。
SDA 數據線 A4 或專用 SDA 黃色線 串列雙向資料線 (Serial Data)，負責傳輸控制指令與字元編碼。
SCL 時脈線 A5 或專用 SCL 黃色 / 紅色線 串列同步時鐘線 (Serial Clock)，由 Arduino 主機產生驅動脈衝。
💡 硬體檢查三大必看重點：
  • 紅色電源 LED：PCF8574 板端的紅色指示燈是否亮起？（圖 1-1 中亮起，表示 5V 供電正常）。
  • 藍色電位器（十字旋鈕）：若螢幕只亮不見字體，請使用十字起子旋轉該旋鈕微調液晶偏壓對比度。
  • 背光跳線帽：背板最右側的黑色雙針跳線帽必須確實插上，否則背光 LED 不會發光。

🧠 二、I2C 雙線通訊與 PCF8574 晶片運作原理

標準 LCD 1602 具備 16 根排針，若直接由微控制器驅動，至少需要佔用 6 根（4-bit 模式）至 10 根（8-bit 模式）數位 I/O 腳位。 透過 PCF8574 晶片，實現了「串列轉並列 (Serial-to-Parallel)」控制：

I2C 匯流排的核心特點：
  • 僅需 2 條通訊線：SDA（數據）與 SCL（時脈），大幅釋放 Arduino 珍貴的數位 GPIO。
  • 7-bit 設備位址定址：PCF8574 預設位址為 0x27，PCF8574A 晶片則為 0x3F。
  • 多設備掛載能力：同一組 SDA/SCL 上可同時並聯 RTC 時鐘 (DS3231)、氣壓計 (BMP280) 等多個設備，互不衝突。

4.2 課堂測試程式碼 (`HelloWorld.ino`)

// YWROBOT
// Compatible with the Arduino IDE 1.0
// Library version: 1.1
#include <Wire.h>                 // 引入 Arduino 官方 I2C 通訊函式庫
#include <LiquidCrystal_I2C.h>    // 引入 PCF8574 轉接板專用 I2C LCD 函式庫

// 設定 LCD 位址為 0x27，具備 16 個字元寬度、2 行高度 (16x2)
LiquidCrystal_I2C lcd(0x27, 16, 2); 

void setup()
{
  lcd.init();                      // 初始化 LCD 液晶顯示器
  lcd.init();                      // 二次呼叫確保電氣時脈與 I2C 匯流排完全就緒
  
  // 開啟液晶背光
  lcd.backlight();
  
  // 移動游標至第 0 行第 3 格 (從 0 起算)
  lcd.setCursor(3, 0);
  lcd.print("Moooom world!");      // 印出測試訊息
  
  // 移動游標至第 1 行第 2 格 (從 0 起算)
  lcd.setCursor(2, 1);
  lcd.print("NO Arduino!");        // 印出測試訊息
}

void loop()
{
  // 靜態展示無須重複運算，loop 保持空白
}

📖 五、LiquidCrystal_I2C 物件屬性與常用方法全面手冊

LiquidCrystal_I2C 提供了豐富的 API 控制硬體。掌握以下常用方法即可靈活打造各種文字介面：

分類 方法名稱與語法 參數說明 功能解析

row: 0~1		 指定下一個輸出字元的起始座標（注意由 0 起算）。

🛠️ 六、進階實作：無閃爍動態計時器與自定義圖示 (INO)

在實際專案中，若在 loop() 內部頻繁呼叫 lcd.clear() 會造成肉眼可見的強烈黑白閃爍。 推薦使用「固定格式定位覆寫法 (Fixed Width Overwrite)」來達到極致平滑的顯示體驗： 

// 檔案路徑: D:\CLASS_NOTE\ec\arduino_i2c_lcd1602_helloworld.ino
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

LiquidCrystal_I2C lcd(0x27, 16, 2);

// 自定義字元 1: 愛心圖示 (5x8 點陣)
byte heartIcon[8] = {
  0b00000, 0b01010, 0b11111, 0b11111, 0b11111, 0b01110, 0b00100, 0b00000
};

// 自定義字元 2: 滿電電池圖示 (5x8 點陣)
byte batteryIcon[8] = {
  0b01110, 0b11111, 0b11111, 0b11111, 0b11111, 0b11111, 0b11111, 0b11111
};

unsigned long previousMillis = 0;
const long interval = 1000;
int counter = 0;

void setup() {
  lcd.init();
  lcd.init();          // 雙重初始化
  lcd.backlight();     // 開啟背光

  // 註冊自定義字元到 CGRAM (編號 0 與 1)
  lcd.createChar(0, heartIcon);
  lcd.createChar(1, batteryIcon);

  // 啟動畫面展示
  lcd.setCursor(1, 0);
  lcd.print("Hello, LCD1602");
  lcd.write(0);        // 印出愛心
  
  lcd.setCursor(0, 1);
  lcd.print("Status: Active ");
  lcd.write(1);        // 印出電池

  delay(2500);         // 停留 2.5 秒展示

  // 進入計時監控畫面
  lcd.clear();
  lcd.setCursor(0, 0);
  lcd.print("Timer Count: ");
  lcd.setCursor(0, 1);
  lcd.print("I2C Addr: 0x27");
}

void loop() {
  unsigned long currentMillis = millis();

  // 每秒更新計數，採用定點覆寫避免 clear() 造成的閃爍
  if (currentMillis - previousMillis >= interval) {
    previousMillis = currentMillis;
    counter++;

    lcd.setCursor(12, 0); // 固定在第 12 格更新三位數
    if (counter < 10) {
      lcd.print("00");
      lcd.print(counter);
    } else if (counter < 100) {
      lcd.print("0");
      lcd.print(counter);
    } else {
      lcd.print(counter);
    }

    // 每 10 秒提示一次游標閃爍效果
    if (counter % 10 == 0) {
      lcd.setCursor(15, 1);
      lcd.cursor();
      lcd.blink();
      delay(400);
      lcd.noBlink();
      lcd.noCursor();
    }
  }
}

❓ 七、常見硬體與軟體疑難排解 (FAQ & I2C Scanner)

故障現象 常見原因 標準解法
背光亮，但只見一排黑方塊或全白 對比度偏壓電阻未調整 用十字螺絲起子微調背板藍色電位器，直到字體清晰可見。
程式上傳成功，但螢幕無任何反應 I2C 位址不符（例如實際是 0x3F） 燒錄下方的 I2C Scanner 程式，從序列埠監視器讀取真實設備位址。
文字更新時畫面瘋狂跳動閃爍 在 loop() 內部頻繁執行 lcd.clear() 改用 lcd.setCursor() 搭配空格覆寫舊資料，根除重繪閃爍。

實用工具：I2C 位址自動掃描程式 (I2C Scanner)

#include <Wire.h>

void setup() {
  Wire.begin();
  Serial.begin(9600);
  while (!Serial);
  Serial.println("\nI2C Scanner 掃描器啟動中...");
}

void loop() {
  byte error, address;
  int nDevices = 0;

  Serial.println("開始掃描 I2C 匯流排...");

  for (address = 1; address < 127; address++) {
    Wire.beginTransmission(address);
    error = Wire.endTransmission();

    if (error == 0) {
      Serial.print("✔ 找到 I2C 設備！位址為: 0x");
      if (address < 16) Serial.print("0");
      Serial.print(address, HEX);
      Serial.println(" !");
      nDevices++;
    }
  }

  if (nDevices == 0) {
    Serial.println("未找到任何 I2C 設備，請檢查接線與 5V 供電！\n");
  } else {
    Serial.println("掃描完成。\n");
  }

  delay(5000); // 每 5 秒掃描一次
}
