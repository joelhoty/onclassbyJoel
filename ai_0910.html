單元一：GPT、ChatGPT、大語言模型 (LLMs) 與 Fine-Tuning 核心剖析

在人工智慧的發展史上，從傳統的機器學習演進至目前的生成式 AI，最關鍵的突破莫過於 Transformer 架構的問世與大語言模型（LLMs）的崛起。以下針對四大核心概念進行詳細定義與底層原理剖析：

⚡

1. GPT (Generative Pre-trained Transformer)

核心定義： 由 OpenAI 提出的自迴歸（Autoregressive）語言模型架構，基於 Transformer 的 Decoder-only 解碼器模組。

三大關鍵元素：

  • Generative (生成式)： 能根據輸入上下文，逐字/逐詞產生新的文本。
  • Pre-trained (預訓練)： 在未標註的海量網路文字庫上進行無監督學習，學習語言結構與世界知識。
  • Transformer： 採用 Self-Attention (自注意力機制) 解決長距離依賴問題。
💬

2. ChatGPT (對話式優化 AI)

核心定義： 以 GPT 基底模型為基礎，經過人類意圖對齊（Alignment）與對話優化後產生的對話產品。

關鍵差異： 未經對齊的 Base GPT 只會「接續文字」；而 ChatGPT 則能理解「指令與對話語境」，並具備安全拒絕與多輪對話能力。

🧠

3. LLMs (Large Language Models, 大語言模型)

核心定義： 擁有數十億至數千億級別參數的巨型神經網路模型（如 GPT-4, Llama 3, Gemini, Claude）。

湧現能力 (Emergent Abilities)： 當模型參數規模與訓練資料量突破臨界值時，模型會突發性具備邏輯推理、跨語言翻譯與程式碼寫作能力。

🎯

4. Fine-Tuning (微調技術)

核心定義： 將預訓練好的通用大模型，利用特定領域數據集進行二次訓練，適應特定場景。

微調主流類型：

  • SFT (Supervised Fine-Tuning)： 指令微調，學習高質量的問答對。
  • PEFT / LoRA (低秩適應)： 凍結原模型 99% 參數，僅訓練低秩矩陣，極大降低顯存門檻。
  • RLHF / DPO： 結合人類偏好反饋進行強化學習對齊。

單元二：GPT 如何實現「下一個詞預測 (Next-Token Prediction)」？

現代 GPT 模型表面上展現出驚人的對話能力，其底層核心數學本質極其純粹：「給定前面已出現的所有文字 Sequence，預測下一個最可能出現的 Token 的機率分布」。

$$ P(x_1, x_2, \dots, x_T) = \prod_{t=1}^{T} P(x_t \mid x_1, x_2, \dots, x_{t-1}) $$

經由 Tokenization (BPE) 轉為 Token ID，傳入包含 Positional Encoding 與 Causal Self-Attention 的 Transformer Decoder 層，最後通過 Softmax 輸出 Logits 概率：

$$ P(y_i) = \frac{\exp(z_i / T)}{\sum_{j} \exp(z_j / T)} $$

單元四：🎨 擴散模型 (Diffusion Models) 訓練與生成圖像原理深度解析

與 GPT 這種「自迴歸文字生成模型」不同，擴散模型 (Diffusion Models, 如 DDPM, Stable Diffusion, Flux, Midjourney) 是當前圖像、影片生成領域的絕對霸主。其核心物理與數學直覺來自於熱力學的分子擴散現象。

💡 擴散模型的核心直覺：毀滅與創新的對偶性
1. 前向破壞 (Forward Process)： 像是一滴墨水滴入水中逐漸擴散，把一張清晰的照片一步步加入高斯雜訊，直到完全變成看不出任何結構的純雪花噪音。
2. 反向創造 (Reverse Process)： 訓練神經網路（U-Net）學會「時光倒流」，學會如何在任意雜訊狀態下預測出剛才加進去的噪聲，從純白噪聲中一步步去噪，還原並創作出震撼的圖像！

1. 前向擴散過程 (Forward Process / Noise Addition)

給定一張原始真實圖像 \(x_0\)，前向過程在時間步 \(t = 1, 2, \dots, T\)（通常 \(T = 1000\)）中，按照預先設定的噪聲排程（Beta Schedule, \(\beta_t\)）逐步加入高斯噪聲：

$$ q(x_t \mid x_{t-1}) = \mathcal{N}\left(x_t; \sqrt{1-\beta_t} x_{t-1}, \beta_t \mathbf{I}\right) $$

重參數化技巧 (Reparameterization Trick)： 透過數學導引，我們不需要真的做 1000 次加噪疊加，可以直接一步從原圖 \(x_0\) 計算出任意時間步 \(t\) 的帶噪圖片 \(x_t\)：

$$ x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \boldsymbol{\epsilon}, \quad \text{where } \boldsymbol{\epsilon} \sim \mathcal{N}(0, \mathbf{I}) $$

2. 反向去噪與神經網路預測 (Reverse Denoising Process & U-Net)

反向過程 \(p_\theta(x_{t-1} \mid x_t)\) 是生成圖像的核心。模型無法直接預測整張照片，因此訓練目標被簡化為：「讓 U-Net 神經網路在給定帶噪圖片 \(x_t\) 與時間步 \(t\) 下，精準預測出當時加進去的噪聲 \(\boldsymbol{\epsilon}_\theta(x_t, t)\)」。

3. 擴散模型的訓練損失函數 (Training Loss Function)

擴散模型的訓練演算法極其簡潔且高效，損失函數即為預測噪聲與實際高斯噪聲之間的均方誤差 (MSE Loss)：

$$ \mathcal{L}_{\text{simple}}(\theta) = \mathbb{E}_{t, x_0, \boldsymbol{\epsilon}} \left[ \left\| \boldsymbol{\epsilon} - \boldsymbol{\epsilon}_\theta\left(\sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \boldsymbol{\epsilon}, \; t\right) \right\|^2 \right] $$

訓練 4 大步驟：

  1. 從訓練集中隨機挑選一張高清圖片 \(x_0\)。
  2. 隨機抽取一個時間步 \(t \in [1, T]\) 與高斯噪聲向量 \(\boldsymbol{\epsilon}\)。
  3. 利用公式計算出帶噪圖片 \(x_t\)。
  4. 將 \(x_t\) 與 \(t\) 餵入 U-Net，計算預測噪聲與真實噪聲 \(\boldsymbol{\epsilon}\) 的 MSE Loss 並更新 U-Net 權重。

4. 文字控制生成：Classifier-Free Guidance (CFG)

為了讓文字 Prompt（如「太空中的柴犬」）控制圖像生成，將文字經由 CLIP Text Encoder 轉為向量條件 \(c\)，經由 Cross-Attention 注入 U-Net。在推論時利用 CFG 引導係數 (\(s\)) 強調 Prompt 的影響：

$$ \tilde{\boldsymbol{\epsilon}}_\theta(x_t, c) = \boldsymbol{\epsilon}_\theta(x_t, \emptyset) + s \cdot \left( \boldsymbol{\epsilon}_\theta(x_t, c) - \boldsymbol{\epsilon}_\theta(x_t, \emptyset) \right) $$

5. Latent Diffusion Models (LDM / Stable Diffusion)

直接在高清像素空間（如 \(1024 \times 1024 \times 3\)）做擴散計算極慢。Stable Diffusion 採用 VAE (變分自編碼器) 將圖片壓縮至隱空間 (Latent Space, 例如 \(64 \times 64 \times 4\))，在 Latent 空間進行加噪與去噪，計算速度提升幾十倍！

單元六：LLMs (自迴歸) vs Diffusion (擴散模型) 核心差異比較

比較維度 LLMs / GPT (自迴歸模型) Diffusion Models (擴散模型)
主要應用領域 文字生成、對話、程式碼寫作、邏輯推理 圖像生成、影片合成、語音合成、3D 資材生成
生成機制 Autoregressive (自迴歸)： 逐個 Token 依照機率從左至右生成 Iterative Denoising (迭代去噪)： 從全局雜訊開始，同時對所有像素進行多輪去噪還原
訓練核心目標 預測下一個 Token 的交叉熵損失 (Cross-Entropy Loss) 預測高斯噪聲向量的均方誤差 (MSE Noise Loss)
條件引導方式 In-Context Prompt (前置上下文 Prompt) CLIP Cross-Attention + CFG (Classifier-Free Guidance)
最新演進趨勢 Reasoning LLMs (思考鏈 o1/R1), MoE 混合專家架構 DiT (Diffusion Transformer), Rectified Flow (Flux.1 / SD3)

單元七：課後學習心得與總結

  1. AI 生成技術的兩大支柱： 文字的世界由自迴歸的 Next-Token Prediction 統治，而視覺與多模態的世界則由迭代去噪的 Diffusion Model 霸佔。理解兩者本質數學模型的差異，是掌握現代 AI 的鑰匙。
  2. 高維噪聲中的秩序： 擴散模型展示了如何從完全無序的白噪聲（Entropy 最高狀態）中，透過 U-Net 逐步提取特徵構造出高品質藝術作品，完美體現了深度學習的擬合能力。
  3. 實務應用的跨界融合： 現代頂級生成系統（如 Flux, Dall-E 3, Sora）正將 LLM（理解複雜 Prompt 指令）與 DiT/Diffusion（生成高解析度圖像影片）深度的結合在一起。
