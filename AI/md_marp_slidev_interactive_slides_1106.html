📖 導言與概覽

今日課堂核心是：以 Markdown 為單一真相來源（Single Source of Truth），再透過不同工具鏈轉換成多種交付格式。

格式副檔名角色典型用途
Markdown.md純文字內容稿版本控管、AI 協作、筆記原稿
Marp.md / .marp.md簡報語意 Markdown投影片分隔、主題、marp-cli 轉檔
HTML.html / .htm瀏覽器可渲染文件筆記頁、靜態／互動簡報網頁
SVG.svg向量圖形（XML 文字）流程圖、架構圖、可縮放插圖
PDF / PPTX.pdf / .pptx交付產物繳交、離線播放

兩條主要工具鏈：

  1. Marp CLI（@marp-team/marp-cli）：把 Marpit Markdown 轉成靜態 HTML／PDF／PPTX。
  2. Slidev：把 Markdown 變成 Vite + Vue 驅動的互動式簡報網頁。

🧠 一、核心概念剖析 (Core Concepts)

1. 為什麼要「先寫 MD，再轉格式」？

  • 內容與版面分離：Markdown 管「說什麼」，主題／CSS／Vue 管「怎麼呈現」。
  • 可重現：同一份 .md 可再產出 HTML、PDF、PPTX。
  • 適合 AI／Git：純文字 diff 清楚，Agent 也好改標題與要點。

2. Marp / Marpit 的底層模型

  • Marpit：以 Markdown 為基礎；--- 分隔頁面，YAML frontmatter 設定主題。
  • Marp Core：加上預設主題、數學式、emoji 等。
  • Marp CLI：預設輸出 HTML；--pdf／--pptx 透過本機瀏覽器渲染。

概念式關係：簡報產物 = Markdown 內容 + 主題 CSS + 渲染引擎（瀏覽器／Vite）。

3. Slidev 的底層模型

  • Markdown + Vue：可嵌入互動元件。
  • Vite 開發伺服器：儲存即熱更新。
  • 互動式網頁：可執行程式碼、Presenter Mode、畫筆註記。
  • 建置輸出：slidev build 產生可部署靜態站。

4. 格式對照：筆記 HTML vs 簡報 HTML

類型例子導覽方式
課堂筆記 HTML本頁長頁捲動、複製程式碼、列印 PDF
Marp 靜態簡報 HTMLmarp slides.md -o out.html全螢幕頁面切換
Slidev 互動簡報npm run dev / dist/SPA、Presenter、元件互動

5. 檔案格式詳解：MD、Marp、HTML、SVG

這四種都常以純文字儲存，可用記事本／VS Code 開啟，也適合放進 Git；差異在「語意層級」與「誰來負責呈現」。

5.1 Markdown（.md）

面向說明
是什麼輕量標記語言：用 #、- 等描述結構，本身不是版面。
本質UTF-8 純文字；需轉譯器才有最終外觀。
優點好寫、好 diff、AI 友善、與工具鏈解耦。
限制原生幾乎沒有版面控制；複雜互動靠下游。

常用語法：# 標題、**粗體**、行內碼、程式碼區塊、![圖](path)、[連結](url)。

5.2 Marp（仍是 Markdown，但帶簡報契約）

面向說明
是什麼Markdown + YAML frontmatter（marp: true）+ --- 分頁。
副檔名常見 .md；本工作區也用 .marp.md 標示簡報稿。
本質仍是文字檔；投影片感來自主題 CSS 與 CLI 輸出。
優點一份稿可轉 HTML／PDF／PPTX。
限制互動弱於 Slidev；不是自由排版軟體。

概念式：Marp 檔 = Markdown + 投影片 frontmatter + 頁分隔（---）。

5.3 HTML（.html）

面向說明
是什麼用標籤描述文件結構的 HyperText Markup Language。
本質瀏覽器直接解析的 DOM；可掛 CSS 與 JS。
本課角色(1) 長頁筆記網頁；(2) Marp／Slidev 產出的簡報網頁。
優點跨平台、可互動、可列印 PDF、可部署 Pages。
限制手寫成本高；原始碼比 MD 難讀／難 diff。

對照：.md 是作者友善的中介格式；.html 是瀏覽器友善的交付格式。

5.4 SVG（.svg）

面向說明
是什麼用 XML 描述點、線、路徑、文字的向量圖。
本質圖形也是文字；縮放不像素化。
與點陣差PNG／JPG 是像素；SVG 是幾何指令。
優點無限縮放清晰、可內嵌 HTML、可被 CSS／JS 操控。
限制不適合照片；過度複雜難維護；部分 Office 支援不一。

典型用法：匯出 SVG → ![說明](./assets/xxx.svg) 嵌進 MD，或 <img src="...svg">／內嵌進 HTML。

5.5 四種格式怎麼分工？

你想做的事優先格式
寫內容、改稿、給 AI.md
做投影片、交 PDFMarp → CLI
用瀏覽器讀筆記／簡報.html
可縮放示意圖、架構圖.svg（或 Mermaid → SVG）

範例 B：使用 marp-cli 轉換

流程：選擇輸出格式 → 執行 npx／marp → 開啟產物驗證。

bash
# 一次性轉換（不永久安裝）：輸出與輸入同目錄的 .html
npx @marp-team/marp-cli@latest slides.md

# 指定輸出 HTML 檔名
npx @marp-team/marp-cli@latest slides.md -o slides.html

# 匯出 PDF（需本機有 Chrome / Edge / Firefox）
npx @marp-team/marp-cli@latest slides.md --pdf -o slides.pdf

# 匯出 PowerPoint
npx @marp-team/marp-cli@latest slides.md --pptx -o slides.pptx

# 監視檔案變更，存檔即重新轉檔
npx @marp-team/marp-cli@latest -w slides.md

# 伺服器模式：把整個資料夾當簡報站
npx @marp-team/marp-cli@latest -s ./slides

# 專案內安裝後使用
npm install --save-dev @marp-team/marp-cli
npx marp slides.md -o dist/slides.html

範例 C：建立 Slidev 互動簡報專案

流程：scaffold → 編輯 slides.md → dev 預覽 → build 靜態站。

bash
# 建議：Node.js >= 22.12
pnpm create slidev
# 或：npm init slidev@latest

cd my-slidev-project
npm run dev      # 本地互動預覽（Vite）
npm run build    # 建置靜態網站到 dist/
npm run export   # 匯出 PDF / PPTX / PNG

🚀 三、延伸思考與進階主題 (Extensions & Advanced Topics)

1. Marp vs Slidev：怎麼選？

維度Marp CLISlidev
學習曲線低中（需一點前端／Node）
互動性低（靜態頁切換）高（Vue、即時碼）
輸出穩定度HTML／PDF／PPTX 成熟網頁優先，匯出也強
適合場景課堂報告、文件型簡報Demo、技術分享、工作坊
部署單檔 HTML 即可build 後的靜態站
實務建議：內容定稿與繳交用 Marp；要「現場跑碼、互動演示」用 Slidev。兩者可共用同一份大綱，再分別加上 frontmatter。

2. 常見坑與邊界條件

  • PDF／PPTX 失敗：找不到瀏覽器引擎；確認 Chrome／Edge／Firefox。
  • 本機圖片：轉 PDF 可能需 --allow-local-files（僅用於可信本機檔）。
  • PPTX 不可編輯：預設多為預渲染圖；可編輯需實驗性 --pptx-editable。
  • Slidev Node 版本：官方要求較新 Node，過舊會失敗。
  • 主題溢出：先用 16:9 全螢幕實測投影機解析度。

3. 性能與工作流權衡

  • 單一巨型 MD 方便但合併衝突多；可拆「大綱 → marp／slidev」。
  • 演示前先 build 或預先開好預覽，避免現場裝套件。
  • 通常只提交來源 .md 與必要 theme CSS；大型 PDF／node_modules 不進版控。

4. 未來延伸

  • CI 在 push 時自動 marp --pdf 或 slidev build 發佈 Pages。
  • 與既有「文件摘要 → 10 頁大綱」流程串接落地。
  • 參考本 repo 的 ec/marp-theme-tech.css 自訂主題。

5. MD／Marp／HTML／SVG 的進階比較與坑

議題MDMarpHTMLSVG
人類可讀性最高高中中（路徑多時難讀）
瀏覽器直接開通常否否（需轉檔）是是
適合照片否（只引用）引用點陣圖可嵌點陣／向量不適合
互動無弱強（+JS）可（+CSS／JS）
Git 友好極佳極佳佳佳（簡單圖）
  • Marp ≠ 二進位格式：不是像 .pptx 的專有容器，而是約定好的 Markdown。
  • HTML 可能很大：Marp／Slidev 產出常內嵌 CSS／JS。
  • SVG 安全性：不明來源可能含 script；公開站宜當靜態圖引用。
  • 相對路徑：引用 ./assets/x.svg 時以開啟檔所在目錄為準，轉 PDF 易斷圖。

性能權衡：示意圖用 SVG；照片用壓縮 JPG／WebP；投影優先簡單靜態 SVG。

✅ 今日課堂重點速記

  1. MD 是源頭；HTML／PDF／PPTX／互動站都是衍生結果。
  2. Marp＝Markdown＋投影片契約（frontmatter、---）；不是神秘二進位格式。
  3. HTML＝瀏覽器可直接渲染的文件；筆記長頁與簡報網頁都屬此類。
  4. SVG＝可縮放向量圖（XML 文字），適合流程／架構示意，可嵌進 MD／HTML。
  5. marp-cli：npx @marp-team/marp-cli@latest file.md [-o out.html|--pdf|--pptx]。
  6. Slidev：交件穩選 Marp，互動選 Slidev。
