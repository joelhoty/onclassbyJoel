一、核心概念剖析（Core Concepts）

1.1 Voronoi 鑲嵌幾何原理與視覺美學（Voronoi Tessellation & Cellular Aesthetics）

Voronoi 圖（泰森多邊形）是計算幾何學中的基礎劃分算法：給定平面上一組離散種子點，將平面劃分成數個凸多邊形，使各多邊形內部任一點到該區種子點的距離均小於到其他種子點的距離。此幾何結構常見於大自然，如長頸鹿斑塊紋理、植物葉脈輸送通道、蜻蜓翅膀翼脈等。

在神經網路與擴散模型層面，vrn.safetensors 是基於 SDXL 架構訓練的專用 LoRA。它將提示詞中的觸發詞（vrn、voronoi complex pattern、intricate cell networks）映射至模型 Cross-Attention 交叉注意力層與卷積特徵層，強迫模型在物體輪廓與表面生成細密且立體的多邊形網格紋理。

1.2 SDXL 底模 Juggernaut XL (Ragnarok) 架構特性

本作業採用的 juggernautXL_ragnarok.safetensors 是 SDXL 1.0 的頂級 Checkpoint，具備以下優勢：

  • 雙文字編碼器（Dual CLIP）支援：結合 OpenCLIP ViT-bigG/14 與 CLIP ViT-L/14，對長句提示詞、鏡頭視角（如 camera angle front）解析極為敏銳。
  • 高韌性解剖學結構：許多純藝術風格模型在加入高強度 LoRA 後容易產生五官融化或斷肢。Juggernaut XL 擁有扎實的寫實人物先驗權重，在 weight: 0.8 的重度幾何風格介入下，依然能生成輪廓鮮明、眼神銳利的戰士面容。

1.3 Fooocus 工具特色與 WebUI 映射邏輯

💡 重要觀念釐清：若將 LoRA 命名為 civitai_298448.safetensors，提示詞該怎麼寫？
  1. 檔案名稱 ≠ 觸發詞：更改 .safetensors 檔名只改變作業系統與軟體辨識的檔名，絕不會改變模型內部訓練好的觸發詞（Trigger Words）！此 LoRA 的專屬觸發詞依然是 vrn、voronoi complex pattern 與 intricate cell networks。
  2. Fooocus 操作方式：不要在提示詞寫 <lora:civitai_298448:0.8>（Fooocus 不支援此語法）。請將檔案放在 models/loras/，在 Fooocus 的 Models 標籤頁 下拉選單選擇 civitai_298448.safetensors，Weight 設為 0.8。提示詞只需照常填寫 vrn, voronoi complex pattern... 即可！
  3. 傳統 WebUI (A1111 / Forge) 寫法：若在傳統 WebUI 中，才需要在 Prompt 寫入檔用語法：<lora:civitai_298448:0.8>, vrn, voronoi complex pattern...。

1.4 LoRA 觸發詞機制深入：所有 LoRA 都必須有觸發詞才能啟用嗎？

答案是：「不一定」！這取決於該 LoRA 訓練時的「打標（Captioning）策略」與設計目標：

LoRA 類型 典型代表範例 底層訓練策略 是否必須觸發詞？ 未填寫觸發詞之實際表現
特定概念 / 主體綁定型 本課之 vrn (Voronoi)、特定角色、名人臉孔、專屬產品 訓練資料集強制綁定特定罕見 Token（如 vrn） 必須有觸發詞 權重雖然載入，但神經網路注意力未被激活，畫面幾乎看不出效果
全域畫質 / 光影風格型 Detail Tweaker (細節增強)、Film Grain (底片顆粒)、Add More Detail 空標籤（No Captions）訓練，直接微調底模常態分佈 免觸發詞 掛載即生效！只要在 UI 中設定權重，全圖自動套用效果
混合泛用風格型 水彩 (Watercolor)、油畫筆觸、賽博龐克色系 混合自然語言長句打標 建議填寫相關詞 未寫時有微弱色調偏移，但加入關鍵字後風格特徵才會完全顯現
🔍 判斷技巧：在 Civitai 下載任何 LoRA 時，先看右側邊欄的 Trained Words。若欄位列有單詞（如 vrn），代表必須寫入；若為空或作者於簡介註明 "No trigger word needed"，則代表只需掛載即可全域生效。
功能項目 標準 SD WebUI / ComfyUI Fooocus 實作機制 課堂操作關鍵
LoRA 載入語法 在 Prompt 填入 <lora:vrn:0.8> 在 Models 標籤頁 的 LoRA 滑桿直接選擇與調整 Prompt 中勿留 <lora:...>，僅保留觸發詞 vrn
預設風格（Styles） 手動載入 Negative Embeddings 預設自動勾選 Fooocus V2 與 Masterpiece 黑白極簡幾何建議取消勾選 Fooocus V2，避免畫面被過度平滑
Guidance (CFG) 通常預設為 7.0 SDXL 推薦 3.5 ~ 5.5 本作業原圖使用 CFG = 5.0，可維持幾何網格邊緣的高清晰度
原生解析度 手動設定 512x640 + Hires. Fix Setting 內建 SDXL 最佳比例選單 直接選取 1024×1280 (4:5)

三、延伸思考與進階主題（Extensions & Advanced Topics）

3.1 LoRA 權重梯形效應（Weight Ramp Analysis）

  • 0.3 ~ 0.5：微量風格化。底模寫實膚質占 80%，僅在顴骨與陰影處出現輕微幾何線條。
  • 0.7 ~ 0.85（原圖設定）：黃金平衡點。細胞多邊形深入皮膚與頭飾，立體雕刻感強烈，且眼眶、唇鼻等核心結構未被破壞。
  • 1.0 以上：超幾何抽象化。多邊形線條變粗，人臉特徵開始碎裂解構，適合前衛超現實海報創作。
