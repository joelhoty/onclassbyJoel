1 課程前言：從生成式 AI (Generative AI) 與 Prompt 談起

1.1 Prompt 工程與生成式 AI 的現代浪潮

在今日課程的開頭，老師特別強調了 Prompt Engineering（提示工程） 以及 Generative AI（生成式人工智慧） 的爆發性發展。從大型語言模型（LLM）如 GPT-4、Gemini 到影像生成模型（如 Stable Diffusion、Midjourney、FLUX），人類與 AI 互動的方式已經轉變為使用自然語言進行「意圖導引」。

然而，不論提示詞寫得再精妙，生成式 AI 背後處理「圖像輸入與輸出」的根本機制，依然深深依賴電腦視覺（Computer Vision, CV）基礎。特別是在圖像理解、特徵編碼（Latent Encoding）與細節重建上，卷積神經網路 (CNN) 奠定了不可替代的技術血脈。

1.2 當 Prompt 遇到視覺：為何仍需深入理解 CNN？

雖然當前基於 Transformer 的大模型（如 Vision-Language Models, VLM）盛行，但 CNN 在計算效率、區域空間特徵提取（Local Spatial Extraction）以及邊緣裝置（Edge Devices）部署上仍具備極大優勢。

💬 Prompt Engineering

高層次互動層：透過文字精確表達需求，導引 AI 生成或分析目標內容。

🎨 Generative AI

內容創造層：基於潛在空間（Latent Space）生成新圖像、影片或文本。

👁️ CNN (卷積神經網路)

視覺感知基石：透視圖像微觀特徵（邊緣、紋理、結構），提供強大的幾何歸納偏置。

💡 生成式 AI 中的 CNN 蹤影

例如在圖像生成模型 Stable Diffusion 中，負責將高維影像壓縮至潛在空間的 VAE (Variational Autoencoder) 以及在擴散過程中去噪的核心架構 U-Net，其本質都是基於深層 CNN 的卷積與轉置卷積（Transposed Convolution）運算！

2 為何傳統前饋神經網路 (FNN) 不適合影像辨識？

2.1 影像數據的三維結構本質

現實中的數位影像並不是一維的數字序列，而是包含高度 (Height, H)、寬度 (Width, W) 與 色彩通道 (Channels, C) 的三維張量（Tensor）。例如一張經典的 224×224 像素 RGB 彩色圖片，資料維度即為 $224 \times 224 \times 3 = 150,528$ 個數值。

2.2 傳統全連接層 (Fully Connected Layer, FNN) 的三大困境

圖 2.1：傳統前饋神經網路 (FNN) 與卷積神經網路 (CNN) 處理解析度影像時的對比
  • 1. 參數爆炸 (Parameter Explosion)： 若將 1080p 彩色影像 ($1920 \times 1080 \times 3 \approx 620$ 萬維度) 輸入全連接層，若第一隱藏層僅有 1,000 個神經元，權重總數高達 62 億個參數！這極易導致嚴重過擬合 (Overfitting) 與計算資源耗盡。
  • 2. 空間幾何資訊遺失 (Loss of Spatial Hierarchy)： 傳統 FNN 必須將圖片展平 (Flatten) 成一維向量。這樣會破壞像素之間的上下左右相鄰關係（例如：眼睛與鼻子之間的幾何距離資訊被硬生生割裂）。
  • 3. 缺乏平移不變性 (Lack of Translation Invariance)： 如果一隻貓出現在圖片左上角與右下角，全連接網路會將其視為完全不同的特徵組合，無法共用學習成果。

2.3 CNN 的三大關鍵拯救機制

1. 局部感受野 (Local Receptive Fields)

神經元不再連接整張圖片，而是每次只關注一小塊區域（如 3×3 或 5×5 像素），專注捕捉局部幾何特徵。

2. 權重共享 (Weight Sharing)

同一個卷積核（Kernel）在滑動掃描整張圖片時，使用完全相同的權重參數，極大地減少了模型參數總數量。

3. 空間降採樣 (Downsampling / Pooling)

透過池化層逐步縮小特徵圖尺寸，降低計算量並獲得更強的平移與轉動容忍度。

3 CNN 核心組件與數學運算原理

3.1 卷積層 (Convolutional Layer) 原理與幾何推導

卷積層是 CNN 的靈魂。它利用一個小型矩陣——卷積核 / 濾鏡 (Kernel / Filter)，在輸入影像上由左至右、由上至下按指定的步長（Stride）滑動，計算對應區域的元素相乘求和（Element-wise Product & Sum），再加上偏置項（Bias），輸出生成特徵圖 (Feature Map)。

卷積數學公式： $$Y_{i,j} = \sum_{m} \sum_{n} X_{i+m, j+n} \cdot W_{m,n} + b$$

卷積層幾何尺寸計算公式

假設輸入影像大小為 $W \times H$，卷積核大小為 $K \times K$，填充邊界大小為 $P$ (Padding)，步長為 $S$ (Stride)，則輸出的特徵圖尺寸 $O$ 為：

$$O = \left\lfloor \frac{W - K + 2P}{S} \right\rfloor + 1$$

3.2 激活函數層 (Activation Layer: ReLU)

卷積運算本身是線性乘加操作。為了讓網路具備學習複雜非線性決策邊界的能力，必須在卷積後導入非線性激活函數。最常用的是 ReLU (Rectified Linear Unit)：

$$f(x) = \max(0, x)$$

ReLU 能有效保留正向特徵訊號，同時將負值歸零，避免了傳統 Sigmoid 或 Tanh 函數在深層網路中的梯度消失問題 (Gradient Vanishing)，且計算速度極快。

3.3 池化層 (Pooling Layer / Downsampling)

池化層主要用於降低特徵圖的空間解析度（Spatial Dimensions），減少參數運算量，並賦予模型一定程度的平移與幾何形變不變性 (Translation Invariance)。

圖 3.2：2x2 最大池化 (Max Pooling, Stride=2) 運算示意圖
  • Max Pooling (最大池化)： 取區域內最大值。能精確保留圖像中最顯著的邊緣或刺激反應，是目前最常用的池化方式。
  • Average Pooling (平均池化)： 取區域內所有值的平均數。平滑感較強，常用於網絡最末端的全局平均池化 (Global Average Pooling)。

3.4 全連接層 (Fully Connected Layer) 與 Softmax 分類

在經歷多次「卷積 $\to$ ReLU $\to$ 池化」的特徵提取後，高階特徵圖將被展平（Flatten）為一維向量，輸入至全連接層（Dense Layer）。最後透過 Softmax 函數 將神經元輸出值轉換為各類別的機率分布：

$$\text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}}$$

4.2 CNN vs. Vision Transformer (ViT) 對比

比較維度 卷積神經網路 (CNN) Vision Transformer (ViT)
核心機制 局部卷積 (Local Convolution) 全局自注意力 (Global Self-Attention)
歸納偏置 (Inductive Bias) 強 (假設局部像素高度相關、具平移不變性) 弱 (無先驗幾何假設，完全從數據學習)
小數據集表現 佳 (無需海量數據即可收斂) 較差 (需預訓練或超大規模數據)
硬體計算複雜度 對影像解析度呈線性關係 $\mathcal{O}(N)$ 對 Patch 數量呈二次方關係 $\mathcal{O}(N^2)$

5 CNN 的廣泛實務應用場景

🔍 1. 物件偵測 (Object Detection)

代表模型：YOLO 系列, Faster R-CNN

不僅辨識圖片中有什麼，還能標註出邊界框（Bounding Box）。廣泛用於自動駕駛行人偵測、工廠瑕疵篩選。

🧩 2. 圖像分割 (Image Segmentation)

代表模型：U-Net, Mask R-CNN

進行像素級別（Pixel-level）分類。在醫療影像（如腫瘤 CT 掃描切割）、衛星地圖土地利用劃分中不可或缺。

🚗 3. 自動駕駛與視覺感知

代表應用：車道線辨識、交通標誌識別

即時處理車載攝影機影像，提供高幀率的幾何結構感知與動態物體追蹤。

✨ 4. 生成式 AI 與影像擴散模型

代表應用：ControlNet, Stable Diffusion UNet

利用 CNN 提取手繪草圖、深度圖（Depth Map）或人體骨架特徵，精準導引生成式 AI 繪製圖片。

6 PyTorch 經典 CNN 分類模型實現

以下是一個精簡但完整的 PyTorch 卷積神經網路實作範例，展示如何構建包含卷積、池化與全連接層的影像分類模型：

Python 3.10+ | PyTorch 2.0+ cnn_model.py 
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    def __init__(self, num_classes=10):
        super(SimpleCNN, self).__init__()
        # 第一層卷積：輸入 3 通道 (RGB)，輸出 16 通道，Kernel 3x3, Padding 1
        self.conv1 = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, stride=1, padding=1)
        
        # 第二層卷積：輸出 32 通道
        self.conv2 = nn.Conv2d(in_channels=16, out_channels=32, kernel_size=3, stride=1, padding=1)
        
        # 2x2 最大池化層 (將尺寸縮小一半)
        self.pool = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # 全連接層 (假設輸入圖片大小為 32x32，經歷兩次 Pool 後變為 8x8)
        self.fc1 = nn.Linear(32 * 8 * 8, 128)
        self.fc2 = nn.Linear(128, num_classes)

    def forward(self, x):
        # 輸入: [Batch, 3, 32, 32]
        x = self.pool(F.relu(self.conv1(x)))  # 變成: [Batch, 16, 16, 16]
        x = self.pool(F.relu(self.conv2(x)))  # 變成: [Batch, 32, 8, 8]
        
        # 展平 (Flatten) 特徵圖
        x = x.view(x.size(0), -1)             # 變成: [Batch, 2048]
        
        x = F.relu(self.fc1(x))
        x = self.fc2(x)                       # 輸出分類 Logits: [Batch, num_classes]
        return x

# 測試模型前向傳播尺寸
if __name__ == "__main__":
    model = SimpleCNN(num_classes=10)
    dummy_input = torch.randn(4, 3, 32, 32)  # 4 張 32x32 彩色圖片
    output = model(dummy_input)
    print(f"模型輸出 Shape: {output.shape}")  # 應為 [4, 10]

📝 本課總結心智梳理
  1. Prompt 與 GenAI 的連結： 生成式 AI 雖然由文字與多模態導向，但其內核（如 Diffusion UNet、Latent VAE）依然深植 CNN 特徵提取與重建能力。
  2. CNN 三大優勢： 局部感受野、權重共享、空間降採樣，徹底克服傳統 FNN 參數爆炸與幾何破壞問題。
  3. 核心運算流程： 輸入影像 $\to$ 卷積層提取邊緣特徵 $\to$ ReLU 非線性化 $\to$ Pooling 降採樣 $\to$ 全連接層整合 $\to$ Softmax 輸出類別機率。
