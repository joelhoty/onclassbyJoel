📖 導言與全流程架構

在學術分享、課堂報告與專案推進中，「將長篇厚重的文件/文獻轉化為易懂、具備說服力的簡報」是每位研究者與學生的高頻關鍵任務。

本練習所採用的提示詞設計（Prompt Design），採用了精確的「二階段漏斗式架構」： 第一階段專注於「低認知負擔同儕摘要（Peer-Oriented Summary）」，第二階段轉譯為「10 頁、15 分鐘行動主張導向簡報大綱與生圖提示詞」。

🧠 一、核心概念剖析 (Core Concepts)

1. 認知負荷理論 (Cognitive Load Theory) 與「18 字法則」

聽眾的大腦無法同時處理「大量眼看文字」與「耳聽口述聲音」，這被稱為注意力分散效應（Split-Attention Effect）。 限制「每點 ≤ 18 字、每頁 3 點」，符合心理學米勒定律（Miller's Law）的 \(7 \pm 2\) 資訊組塊（Chunks）極限，強迫投影片回歸「視覺錨點」而非提詞機。

2. 主張－證據架構 (Assertion-Evidence Framework)

傳統簡報習慣使用「內容介紹」、「背景概述」等標籤式標題，聽眾無法瞬間掌握核心觀點。 主張式標題法要求標題必須是「一句完整的結論、論點或反直覺提問」，再以圖表與精煉要點作為證明證據。

3. 雙碼理論 (Dual-Coding Theory) 與生圖提示詞設計

根據 Paivio 雙碼理論，大腦分別以「語言代碼」與「圖像代碼」儲存記憶。當兩者同步啟動時，長期記憶留存率大幅提升。 提示詞中為每頁生成專屬 AI 影像生成提示詞（AI Image Generation Prompt），能精準將抽象邏輯視覺化。

4. 漸進式兩階段生成 (Two-Stage Progressive Generation)

避免一次性命令大語言模型直接輸出 10 頁簡報而造成「上下文注意力分散」與「事實幻覺」。 先進行高保真 500 字蒸餾，再進行分頁演繹，確保資訊保真度（Fidelity）。

🔍 二、原始提示詞診斷與全方位評析 (Prompt Diagnosis)

✅ 優點亮點 (Strengths)

  • 受眾鎖定高中同學：語氣自動調校為親切、生活化，去除論文官僚調性。
  • 邊界極度清晰：限制 500 字內、每點 ≤ 18 字，給予 LLM 嚴密的物理約束。
  • 主張式標題思維：禁用「介紹」、「內容」，逼出高張力觀點。
  • 首尾呼應：第 1 頁目標定調，最後 1 頁提供可執行下一步。
  • 防幻覺規範：嚴格保留原文觀點，不增補未提及數據。

⚠️ 潛在盲點 (Weaknesses)

  • 時間預算未切分：15 分鐘平均分配每頁 1.5 分鐘不切實際，核心頁與引言需要不同權重。
  • 生圖風格缺乏統一錨定：未指定生圖風格（如向量插畫、3D 等），容易產生視覺混亂。
  • 缺乏排版構圖指引：未提示版面佈局（如左右對比、三欄卡片、大數字強調）。
  • 口說缺乏情緒鉤子：僅要求一句口說，缺少課堂互動與問答破冰設計。

🚀 三、升級版二階段提示詞模版 (Upgraded Prompts)

以下為經過診斷強化後的完整實戰提示詞，可直接複製至 Gemini、Claude 或 ChatGPT 使用：

🔹 階段一：同儕導向高保真文摘提示詞

Prompt Template: Peer-Oriented Summary 
請閱讀我所提供的檔案內容，為【沒看過原文的高中同學】撰寫一份易懂且精確的課堂報告摘要。

【輸出架構規範】
1. 💡 核心亮點（3-5 點）：每點請以「粗體主張標題 + 1 句白話生活化解釋」呈現。
2. 🔑 關鍵名詞通俗解碼（2-3 個）：以高中生生活經驗做類比，說明該名詞的物理意義或核心原理。
3. 🎯 一句話 takeaways：用一句震撼或富啟發性的話總結全文價值。

【嚴格邊界限制】
- 總字數上限：嚴格控制在 450 ~ 500 字以內。
- 零幻覺原則：嚴格保留原文事實與論點，嚴禁加入原文未提及之數據、年代或推論。
- 語系與修辭：繁體中文（台灣習慣用詞，如：程式、軟體、資料、陣列，禁出現大陸語彙）。
- 語氣：親切、清晰、有熱忱的同儕分享語調。

🔹 階段二：10 頁高張力簡報大綱與風格一致性生圖提示詞

Prompt Template: 10-Slide Deck & Style-Consistent Image Prompts 
基於上述摘要與原文，請為我設計一份標準 10 頁、演講時長 15 分鐘的高中課堂分享簡報大綱。

【基本設定】
- 聽眾：未接觸過此題目的高中同班同學（需降低專業門檻，重視共鳴感）
- 場合：課堂專題報告（氣氛輕鬆、互動性強，非死板評審競賽）
- 視覺風格基調：【極簡扁平科技插畫風格 Minimalist Tech Vector Illustration, 雙色調藍青配色, 乾淨白色背景】，確保全套簡報生圖風格高度一致。

【每頁必須依序包含以下 6 項資訊】：
1. 頁碼與時間預算：標註「第 X 頁 / 建議演講時間：X 分鐘」。
2. 頁標題：嚴禁「介紹」、「背景」等名詞標籤；必須採用「反直覺提問」或「具體主張結論」。
3. 投影片重點（3 點）：每點嚴格不超過 18 字，採動詞開頭的簡明短句。
4. 建議版面配置（Layout Hint）：說明該頁適合之排版（例如：左右兩欄對照、大數據強調卡片、流程時間軸、滿版意境圖）。
5. 口說台詞導引（Speaker's Script）：2 句以內的高中生口語對話，包含引起共鳴的日常比喻或設問。
6. 影像生成提示詞（AI Image Prompt）：
   - 提供可直接複製至 Midjourney / DALL-E 3 / Bing 的英文 Prompt。
   - 結構規範：[Subject action], [Minimalist flat vector illustration style, blue and teal color palette], [clean white isolated background, 16:9 ratio, no text inside image].

【總體章節編排限制】
- 第 1 頁：明確破冰並點出「本演講能帶給同學什麼啟發」。
- 第 2~3 頁：痛點與現實問題引發共鳴。
- 第 4~7 頁：核心原理、技術拆解與實驗發現（深入淺出）。
- 第 8~9 頁：實際應用場景與未來想像。
- 第 10 頁：清晰可執行的「下一步行動指南（Call To Action）」與 Q&A 互動提問。
- 嚴禁捏造數據，全文繁體中文（生圖提示詞採英文以確保渲染品質）。

💻 四、自動化實作：大綱轉 Marp 簡報格式解析腳本

將 AI 產出的大綱文字，透過 Python 正則解析自動格式化為 Marp (Markdown Presentation) 格式，可直接在 VS Code 一鍵預覽並匯出成 PDF 或 PPTX。

Python: outline_to_marp.py 
# -*- coding: utf-8 -*-
"""
簡報大綱自動轉 Marp Markdown 工具
功能：將結構化的 AI 簡報大綱文字，自動解析並格式化為相容於 Marp 的簡報檔案。
支援功能：自動頁面分割 (---)、投影片要點排版、演講者備忘稿 (<!-- comment -->) 與生圖提示備忘。
"""

import os
import re

def convert_outline_to_marp(input_file_path: str, output_file_path: str):
    """
    讀取原始大綱並轉譯為 Marp 語法簡報
    """
    if not os.path.exists(input_file_path):
        print(f"[錯誤] 找不到輸入檔案: {input_file_path}")
        return

    with open(input_file_path, 'r', encoding='utf-8') as f:
        raw_content = f.read()

    # 定義 Marp 標頭檔 (Frontmatter)
    marp_header = """---
marp: true
theme: gaia
_class: lead
paginate: true
backgroundColor: #f8fafc
color: #1e293b
style: |
  section {
    font-family: 'Segoe UI', 'Noto Sans TC', sans-serif;
    font-size: 28px;
    padding: 40px 60px;
  }
  h1 {
    color: #1e40af;
    font-size: 42px;
    margin-bottom: 20px;
  }
  h2 {
    color: #2563eb;
    font-size: 34px;
  }
  footer {
    font-size: 14px;
    color: #94a3b8;
  }
---

"""

    slides = []
    # 根據「第 X 頁」切分章節
    slide_chunks = re.split(r'(?=第\s*\d+\s*頁)', raw_content)

    for chunk in slide_chunks:
        chunk = chunk.strip()
        if not chunk:
            continue

        lines = chunk.split('\n')
        slide_title = ""
        bullet_points = []
        speaker_note = ""
        image_prompt = ""

        for line in lines:
            line_str = line.strip()
            # 辨識標題
            if "頁標題" in line_str or line_str.startswith("###") or "第" in line_str and "頁" in line_str:
                clean_title = re.sub(r'^(第\s*\d+\s*頁|頁標題[:：]|###|\d+\.|\s)+', '', line_str).strip()
                if clean_title:
                    slide_title = clean_title
            # 辨識重點要點
            elif re.match(r'^[-*•\d\)]', line_str) and "口說" not in line_str and "圖像" not in line_str:
                clean_point = re.sub(r'^[-*•\d\.\)\s]+', '', line_str).strip()
                if clean_point:
                    bullet_points.append(clean_point)
            # 辨識口說台詞
            elif "口說" in line_str or "台詞" in line_str:
                speaker_note = re.sub(r'^(建議口說重點[:：]|口說台詞[:：]|\s)+', '', line_str).strip()
            # 辨識生圖提示詞
            elif "圖像" in line_str or "生圖" in line_str or "Prompt" in line_str:
                image_prompt = re.sub(r'^(適合搭配的圖像類型[:：]|影像生成提示詞[:：]|\s)+', '', line_str).strip()

        # 組裝單頁 Marp 投影片 Markdown
        slide_md = []
        if slide_title:
            slide_md.append(f"## {slide_title}\n")
        
        if bullet_points:
            for pt in bullet_points:
                slide_md.append(f"- {pt}")
            slide_md.append("")

        # 將生圖提示與口說重點放入演講者備忘稿 (Presenter Notes)
        notes_block = []
        if speaker_note:
            notes_block.append(f"🗣️ 口說重點：{speaker_note}")
        if image_prompt:
            notes_block.append(f"🎨 建議圖像/生圖Prompt：{image_prompt}")

        if notes_block:
            slide_md.append("<!--")
            slide_md.extend(notes_block)
            slide_md.append("-->\n")

        slides.append("\n".join(slide_md))

    # 合併所有投影片，中間以 '---' 隔開
    final_output = marp_header + "\n---\n\n".join(slides)

    with open(output_file_path, 'w', encoding='utf-8') as f:
        f.write(final_output)

    print(f"[成功] 已成功將簡報大綱轉換為 Marp 檔案：{output_file_path}")

if __name__ == "__main__":
    print("Marp 自動轉換模組已就緒。")

3. Marp 五大進階設計 Skills（排版黑魔法）

  1. 圖文分割背景（Split Backgrounds）：語法 ![bg right:40% 85%](image.png)，自動形成左文字、右概念圖的現代雜誌佈局。
  2. 單頁局部樣式覆蓋（<style scoped>）：在該頁宣告 <style scoped> section { background: #7f1d1d; } </style>，僅改變當前頁面色彩。
  3. 版面模式指令（Class Directives）：<!-- _class: lead --> 啟用首頁引導模式（文字置中放大）；<!-- _class: invert --> 切換反白對比。
  4. CSS Grid / Flexbox 雙欄卡片容器：透過原生 HTML <div class="grid-2"> 與 <div class="card">，實現雙欄論點對照或終端狀態卡。
  5. 雙螢幕演講者備忘錄（Presenter Notes）：口說與生圖提示詞放入 <!-- --> 註解，簡報時按鍵盤 P 鍵即開啟講者雙螢幕檢視模式。

🛠️ 六、後續如何完成高質感簡報的全流程指南 (End-to-End Workflow)

步驟一：大綱的人機協同微調 (Human Review)

  • 18 字極速檢核：每點嚴格控制在 18 字以內，剔除所有贅詞。
  • 設計三段情緒弧線（Emotional Arc）：第 1 頁破冰拋出日常痛點；第 5 頁揭曉核心原理解謎；第 10 頁呼籲行動。

步驟二：AI 影像生成與風格一致性掌控

  • 風格定錨句（Style Anchor）：全套圖片共用相同的結尾描述，如：Minimalist flat vector illustration style, blue and teal color palette, clean white background, 16:9 ratio。
  • 推薦免翻牆或易用工具： Recraft.ai（向量與圖示首選，可輸出 SVG/PNG）、 Microsoft Designer / DALL-E 3（完全免費、中文語意理解優異）、 Midjourney v6（使用 --sref 風格參考維持全套色調一致）。

步驟三：簡報排版工具選型與落地

途徑與工具 適用場景與特色 輸出與相容性
途徑 A：Gamma.app / Canva AI 極速排版。直接貼上大綱，AI 自動配置文字卡片與配圖，5 分鐘搞定。 可直接網頁投影，支援匯出 PPTX / PDF。

途徑 C：Microsoft PowerPoint / Google 簡報 適合套用校系既定母片、需要高度客製化動畫與排版者。 標準 .pptx，全球課堂相容度最高。
