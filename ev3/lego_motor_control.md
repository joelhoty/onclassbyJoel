## 📌 概述 (Overview)

本筆記完整拆解 LEGO MINDSTORMS EV3 兩大移動控制方塊——**Move Steering**（差速轉向）與 **Move Tank**（獨立雙馬達）——的底層原理、參數對照、選用時機，並以「前進 / 後退」「精準距離」「原地旋轉」「走正方形」四個實作範例分別示範兩種寫法；最後深入剖析「走正方形走不準」背後的六大誤差來源與開迴路／閉迴路控制的差異。

## 1️⃣ 核心概念剖析 (Core Concepts)

### 馬達控制三大參數
| 參數 | 範圍 | 說明 |
| :--- | :--- | :--- |
| **動力 (Power)** | −100 ~ 100 | 正數／負數決定方向，0 為停止 |
| **模式 (Mode)** | 秒 / 角度 / 圈數 | 秒＝時間；角度／圈數＝精準位移 |
| **停止方式 (Stop Action)** | 煞車 / 滑行 | 煞車立即鎖定；滑行自然減速 |

### Move Steering：差速轉向公式
Move Steering 用單一「轉向值 (−100~100)」同時換算左右馬達功率，其底層邏輯即為**差速控制**：轉向值越大，內外側輪功率差越大。轉向 = 100（或 −100）時，左右輪功率大小相等、方向相反，實現**原地旋轉**。

**幾何原理**：原地旋轉時，兩輪各自以「輪距 W 的一半」為半徑畫圓弧。車身轉 θ 度，輪子在地面滾動的弧長為：

```
弧長 = (W × π × θ) / 360
馬達圈數 = 弧長 / 輪胎周長 C
```

直線段換算則單純為 `圈數 = 邊長 L / 輪胎周長 C`，與輪距無關。

### Move Tank：獨立雙馬達控制
直接、獨立設定左（Power B）與右（Power C）馬達動力，不經任何換算。本質上 Move Steering 就是在內部把「轉向值」換算成左右動力後，呼叫與 Move Tank 相同的底層驅動邏輯——因此 **Move Tank 是更底層的原始控制，Move Steering 是它的便利包裝**。

### 兩者選用決策
- 若動作可用「單一轉向值」描述（直線、對稱弧線、原地旋轉）→ **Move Steering**（直覺、程式精簡）
- 若動作不對稱（如單輪擺動轉彎、只讓一輪反轉）→ **Move Tank**（唯一能表達任意左右動力組合）

## 2️⃣ 實作與應用範例 (Practical Examples)

| 應用 | 目標 | Move Steering | Move Tank |
| :--- | :--- | :--- | :--- |
| **時間控制** | 前進/後退各 5 秒 | 模式:秒\|轉向:0\|動力:±50\|秒數:5 | 模式:秒\|左:±50\|右:±50\|秒數:5 |
| **距離控制** | 前進/後退 100cm | 模式:圈數\|轉向:0\|動力:±50\|圈數:5.68 | 模式:圈數\|左:±50\|右:±50\|圈數:5.68 |
| **角度控制** | 原地右轉 90° | 模式:圈數\|轉向:100\|動力:40\|圈數:0.54 | 模式:圈數\|左:40\|右:-40\|圈數:0.54 |
| **綜合應用** | 走正方形（迴圈×4） | 前進 2.84 圈（轉向0/動力50）+ 轉彎 0.54 圈（轉向100/動力40） | 前進 2.84 圈（左右各50）+ 轉彎 0.54 圈（左40/右-40） |

> 換算依據：輪胎周長 17.6cm、輪距 12cm。距離 100cm → 100/17.6 ≈ 5.68 圈；旋轉 90° → (12×π×90/360)/17.6 ≈ 0.54 圈。

四個範例的動作都是「對稱動作」，因此兩種方塊可設定出完全等效的結果，差別僅在輸入方式；一旦動作變成不對稱，就只有 Move Tank 能直接做到。實務上兩種方塊也常在同一程式中混用。

## 3️⃣ 延伸思考與進階主題 (Extensions & Advanced Topics)

### 走正方形為何「看似簡單卻走不準」：六大誤差來源

| # | 誤差來源 | 成因 | 對策 |
| :-- | :--- | :--- | :--- |
| 1 | 輪胎周長測量誤差 | 直徑量測不準 + 輪胎受壓變形 | 直接量測滾動一圈的實際地面距離，取多次平均 |
| 2 | 輪距測量誤差 | W 量測不精準，直接影響轉角公式 | 用「原地轉 360° 應回到原朝向」反推真實有效輪距 |
| 3 | 轉彎打滑 (Slip) | 原地旋轉需克服側向摩擦力，是轉角誤差最大來源 | 降低轉彎動力；改用陀螺儀量測實際車身角度 |
| 4 | 開迴路、無回饋修正 | 只下達指令、不檢查結果 | 導入閉迴路：陀螺儀讀取實際角度決定何時停止 |
| 5 | 電壓下降造成雙馬達不對稱 | 電量下降 + 兩馬達耗損不同 | 啟用角度編碼器做速度閉迴路控制 |
| 6 | 累積誤差 (Cumulative Error) | 4 次動作的小誤差疊加放大 | 每完成一邊做一次歸零校正（色感應器 / 陀螺歸零） |

### 開迴路 vs 閉迴路
本文所有寫法本質上都是**開迴路控制**——只下指令、不驗證結果。相對地，黑色圓圈光感應器尋跡程式的「比例控制法 (P-Control)」持續讀取感應器並即時修正，屬於**閉迴路控制**，因此能長時間穩定運行而不累積誤差。

### 三種精度等級建議
1. **入門（開迴路）**：直接用圈數公式，簡單易懂但誤差隨圈數累積，適合教學示範。
2. **進階（陀螺儀閉迴路）**：轉彎改用「Switch + Loop：讀取角度 < 目標角度時持續轉動」，消除打滑造成的角度誤差。
3. **高階（陀螺儀 + 編碼器雙回饋）**：直線段用編碼器差值做即時速度校正（類似 P-Control），轉彎段用陀螺儀角度回饋，兩者搭配可讓正方形連續繞行數十圈仍幾乎不失準。
