👨‍🏫 生活科技老師的開場剖析 (Teacher's Introduction)

同學你好！看到你想運用 6 顆 LEGO SPIKE 馬達 來挑戰「仿生機械手臂（Bionic Robotic Arm）」的研究，老師非常讚賞你的雄心與選題！

在生活科技與工程領域中，「仿生學（Biomimetics）」並非只是拼裝出一隻長相類似手臂的外觀模型，而是深入探究自然界生物在力學、運動協調與結構演化上的機制（例如：前臂肌腱遠距索驅、多關節欠驅動自適應抓握、連桿過死點自鎖、無關節柔性連續體等），並透過機電整合與程式邏輯重現這些功能。

💡 關鍵硬體限制與戰略優勢分析：

  • 連接埠飽和（Port Constraints）：標準 LEGO SPIKE Prime 集線器恰好只有 6 個連接埠（Port A ~ F）。當 6 顆馬達全插滿時，便無法外接超音波或顏色感測器。
  • 馬達即感測器（Motors as Sensors）：SPIKE 的角度馬達內建高精準絕對位置編碼器（Absolute Position Encoder），並能即時反饋旋轉角度、轉速與馬達負載扭矩（Stall/Duty Cycle）；集線器本體更內建 6 軸陀螺儀/加速度計。充分利用編碼器反饋，即可做到高水準的閉迴路控制！
  • 力矩與結構剛性挑戰：機械臂伸長時力臂放大（$\tau = F \times d$），樂高塑膠件易產生形變。如何運用肌腱索驅（Tendon-driven）將重量後置於基座，是成功關鍵。

🔬 五大仿生機械手臂研究題目深度規劃

題目 1【肌腱傳動型仿生人手】基於索驅（Tendon-driven）與欠驅動（Underactuated）之五指自適應靈巧手研究

🌿 仿生原型剖析：人類手指內部沒有肌肉，主要屈指肌群全在前臂，透過腕隧道的屈指肌腱拉動手指各關節，伸直時靠韌帶彈性回彈。藉此機制，手掌能保持極度輕巧敏捷。

⚙️ 6 顆馬達分配方案：

  • 馬達 A (Wrist)：手腕俯仰/旋轉，調整整體抓握空間姿態。
  • 馬達 B (Thumb Opposition)：大拇指對掌旋轉軸（拇指能轉至掌心面對其餘四指，是靈長類抓握關鍵）。
  • 馬達 C (Thumb Flexion)：大拇指獨立屈伸抓握。
  • 馬達 D (Index Finger)：食指獨立屈伸（精細對捏 Pinch）。
  • 馬達 E (Middle Finger)：中指獨立屈伸（強力抓握主軸）。
  • 馬達 F (Ring & Pinky)：無名指與小指連動驅動（透過差動滑輪欠驅動機構，自動緊密包覆不規則物體）。
🎯 科學探究核心變因：探究肌腱走線阻力對拉力的耗損，以及自適應外包絡對圓球、圓柱、方塊與易碎紙杯的「包覆抓握接觸面積」與「最大防滑抗拉脫力（N）」。

題目 2【擬人化 6 自由度 (6-DOF) 機械臂】逆向運動學（IK）空間軌跡追蹤與重力補償研究

🌿 仿生原型剖析：完整重現人體上肢三大複合關節：胸肩關節（Ball-and-Socket 3-DOF）+ 肘關節（Hinge 1-DOF）+ 腕關節（Condyloid 2-DOF），使末端在笛卡爾三維空間具備完整的 6 軸運動能力。

⚙️ 6 顆馬達分配方案：

  • 馬達 A (Joint 1 - Base Yaw)：基座水平旋轉（肩部水平擺向）。
  • 馬達 B (Joint 2 - Shoulder Pitch)：肩部大臂抬升俯仰（承受最大重力力矩，需雙層蝸輪減速）。
  • 馬達 C (Joint 3 - Arm Roll)：大臂軸向旋轉（模擬肱骨自轉）。
  • 馬達 D (Joint 4 - Elbow Pitch)：肘部屈伸。
  • 馬達 E (Joint 5 - Wrist Pitch)：手腕俯仰。
  • 馬達 F (Joint 6 - Wrist Roll / End Gripper)：手腕翻轉或末端開合夾爪。
🎯 科學探究核心變因：探究「橡皮筋張力平衡 / 配重塊平衡機構」對肩關節馬達發熱與堵轉電流的改善幅度，並驗證末端點執行直線插補運動時的空間軌跡偏差值（mm）。

題目 3【主從同步遙控與雙向擬態力回饋仿生臂】利用 SPIKE 馬達編碼器與阻抗負載檢測之遠端遙操作系統

🌿 仿生原型剖析：模仿人類神經系統的「本體感覺（Proprioception）」與「觸覺受器回饋」。操作者透過穿戴式裝置操作時，遠端手臂若碰觸障礙物，阻力能即刻反傳給操作端。

⚙️ 6 顆馬達分配方案（單 Hub 3+3 主從模式）：

  • 主控端（Master 外骨骼穿戴輸入）：馬達 A（手肘輸入）、馬達 B（手腕輸入）、馬達 C（握力輸入）。
  • 受控端（Slave 仿生機械手臂執行）：馬達 D（手肘追隨）、馬達 E（手腕追隨）、馬達 F（夾爪抓取）。
🎯 科學探究核心變因：利用受控端馬達遇到阻力時的電流負載與轉速驟降變化，透過程式即時對主控端馬達施加反向力矩，測試操作者對海綿、木塊、硬幣等不同剛性物體的「遠端觸覺感知辨識率」。

題目 4【仿象鼻/章魚觸手之索驅連續體手臂】柔性脊柱曲率變形與空間避障抓取研究

🌿 仿生原型剖析：象鼻與章魚觸手屬於生物學上的「肌肉水骨骼（Muscular Hydrostat）」，全段無剛性關節鉸鏈，依靠無數縱向與環向肌肉纖維拉動，達成平滑三維彎曲與纏繞。

⚙️ 6 顆馬達分配方案（雙節連續體 2 Segments × 3 Cables = 6 Motors）：

  • 近端節段（Proximal Segment 1）：馬達 A、B、C 牽引 3 根呈 $120^\circ$ 佈局的拉索，控制基部空間彎曲方向與角度。
  • 遠端節段（Distal Segment 2）：馬達 D、E、F 牽引穿過近端節段的另外 3 根拉索，獨立控制前端梢部的細緻曲率。
🎯 科學探究核心變因：探究索驅捲線筒半徑與中心彈性脊樑剛性對彎曲曲率的非線性影響，以及在狹窄複雜 S 型障礙管道中穿透與纏繞圓柱物體的成功率。

題目 5【仿猛禽利爪高速俯衝捕捉與被動自鎖減震臂】死點連桿自鎖與著陸衝擊吸收研究

🌿 仿生原型剖析：老鷹與猛禽在樹枝棲息或高速撲擊獵物時，依靠腳部「被動屈指肌腱鎖定（Digital Flexor Tendon Lock Mechanism）」——接觸時利用衝擊力自然卡入自鎖狀態，完全不需要肌肉持續消耗能量；腿部懸吊結構亦能吸收劇烈撞擊。

⚙️ 6 顆馬達分配方案：

  • 馬達 A (Shoulder Extension)：大臂高速下壓伸展撲擊。
  • 馬達 B (Forearm Deployment)：前臂協同展開。
  • 馬達 C (Wrist Pitch & Angle)：爪部俯衝抓取動態角度補償。
  • 馬達 D (Front Claw Left)：前左仿生爪（配備過死點自鎖四連桿）。
  • 馬達 E (Front Claw Right)：前右仿生爪。
  • 馬達 F (Rear Opposing Talon)：後側對向猛禽大爪（形成三點包絡抓鎖）。
🎯 科學探究核心變因：探究連桿超越死點（Over-center Toggle）自鎖的角度臨界值，測試在馬達斷電（零功耗）狀態下抓住獵物的最大抗拉脫承重能力（g）。

"""
LEGO SPIKE Prime 仿生機械手臂 - 肌腱驅動自適應抓握控制程式
適用題目：題目一（肌腱傳動欠驅動靈巧手）
核心邏輯：利用馬達負載檢測與編碼器回饋，達到自適應輕柔抓持（避免夾碎雞蛋/紙杯）
"""

import hub
import utime

# ================= 1. 硬體連接埠常數定義 =================
# 6 顆馬達全配置 (滿載 Port A~F)
PORT_WRIST       = hub.port.A  # 手腕俯仰
PORT_THUMB_OPP   = hub.port.B  # 拇指對掌
PORT_THUMB_FLEX  = hub.port.C  # 拇指屈伸
PORT_INDEX       = hub.port.D  # 食指肌腱
PORT_MIDDLE      = hub.port.E  # 中指肌腱
PORT_RING_PINKY  = hub.port.F  # 無名指與小指連動肌腱

# 抓握靈敏度參數
TOUCH_LOAD_THRESHOLD = 35    # 觸碰負載閾值 (Duty cycle 百分比 0-100)
MAX_GRIP_DEGREES     = 360   # 各指最大收線安全行程 (度)
APPROACH_SPEED       = 25    # 接觸前進速度 (百分比，不宜過快)
HOLD_POWER           = 12    # 夾住物體後維持接觸之輕柔保持力

# ================= 2. 輔助函式定義 =================
def init_motor(port_obj, name="Motor"):
    """檢查並取得馬達物件"""
    motor = port_obj.motor
    if motor is None:
        print("警告: 連接埠未檢測到馬達 ->", name)
    return motor

def adaptive_single_finger_grip(motor, name="Finger"):
    """
    單指自適應閉合控制核心演算法：
    以低速牽引肌腱，當檢測到負載超過閾值（接觸物體）即刻煞車並切換為低功率保壓。
    """
    if motor is None:
        return
    
    # 紀錄起始絕對編碼器角度
    start_pos = motor.get()[1]
    print(f"[{name}] 開始閉合抓握... 起始角度: {start_pos}")
    
    # 以正向低速平穩轉動拉動肌腱
    motor.pwm(APPROACH_SPEED)
    
    grasped = False
    start_time = utime.ticks_ms()
    
    while True:
        pos_data = motor.get()
        current_pos = pos_data[1]
        current_speed = abs(pos_data[0])
        
        # 計算位移量
        travel = abs(current_pos - start_pos)
        
        # 條件 A: 遇到障礙物（速度驟降至近乎零且已經過初期啟動時間）
        elapsed = utime.ticks_diff(utime.ticks_ms(), start_time)
        if elapsed > 150 and current_speed < 5:
            print(f"[{name}] 檢測到物體接觸！位移量: {travel}°，切換至微力保壓。")
            # 切換至極低微功率保持住，避免馬達高扭矩燒毀或壓壞物體
            motor.pwm(HOLD_POWER)
            grasped = True
            break
            
        # 條件 B: 達到極限行程（空抓，未碰到物體）
        if travel >= MAX_GRIP_DEGREES:
            print(f"[{name}] 達到最大行程極限，停止收線。")
            motor.brake()
            break
            
        utime.sleep_ms(10)
        
    return grasped

def release_all_fingers(motors):
    """釋放所有肌腱，利用橡皮筋/回位彈簧張開手指"""
    print("釋放所有手指...")
    for m in motors:
        if m:
            m.pwm(-APPROACH_SPEED)  # 反轉放線
    utime.sleep_ms(800)
    for m in motors:
        if m:
            m.float()  # 放鬆狀態，完全依靠彈簧恢復初始張開姿態
    print("手掌已完全張開！")

# ================= 3. 主程序示範 =================
def main():
    print("=== LEGO SPIKE 仿生手控制系統啟動 ===")
    
    # 初始化 6 顆馬達
    m_wrist      = init_motor(PORT_WRIST, "Wrist")
    m_thumb_opp  = init_motor(PORT_THUMB_OPP, "Thumb Opposition")
    m_thumb_flex = init_motor(PORT_THUMB_FLEX, "Thumb Flex")
    m_index      = init_motor(PORT_INDEX, "Index")
    m_middle     = init_motor(PORT_MIDDLE, "Middle")
    m_ring_pinky = init_motor(PORT_RING_PINKY, "Ring & Pinky")
    
    all_finger_motors = [m_thumb_flex, m_index, m_middle, m_ring_pinky]
    
    # 步驟 1: 大拇指轉向對掌姿態 (Opposition)
    if m_thumb_opp:
        print("步驟 1: 大拇指旋轉對掌面向掌心...")
        m_thumb_opp.run_for_degrees(90, 30)
        utime.sleep_ms(500)
        
    # 步驟 2: 各手指同時執行自適應抓握
    print("步驟 2: 執行自適應包覆抓握...")
    for f_motor in all_finger_motors:
        adaptive_single_finger_grip(f_motor)
        
    print(">> 抓握完成！維持抓取狀態 3 秒...")
    utime.sleep_ms(3000)
    
    # 步驟 3: 釋放物品並復位
    print("步驟 3: 釋放目標物...")
    release_all_fingers(all_finger_motors)
    
    if m_thumb_opp:
        m_thumb_opp.run_for_degrees(-90, 30)  # 大拇指復位
        
    print("=== 專題示範流程結束 ===")

if __name__ == "__main__":
    main()
