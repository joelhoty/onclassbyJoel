LEGO Mindstorms EV3 雙層巢狀切換 (Nested Switch) 距離感測邏輯與應用筆記

📅 2026-09-14
雙層巢狀 Switch 超音波/紅外線感測器 動態音頻對映算術 負斜率線性演算法 雙曲倒數演算法 汽車倒車雷達人因工程

本集課程內容摘要：

  • 兩大視覺化圖檔對比：對比基礎定頻程式 (2swtcih.jpg) 與變數調頻實作程式 (cm2hz.jpg) 之資料線接法與 Math Block 設定。
  • 實作程式正比盲點剖析：剖析 cm2hz.jpg 中 $\text{Freq} = \text{dis} + 440$ 與 $\text{Freq} = \text{dis} \times 300$ 之正比算數缺陷（距離越近聲音反而越低沉）。
  • 「距離越短音頻越高」算術對映推導：
    • 負斜率線性公式：$\text{Freq} = 968 - 17.6 \times d$ （實現 $5\text{cm}\sim30\text{cm}$ 區間發出 $880\text{Hz}\sim440\text{Hz}$ 平滑調頻）。
    • 雙曲倒數公式：$\text{Freq} = \frac{2000}{d} + 300$ （實現 $d \le 5\text{cm}$ 急促衝高音頻至 $2300\text{Hz}$）。
  • 虛擬碼與流程圖演進：加入音頻邊界保護 (Pitch Clamping) 與發音時間響應優化之結構化虛擬碼與動態 Mermaid 流程圖。

LEGO Mindstorms EV3 硬體架構與第一個輸出積木 (聲音 Sound)

📅 2026-09-07
EV3 硬體概論 聲音積木 (Sound) The Final Countdown 音樂排譜 Block Builder (My Block) 距離反饋蜂鳴器專題 MP3 音訊播放解法

本集課程內容摘要：

  • EV3 主機硬體介紹：ARM9 處理器規格、178x128 LCD 螢幕、輸入埠 (1~4)、輸出埠 (A~D)、USB/SD卡槽及按鈕功能詳細解析。
  • 聲音積木 (Sound Block) 4 大模式：Play File、Play Tone、Play Note 與 Stop 模式之操作與應用。
  • 播放控制 (Play Type) 參數：比較 Wait for Completion (阻塞式) 與 Play Once / Repeat (非阻塞式/背景播放) 對馬達與音效併行控制的影響。
  • 實作樂曲設計：Europe 搖滾名曲《The Final Countdown》前奏合成器旋律之音符 (Note) 與節拍時間換算排譜明細表。
  • 自訂積木 (Block Builder / My Block)：如何將長串音樂音符封裝為具備 Volume 與 Speed 輸入參數的模組化青綠色自訂積木。
  • 專題實作 — 距離反饋蜂鳴器：結合超音波感測器 (Ultrasonic Sensor) 量測距離，透過動態數據對映公式與 Switch 多階分段警報音效，模擬車輛倒車雷達與 Python ev3dev 演算法。
  • 延伸專題研究：解析 EV3 官方無法直解 MP3 檔的原因（CPU 軟解開銷與 16MB Flash 容量限制），並提供 WAV 音訊轉碼與第三方系統 ev3dev + Python + mpg123 的播放解法。
