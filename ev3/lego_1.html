黑色圓圈光感應器尋跡程式設計

完整剖析沿邊尋跡原理、幾何邏輯判斷流程圖、積木模組配置、MicroPython 實作與高階 PID 移動優化技巧

1 核心觀念：為什麼圓圈尋跡要「沿邊 (Edge Following)」？

在 LEGO EV3 / SPIKE 的尋跡任務中，機器人裝設了光感應器 / 顏色感應器 (Color Sensor)。感應器會向地面發射紅光並接收「反射光強度 (Reflected Light Intensity)」（數值範圍 0% ~ 100%）。

⚠️ 常見誤解與關鍵原理：

機器人如果「直接走在黑線正中央」，當感應器偏離黑線時，機器人無法判斷自己是偏向左邊還是偏向右邊。因此，機器人必須沿著「黑白邊界 (Black-White Edge)」前進！當看到太黑就往白處轉，看到太白就往黑處轉，就能順暢沿著線條邊緣修正前進。

圓圈軌跡 (Circular Track) 的幾何特性

繞圓圈行駛時，軌跡具有恆定的曲率。我們推薦採用「沿黑線外邊界 (Outer Edge)」或「沿黑線內邊界 (Inner Edge)」：

  • 外邊界尋跡 (推薦)： 當軌跡向內彎曲時，機器人感應器看到白色會自動向內轉，看到黑色會向外甩，對於大半徑圓圈極為穩定。
  • 門檻值 (Threshold) 計算：
    在比賽或練習前，需先測量地面的反射光數值：
    Threshold = (白地反射光強度 + 黑線反射光強度) / 2
    例如：白色地面讀值 70%，黑色線條讀值 10%，則閾值設定為 (70 + 10) / 2 = 40%。

3 程式碼 虛擬碼 (Pseudo Code) 與 MicroPython

我們提供兩種常見的尋跡邏輯：適合初學者的「兩態切換法 (On-Off / Switch)」與適合高階流暢行駛的「比例控制法 (P-Controller)」。

方法一：兩態雙區間切換法 (On-Off / Switch Control)

簡單直觀，透過判斷當前反射光是否低於門檻值（壓在黑線上），來交替給予馬達不同的功率速差：

// --- 1. 初始化與閾值設定 ---
SET Threshold = (White_Value + Black_Value) / 2   // 例如: (70 + 10) / 2 = 40
SET BaseSpeed = 30                                 // 基礎前進速度
SET TurnSpeed = 10                                 // 轉向減速功率

// --- 2. 主尋跡迴圈 ---
LOOP Forever:
    READ LightSensor ON Port 3 AS LightValue

    IF LightValue < Threshold THEN
        // 壓在黑色線上：感應器偏向黑線內部 -> 需要往外邊界(白色)轉
        SetMotorSpeed(Motor_B, BaseSpeed)    // 外側馬達快
        SetMotorSpeed(Motor_C, TurnSpeed)    // 內側馬達慢
    ELSE
        // 壓在白色地面：感應器偏離黑線 -> 需要往內邊界(黑色)轉
        SetMotorSpeed(Motor_B, TurnSpeed)    // 外側馬達慢
        SetMotorSpeed(Motor_C, BaseSpeed)    // 內側馬達快
    END IF
END LOOP

方法二：比例控制法 (P-Control Line Follower) - 圓圈平滑流暢首選

根據偏離門檻值的程度（誤差 Error）動態計算轉向修正量（Turn），能極大幅度減少在圓圈上行駛時的蛇行抖動：

// --- 1. 初始化參數 ---
SET TargetValue = 40     // 目標黑白邊界反射光強度
SET Kp = 0.8             // 比例增益常數 (Proportional Gain)
SET BasePower = 35        // 馬達巡航基準功率

// --- 2. 主尋跡迴圈 ---
LOOP Forever:
    READ LightSensor ON Port 3 AS CurrentLight

    // 計算當前與理想邊界的偏差量
    SET Error = CurrentLight - TargetValue
    
    // 計算轉向修正量 (Steering Adjustment)
    SET Turn = Error * Kp

    // 動態設定左右馬達功率 (Assuming B=Left, C=Right)
    SetMotorPower(Motor_B, BasePower + Turn)
    SetMotorPower(Motor_C, BasePower - Turn)
END LOOP

🐍 LEGO SPIKE Prime MicroPython 實作程式碼 (含詳細註解)

若您使用的是 LEGO Education SPIKE Prime 機器人，可以直接採用以下 MicroPython 程式碼進行實作：

1. 兩態切換法 MicroPython (On-Off Control)

# =========================================================
# LEGO SPIKE Prime MicroPython - 兩態切換圓圈尋跡程式
# =========================================================
from spike import PrimeHub, ColorSensor, MotorPair, Port
import time

# --- 1. 硬體物件初始化 ---
# 建立 PrimeHub 中央控制器物件
hub = PrimeHub()

# 初始化顏色感應器 (假設接在 Port E)
color_sensor = ColorSensor(Port.E)

# 初始化雙輪驅動馬達對 (左輪接 Port A，右輪接 Port B)
wheels = MotorPair(Port.A, Port.B)

# --- 2. 設定反射光門檻值 (Threshold) 與馬達功率 ---
BLACK_LIGHT = 10   # 實測黑線反射光強度 (%)
WHITE_LIGHT = 70   # 實測白地反射光強度 (%)

# 計算黑白邊界理想門檻值 = (10 + 70) / 2 = 40%
THRESHOLD = (BLACK_LIGHT + WHITE_LIGHT) / 2

FAST_SPEED = 30    # 外側加速車輪功率 (%)
SLOW_SPEED = 10    # 內側轉向減速車輪功率 (%)

# --- 3. 無限尋跡主迴圈 ---
while True:
    # 讀取感應器傳回之反射光強度 (數值介於 0 到 100 之間)
    light_value = color_sensor.get_reflected_light()
    
    if light_value < THRESHOLD:
        # 【情況 A】：光線低於門檻值 -> 機器人壓在黑線上 (偏向圓內)
        # 動作：左輪輸出 30%、右輪輸出 10% -> 機器人向右(往白色外邊界)切出
        wheels.start_tank(FAST_SPEED, SLOW_SPEED)
    else:
        # 【情況 B】：光線高於門檻值 -> 機器人偏離到白地上 (偏向圓外)
        # 動作：左輪輸出 10%、右輪輸出 30% -> 機器人向左(往黑色圓內)切入
        wheels.start_tank(SLOW_SPEED, FAST_SPEED)

2. 比例控制法 MicroPython (P-Control Line Follower - 繞圓平滑首選)

# =========================================================
# LEGO SPIKE Prime MicroPython - 比例控制 (P-Control) 尋跡程式
# =========================================================
from spike import PrimeHub, ColorSensor, MotorPair, Port

# --- 1. 硬體物件初始化 ---
hub = PrimeHub()
color_sensor = ColorSensor(Port.E)  # 光感應器連接至 Port E
wheels = MotorPair(Port.A, Port.B)  # 左馬達 Port A，右馬達 Port B

# --- 2. P 控制器核心參數設定 ---
TARGET_LIGHT = 40.0   # 目標黑白邊界反射光強度 (Threshold)
KP = 0.8              # 比例增益常數 (Proportional Gain)
BASE_SPEED = 35       # 車輪巡航基準速度 (%)

# --- 3. 比例控制無限迴圈 ---
while True:
    # 步驟 (1)：即時讀取地面光感應器反射值
    current_light = color_sensor.get_reflected_light()
    
    # 步驟 (2)：計算當前讀值與目標邊值的偏差量 (Error)
    # 當偏白時 Error > 0；偏黑時 Error < 0
    error = current_light - TARGET_LIGHT
    
    # 步驟 (3)：計算動態轉向修正量 (Turn = Error * Kp)
    turn = error * KP
    
    # 步驟 (4)：計算左右車輪個自應輸出的馬達功率
    # 壓白時 (turn > 0): 左輪減速、右輪加速 -> 車頭左轉切回黑線
    # 壓黑時 (turn < 0): Left Power 增大、Right Power 減小 -> 車頭右轉甩出黑線
    left_power = int(BASE_SPEED + turn)
    right_power = int(BASE_SPEED - turn)
    
    # 步驟 (5)：限制馬達功率在安全數值範圍 [-100, 100] 以內，避免馬達爆速溢位
    left_power = max(-100, min(100, left_power))
    right_power = max(-100, min(100, right_power))
    
    # 步驟 (6)：將計算好的功率即時傳送給 Tank 雙驅馬達運轉
    wheels.start_tank(left_power, right_power)

5 圓圈軌跡實作調校與注意事項

  1. 調整圓圈半徑相對應的「馬達速差」：
    如果黑色圓圈的半徑較小（彎度很急），若左右馬達功率差異不夠大（例如 30% 對 25%），機器人會來不及轉彎而脫軌甩出去。小圓圈建議增大人為速差（例如 35% 對 5%）。
  2. 光感應器離地高度與位置：
    光感應器最佳離地距離約為 0.8 ~ 1.5 cm。過高容易受環境燈光干擾，過低可能卡到地面。此外，感應器安裝在輪軸前方靠近車頭位置，反應會最敏捷。
  3. 外圈尋跡 vs 內圈尋跡選擇：
    圓圈順時針行駛時，建議跟隨「外側邊界」。因圓圈弧度自然向內彎，外側邊界給予機器人較寬廣的修正緩衝空間。
  4. 比例控制 (P-Control) 的 \(K_p\) 調校口訣：
    • 若機器人反應遲鈍、轉不過圓圈：增大 \(K_p\)（如從 0.5 調至 0.8 或 1.0）。
    • 若機器人劇烈左右搖晃、抖動嚴重：減小 \(K_p\)（如從 0.8 調降至 0.4）。

6 尋跡程式的實際應用延伸與高效率移動優化

一、 尋跡技術的產業實際應用 (Real-World Applications)

在現實工業與科技領域中，光電尋跡原理被廣泛應用於自動化與無人化設備中：

智慧倉儲

1. AGV 無人搬運車 (Automated Guided Vehicles)

在亞馬遜 (Amazon) 倉儲或台積電晶圓廠中，AGV 機器人沿著地面鋪設的光學色帶或磁性軌跡行駛，實現 24 小時無人化貨物搬運與精密物料派送。

自動駕駛

2. 車道保持輔助系統 (Lane Keeping Assist, LKA)

現代智慧汽車（如 Tesla、ADAS 系統）利用影像感測器辨識道路兩側的白線/黃線，原理正是透過邊界偏離演算法進行微幅轉向修正，防止車輛偏離車道。

工業巡檢

3. 軌道與巡檢機器人

高壓電廠、變電所與地下管道的自動巡檢機器人，沿著特定路徑標示線巡邏，即時檢測設備異常並傳回影像，保障作業安全。

機器人競賽

4. 競速尋跡與迷宮探索 (Line Maze Solving)

在 WRO (世界機器人奧林匹克) 或 FLL 競賽中，機器人需結合「節點辨識 (Intersection Detection)」與「路徑記憶演算法 (如左手法則、DFS)」，在複雜網格地圖中自動尋找最短路徑。

二、 程式演算法：如何讓機器人移動更高效、速度更快？

單純的「兩態切換」會導致機器人劇烈左右抖動（蛇行）並消耗大量馬達電力。要讓機器人跑得更快、軌跡更平滑、時間更短，可以採用以下四項高階程式優化技巧：

🚀 1. 升級為完整 PID 控制器 (Full PID Controller - P + I + D)

只用 P (比例) 仍可能產生些微震盪，加入 I (積分 Integral) 與 D (微分 Derivative) 能達到極致平滑：

  • P (Proportional 比例項)： 修正當前偏差。P_turn = Error * Kp
  • I (Integral 積分項)： 累積微小長期偏差，消除機械構造左右不對稱的偏向。Integral = Integral + Error
  • D (Derivative 微分項)： 預測偏差的變化率（相當於「煞車阻尼」），有效抑制過衝 (Overshoot) 與急甩震盪！D_turn = (Error - Last_Error) * Kd
🏎️ 2. 動態車速自適應控制 (Dynamic Speed Ramp / Cornering Speed)

固定速度會限制直線表現（直線太慢、彎道太快甩尾）。程式可加入「直線加速、急灣減速」的智慧邏輯：

// 根據偏差大小 Error 動態計算基準車速 (當偏差越小表示在直線，速度升至最大)
SET DynamicSpeed = MaxSpeed - (abs(Error) * SpeedScale)
SetMotorPower(LeftMotor, DynamicSpeed + Turn)
SetMotorPower(RightMotor, DynamicSpeed - Turn)
  1. 3. 雙光感應器跨線尋跡 (Dual Sensor Straddling)：
    將感應器數量增加為 2 個（跨騎在黑線左右兩側的白區）：
    • 兩感應器皆看到白色： 代表黑線完美位於兩感應器中央，馬達 100% 全速衝刺！
    • 左感應器壓黑： 代表車頭偏右，左輪減速向左修正。
    • 兩感應器皆壓黑： 偵測到交叉路口 (Crossroad) 或橫向停靠線，可執行精準停靠或轉向邏輯。
  2. 4. 高頻採樣與閉迴路馬達控制 (Encoder Velocity Feedback)：
    在 Python 或 LabVIEW 中儘量減少 sleep() 延遲時間，拉高採樣頻率（100Hz 以上）。同時啟用 EV3/SPIKE 馬達內建的角度編碼器 (Encoder) 轉速閉迴路控制，即使電池電量下降，也能確保左右馬達輸出精確無誤的實際轉速。
