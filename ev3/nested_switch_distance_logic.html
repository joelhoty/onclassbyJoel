實作程式 (cm2hz.jpg) 積木架構與數據線接法拆解：

  1. 感測器讀取與變數寫入 (Variable Store)：
    • 在進入 Switch 前，黃色感測器積木（Port 1 距離 Cm）讀取距離數值，透過資料傳輸線注入紅色變數積木（Variable 寫入模式 #），變數名稱命名為 dis。
  2. 外層 Switch False 分支 ($d \le 5\text{ cm}$)：
    • 讀取變數 dis，經由 Math 積木（乘法模式 $\times$）與常數 $300$ 相乘，公式為： $$\text{Frequency} = \text{dis} \times 300$$
    • 計算結果直接傳入 Sound 積木的頻率（Hz）輸入接腳。
  3. 內層 Switch True 分支 ($5\text{ cm} < d \le 30\text{ cm}$)：
    • 讀取變數 dis，經由 Math 積木（加法模式 $+$）與常數 $440$ 相加，公式為： $$\text{Frequency} = \text{dis} + 440$$
    • 計算結果傳入 Sound 積木的頻率（Hz）接腳。

⚠️ 2. 實作程式 (cm2hz.jpg) 的正比痛點與盲點剖析

❌ 盲點分析：直覺認知與正比運算的矛盾 (Psychacoustic Mismatch)
在 cm2hz.jpg 的算術公式中：
  • 內層區段：$\text{Freq} = \text{dis} + 440$。當距離從 $30\text{ cm}$ 靠近至 $6\text{ cm}$ 時，頻率由 $470\text{ Hz}$ 降低至 $446\text{ Hz}$。
  • 外層區段：$\text{Freq} = \text{dis} \times 300$。當距離從 $5\text{ cm}$ 靠近至 $1\text{ cm}$ 時，頻率由 $1500\text{ Hz}$ 劇降至 $300\text{ Hz}$。
問題所在：兩公式皆為正比關係 (Directly Proportional)！當物體越靠近車尾或障礙物時，發出的音頻反而越來越低沉，這與人類直覺（越近警報越急促高亢）完全相反！

🎯 3. 「距離越短，音頻越高」核心演算法推導 (Frequency Mapping Algorithms)

為符合倒車雷達與防撞警報的人因工程設計，我們必須建立距離 $d$ 與音頻 $f$ 的負斜率 / 反比映射關係。

演算法 A：負斜率線性映射 (Negative Slope Linear Mapping)

設定目標距離範圍 $[d_{\text{min}}, d_{\text{max}}]$ 對應至頻率範圍 $[f_{\text{high}}, f_{\text{low}}]$。一般通用數學公式為：

$$\text{Frequency}(d) = f_{\text{high}} - \left( \frac{f_{\text{high}} - f_{\text{low}}}{d_{\text{max}} - d_{\text{min}}} \right) \cdot (d - d_{\text{min}})$$
實作數值推導（以 $5\text{ cm} < d \le 30\text{ cm}$ 區間為例）：
目標：當 $d = 30\text{ cm}$ 時，頻率為 $440\text{ Hz}$ (低音)；當 $d = 5\text{ cm}$ 時，頻率提升至 $880\text{ Hz}$ (高音)。
$$\text{Frequency}(d) = 880 - \left( \frac{880 - 440}{30 - 5} \right) \times (d - 5) = 880 - 17.6 \times (d - 5) = \mathbf{968 - 17.6 \times d}$$
LEGO EV3 積木設定步驟：
  1. 使用 Advanced Math 積木（高級數學公式介面）。
  2. 公式填入：968 - (17.6 * a)，其中 a 輸入端連接變數 dis。
  3. 將輸出結果接入 Sound 積木的 Hz 埠。

演算法 B：雙曲倒數非線性映射 (Reciprocal Hyperbolic Mapping)

若希望在極近距離時頻率呈指數級攀升（呈現極度急促感），可採用雙曲倒數函數：

$$\text{Frequency}(d) = \frac{K}{d} + f_{\text{base}}$$
實作數值推導（設定 $K = 2000, f_{\text{base}} = 300$）：
  • 當 $d = 30\text{ cm}$ 時：$f(30) = \frac{2000}{30} + 300 = \mathbf{367\text{ Hz}}$ (低音提示)
  • 當 $d = 10\text{ cm}$ 時：$f(10) = \frac{2000}{10} + 300 = \mathbf{500\text{ Hz}}$ (中音警戒)
  • 當 $d = 5\text{ cm}$ 時：$f(5) = \frac{2000}{5} + 300 = \mathbf{700\text{ Hz}}$ (高音警報)
  • 當 $d = 2\text{ cm}$ 時：$f(2) = \frac{2000}{2} + 300 = \mathbf{1300\text{ Hz}}$ (極高音緊急煞停)

💻 4. 優化後之虛擬碼與流程圖 (Improved Pseudo Code)

優化演算法 Python 風格虛擬碼

FUNCTION Main():
    sensor_port = 1
    
    WHILE True:  # Infinite Loop 01
        # 1. 讀取距離並存入變數 dis
        dis = ReadDistanceSensor(port=sensor_port)
        
        IF dis > 5:
            IF dis <= 30:
                # 2. 5cm < dis <= 30cm: 負斜率線性反比演算法
                # 距離越小(靠近5cm)，發出頻率越高(靠近880Hz)
                calc_freq = 968 - (17.6 * dis)
                
                # 限制頻率安全邊界 (Pitch Clamping)
                calc_freq = Clamp(calc_freq, min_val=440, max_val=880)
                
                PlayTone(frequency=calc_freq, duration=0.2, volume=100, wait=TRUE)
            ELSE:
                # dis > 30cm: 安全區靜音
                Pass
        ELSE:
            # 3. dis <= 5cm: 倒數指數加速警報演算法
            # 距離越短(1~5cm)，頻率衝高至 700Hz ~ 2300Hz
            calc_freq = (2000 / MAX(dis, 1)) + 300
            calc_freq = Clamp(calc_freq, min_val=700, max_val=2300)
            
            PlayTone(frequency=calc_freq, duration=0.1, volume=100, wait=TRUE)
            
    END WHILE
END FUNCTION

🔬 5. 實務應用與演算法邊界保護 (Applications & Edge Cases)

1. 音頻上下限截斷機制 (Pitch Clamping Protect)
LEGO EV3 喇叭支援頻率約為 $250\text{ Hz} \sim 10000\text{ Hz}$。當 $d \to 0$ 時，倒數公式分母接近 0 會導致頻率爆表產生失真雜音。必須在演算法中加入 Clamp(freq, 250, 2500) 將極限值鎖定於舒適安全的聽覺範圍。
2. 發聲持續時間 (Duration) 與動態響應速度優化
在原本積木中發聲時間設為 1 秒。當使用連續動態調頻時，發聲時間應縮短為 0.1 秒 ~ 0.2 秒，才能讓駕駛或使用者在移動過程中即時感受到頻率的滑順調變換（Pitch Modulation）。
