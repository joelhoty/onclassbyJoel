1. EV3 主機硬體架構與介面

LEGO Mindstorms EV3 主機（Intelligent Brick）是機器人的大腦，負責接收感測器訊號、運算邏輯並驅動輸出設備。

🧠 核心硬體規格

  • 處理器：ARM9 處理器 (300 MHz)，運行 Linux 作業系統。
  • 記憶體：64 MB RAM + 16 MB Flash 記憶體。
  • 顯示螢幕：178 x 128 像素單色 LCD 螢幕。
  • 發聲元件：內建 8 歐姆喇叭 (Speaker)，可發出不同頻率與單音。
  • 狀態指示燈：按鈕下方設有雙色/三色 LED 指示燈（綠/紅/橘），用以顯示運作、下載或錯誤狀態。

🔌 連接埠配置 (Ports Layout)

  • 輸出埠 (Output Ports A, B, C, D)：位於主機頂部，專門連接馬達 (大型馬達、中型馬達)。
  • 輸入埠 (Input Ports 1, 2, 3, 4)：位於主機底部，專門連接感測器 (觸控、超音波、顏色、陀螺儀等)。
  • PC USB 埠：Mini-USB 介面，用於連接電腦進行程式編譯與燒錄。
  • USB Host 埠：擴充 Wi-Fi 網卡、藍牙或主機串接 (Daisy-Chain)。
  • SD 卡擴充槽：支援最高 32GB Micro SD 卡（可用於擴充系統或載入外置作業系統如 ev3dev）。

🔘 主機控制按鈕介紹

按鈕名稱 圖示 / 位置 主要功能
中央按鈕 (Enter) 正中央暗紅色/灰色區域 開機、確認選擇、執行程式。
左上按鈕 (Back/Cancel) 左上方獨立按鈕 返回上一頁、取消操作、關機（長按）或終止正在執行的程式。

2. 第一個輸出積木 — 聲音積木 (Sound Block)

聲音積木（Sound Block）是 EV3 程式設計中最直觀且具備即時回饋的綠色輸出積木（Action Blocks）之一。透過聲音反饋，我們可以快速驗證程式執行進度與機器人狀態。

💡 為什麼聲音積木是最佳入門輸出設備？
  • 不需要複雜的機械結構即可直接觀察輸出結果。
  • 是進行機器人狀態偵錯（Debugging）最方便的工具（例如：執行到特定程式區塊時發出聲音提示）。
  • 能為機器人增加人性化的互動與情感表達。

3. 聲音積木 4 大控制模式

聲音積木點選左下角的模式切換按鈕後，提供以下 4 種運作模式：

模式種類 圖示與名稱 說明與用途 主要參數
Mode 1 Play File (播放檔案) 播放 EV3 內建的語音檔或自訂聲音檔（如動物聲、數字、招呼語等）。 檔名 (File Name)、音量 (Volume)、播放方式 (Play Type)
Mode 2 Play Tone (播放單音) 指定特定的聲音頻率 (Hz) 與發聲持續時間 (秒)，常用於製作簡易警報聲。 頻率 (Frequency: 250~10000 Hz)、持續時間 (Duration)、音量、播放方式
Mode 3 Play Note (播放樂音/音階) 使用標準音樂鋼琴音階 (如 C4, D4, E4) 與音樂拍子 (Beat) 來設定，適合演奏歌曲。 音符 (Note)、持續時間 (Duration/Beats)、音量、播放方式
Mode 4 Stop (停止聲音) 立即切斷與停止目前正在播放的任何聲音。 無參數

4. 核心參數：播放控制 (Play Type) 深度解析

在「Play File」、「Play Tone」與「Play Note」模式中，有一個極為關鍵的控制參數——Play Type（播放控制方式）。這決定了程式執行流程是「阻塞（Blocking）」還是「非阻塞（Non-blocking）」。

1. Wait for Completion (等待播放完成) 預設

行為：程式會暫停在此積木，直到聲音完全播放完畢後，才會繼續執行下一個積木。

適用場景：提示語、播放完整音樂片段、確定前置聲音結束才開始移動。

2. Play Once (播放一次即往下執行)

行為：聲音開始播放的瞬間，程式會立即向下執行下一個積木，聲音會在背景繼續發聲。

適用場景：機器人一邊向前移動、一邊發出警報聲或開機音效。

3. Repeat (重複循環播放)

行為：聲音會不斷循環播放，程式不會被阻塞，會持續向下執行其他積木，直到遇到 Stop 聲音積木或程式結束。

適用場景：連續警示燈/警報聲、背景音樂。

⚠️ 觀念觀測重點：併行處理 (Parallel Execution)

若希望機器人同時移動又同時發聲，必須將 Sound Block 設定為 Play Once，或者利用 EV3 的多執行緒（Parallel Beam / 多重分流管道）同時驅動馬達與聲音。若設為 Wait for Completion，馬達將會等待聲音播完後才開始轉動！

範例 5：使用 Block Builder (My Block 自訂積木建立器) 封裝樂曲積木

當我們在 EV3 中編寫《The Final Countdown》這類包含十幾個音符的長曲時，主程式面板會變得極為冗長雜亂。利用 EV3 的 My Block Builder (自訂積木建立器)，可以將這一長串聲音積木封裝成一個乾淨的青綠色自訂積木（例如：Play_FinalCountdown），甚至能加入動態控制參數！

🛠️ Block Builder 自訂積木建立步驟教學：

  1. 框選積木 (Select Blocks)：用滑鼠拉出選取框，選取剛剛排好的 18 個 Sound Note 積木。
  2. 啟動 Block Builder：點擊頂部選單 Tools (工具) ➔ 點選 My Block Builder (我的積木建立器)。
  3. 設定積木資訊 (Block Information)：
    • Block Name (積木名稱)：填入 Play_Countdown_Riff
    • Description (說明)：播放 Europe - The Final Countdown 前奏旋律
    • Icon (自訂圖示)：挑選樂符 🎵 或喇叭 🔊 圖示，方便視覺化辨識。
  4. 新增參數 (Add Parameters)：為自訂積木建立輸入介面 (Input Ports)：
    • 參數 1：Volume (音量) — 設定型態為數字 (Number)，預設值 100。內部將此參數接線至所有 Sound Block 的 Volume 連接埠。
    • 參數 2：Speed_Factor (演奏速度) — 設定型態為數字 (Number)，預設值 1.0。內部使用除法積木 (Divide Block) 控制 Duration 秒數。
  5. 完成與調用：點擊 Finish。自訂積木會自動加入青綠色標籤頁（My Blocks），之後在主程式中只需拉出一個 [Play_Countdown_Riff] 積木即可一鍵播放整首前奏！

6. 專題實作：距離反饋蜂鳴器 (Distance Audio Feedback System)

距離反饋蜂鳴器是結合輸入感測器（超音波感測器 Ultrasonic Sensor）與輸出設備（聲音積木 Sound Block）的經典動態互動專題。透過即時量測障礙物距離，並經由數據對映（Data Mapping）動態調整聲音頻率 (Frequency) 與蜂鳴間隔 (Beeping Interval)，完美模擬汽車倒車雷達 (Parking Sensors) 與視障無障礙導引系統。

📡 1. 系統硬體與感測原理

  • 輸入感測器：EV3 超音波感測器 (Ultrasonic Sensor)，連接至 Input Port 4。
  • 量測原理：發射 40kHz 高頻超音波並接收反射波，計算時間差得出距離數值 D（單位：cm，有效範圍 3 ~ 250 cm）。
  • 反饋邏輯：距離越近 → 聲音頻率越高、逼逼聲間隔越短、警示越急促。

🧮 2. 數據對映數學模型 (Data Mapping Math)

將感測距離 D (cm) 轉換為聲音發聲頻率 f (Hz) 的動態線性對映公式：

f(D) = f_max - [ (D - D_min) / (D_max - D_min) ] × (f_max - f_min)

設定感測區間 D ∈ [5, 100] cm，頻率範圍 f ∈ [250, 2000] Hz：

  • 極近距離 (D = 5 cm)： 輸出 2000 Hz（高音急促警報）
  • 遠距離 (D = 100 cm)： 輸出 250 Hz（低音緩慢聲音）
  • 超遠安全距離 (D > 100 cm)： 靜音 (Mute / Safe Range)

🧩 EV3 積木程式邏輯實現 (Block Implementation)

做法 A：動態頻率連續對映 (Continuous Frequency Control)

積木邏輯：使用 Loop (無限迴圈) 不斷讀取超音波數值，透過算術積木 (Math Block) 計算出對映頻率，直接餵入 Sound Block 的 Frequency 數據埠。

[Loop Block: Infinite]
  ├─➔ [Ultrasonic Block: Measure - Distance Centimeters (Port 4)] → 輸出 D
  ├─➔ [Math Block (Advanced): "2000 - (D - 5) * 18.4"] → 輸出頻率 f
  └─➔ [Sound Block: Play Tone (Freq = f, Duration = 0.1s, Play Type = Play Once)]

做法 B：多階條件判斷蜂鳴器 (Switch Staged Beeping)

積木邏輯：使用條件判斷積木 Switch Block 根據距離區間進行分級，實現傳統汽車倒車雷達的不同急促等級逼逼聲。

💡 關鍵設定技巧 (Avoid Latency Blocking)：

在實作急促嗶嗶聲時，Sound Block 的 Play Type 必須設定為 Play Once (1) 或設定極短發聲時間 (如 0.08 秒)，後面緊接相應的 Wait Block。若設為 Wait for Completion 且聲音時間過長，會導致迴圈響應遲鈍、反應嚴重延遲！

🚀 延伸設計：進階數學轉換公式與複合積木數據架構 (Extended Formula & Block Architecture)

在實際車用工程與機器人防撞設計中，單一線性對映往往無法完美突顯「距離越近、危險等級呈指數級暴增」的生理警示效果。以下延伸設計 4 種進階數學轉換模型與相應的 EV3 數據線 (Data Wires) 接線積木架構：

1. 雙重調變模型 (Dual Modulation Model)

原理：同時對聲音頻率 \(f\) 與發聲等待間隔 \(T_{\text{wait}}\) 進行雙重動態調變。距離越近，音調越尖銳，且逼逼聲停頓越短。

  • 頻率對映：f(D) = 2600 - 23.5 × (D - 5) (Hz)
  • 間隔對映：T_wait(D) = max(0.04, 0.006 × D) (秒)

2. 反比雙曲急迫曲線 (Inverse Hyperbolic Emergency Curve)

原理：線性公式在近距離變化不夠陡峭。改用反比雙曲公式，使距離在 \(< 20\text{ cm}\) 時頻率呈飆升狀態，極具衝擊感！

f(D) = 300 + [ 18000 / (D + 2) ] (Hz)

例：\(D=50\text{cm} \rightarrow f=646\text{Hz}\)；\(D=15\text{cm} \rightarrow f=1358\text{Hz}\)；\(D=5\text{cm} \rightarrow f=2871\text{Hz}\)（極陡急升警報）。

3. 指數縮放嗶聲間隔 (Exponential Interval Curve)

原理：發聲間隔採用二次方指數縮放，遠距離時音速減慢變化平緩，越接近障礙物則頻率間隔縮短越劇烈。

T_interval(D) = 0.03 + 0.8 × ( D / 100 )² (秒)

4. 數位低通平滑濾波 (Low-Pass Filter)

原理：解決超音波感測器反射角產生的雜訊突波 (Jitter Spike)，避免蜂鳴器發出突然刺耳的雜音。

D_filtered(k) = 0.3 × D_raw(k) + 0.7 × D_filtered(k-1)

🐍 進階擴充：ev3dev Python 雙重動態調變演算法範例

在 Linux ev3dev 系統環境下，使用 Python 實現雙重動態調變與雙曲緊急曲線：

#!/usr/bin/env python3
import time
from ev3dev2.sensor.lego import UltrasonicSensor
from ev3dev2.sound import Sound

# 初始化超音波感測器 (Port 4) 與聲音系統
us = UltrasonicSensor('in4')
sound = Sound()

print("Distance Audio Feedback (Extended Radar) Started...")

d_filtered = 100.0  # 初始化低通濾波變數

while True:
    d_raw = us.distance_centimeters
    
    # 1. 低通濾波 (Low-pass Filter) 平滑訊號
    if d_raw < 250.0:
        d_filtered = 0.3 * d_raw + 0.7 * d_filtered
    
    # 2. 數值截斷 Clamp [5.0, 100.0]
    dist = min(100.0, max(5.0, d_filtered))
    
    if dist < 10.0:
        # 3. 超近危險區 (< 10cm)：持續長鳴高頻警報
        sound.tone(2800, 120)
        time.sleep(0.04)
    elif dist < 100.0:
        # 4. 雙曲對映頻率 + 雙重調變發聲間隔
        freq = int(300 + (18000 / (dist + 2.0)))       # 雙曲急迫頻率曲線
        interval = max(0.04, 0.006 * dist)            # 動態縮短間隔
        
        sound.tone(freq, 60)
        time.sleep(interval)
    else:
        # 5. 安全距離靜音
        time.sleep(0.15)
⚠️ 實務工程開發注意事項 (Engineering & Debugging Tips)
  • 無反射訊號與無窮大處理 (Invalid Readings)：超音波量測無反射波時可能傳回 255 cm。程式中務必加入截斷門檻 (Clamping Filter)，避免異常數據導致數學算術溢位或異常音頻。
  • 感測器盲區 (Dead Zone)：超音波感測器低於 3 cm 時讀數容易飄移，建議在邏輯中將 < 10 cm 統一判定為最高警示層級。

7. 延伸想法與創新應用 (Extended Ideas)

🔍 1. 聲音做為「機器人狀態診斷器」(Audio Debugger)

在複雜程式中（如循線或避障），當感測器讀值異常或程式走到未預期的分支時，輸出特定音頻（如高音 BEEP 表示讀到黑色，低音 BEEP 表示讀到白色）。這比每次都停下來看 LCD 螢幕更有效率。

🔊 2. 距離反饋蜂鳴器 (Distance Audio Feedback)

結合超音波感測器 (Ultrasonic Sensor)，將測得的距離數值經由數學公式轉換為聲音頻率 (Frequency) 或發聲間隔（距離越近，音調越高、嗶嗶聲越急促），模擬汽車倒車雷達。（詳細完整實作請參閱第 6 章專題）

🎼 3. 自訂樂曲與聲音檔編輯 (Custom Sound WAV Converter)

利用 EV3 Software 內建的 Sound Editor 工具，將自製的 WAV 語音檔轉為 EV3 格式 (.rsf)，讓機器人說出客製化語音（例如：「請幫我開門」、「警告！前面有障礙物」）。

🤝 4. 視障導引與無障礙設計 (Accessibility Assistance)

設計一款針對視障人士的導盲機器人，透過聲音的長短、高低與語音播報，將周遭環境訊息視覺轉聽覺，發揮科技人文關懷。

8. 延伸專題：如何在 EV3 播放 MP3 音樂？（限制與解法）

❓ 為什麼 EV3 官方預設「無法直接播放 MP3 檔」？

LEGO EV3 官方韌體（Official Firmware）與原廠積木軟體不支援直接播放 MP3 格式，主要原因如下：

1. 硬體 CPU 與記憶體開銷 (Codec Limitation)

EV3 採用 ARM9 處理器 (300 MHz) 與 64MB RAM。硬體無獨立 MP3 編解碼晶片，純軟體解碼 MP3 會消耗大量 CPU 運算資源，影響馬達控制與感測器即時反應。

2. 內部 Flash 儲存空間極小 (16MB)

主機內建快閃記憶體僅 16MB，扣除 Linux 作業系統後僅剩數 MB。一首 3~5 分鐘的 MP3 檔即需 3~5MB，極易塞滿系統儲存空間。

3. 官方音訊格式標準：.RSF / Uncompressed WAV

EV3 官方僅原生支援 .rsf (Robot Sound File) 專用格式與低採樣率 WAV 檔（規格限制：8-bit、單聲道 Mono、取樣率 8 kHz）。

🛠️ 解決方案：如何在 EV3 上實現播放 MP3 / 音樂？

方案 A：官方軟體途徑 — 轉檔為低採樣率 WAV/RSF 檔 (適用官方積木)

實作步驟：
  1. 轉檔：使用 Audacity、Format Factory 等工具，將 MP3 轉為 WAV 格式 (單聲道 Mono；匯入 Sound Editor 後會轉為 8 kHz / 8-bit 的 .rsf)。
  2. 裁切：因容量限制，建議將音樂截取為 5~15 秒精簡片段。
  3. 匯入：打開 EV3 Software 標籤選單 ➔ 選擇 Sound Editor (聲音編輯器) ➔ 匯入 WAV 檔並轉換儲存為 .rsf 格式匯入專案。
  4. 播放：使用 Sound Block 的 Play File 模式調用該音檔。

⚠️ 限制：音質會因降為 8 kHz / 8-bit 而變低（類似電話語音音質），且無法播放數分鐘的完整長曲。

方案 B：進階玩家途徑 — 使用 Linux 第三方系統 ev3dev + Python (打破容量與格式限制)

實作步驟：
  1. 準備 SD 卡：將 Micro SD 卡格式化並寫入 ev3dev (基於 Debian Linux 的 EV3 專用作業系統)。
  2. 安裝音訊工具：開機登入 ev3dev 後，透過 Linux 終端機安裝 MP3 播放工具：
    sudo apt-get update && sudo apt-get install mpg123
  3. 存放 MP3 檔：將完整 MP3 音檔放在 Micro SD 卡中（SD 卡容量可達 32GB，徹底解決 16MB Flash 限制）。
  4. Python 程式播放：撰寫 Python 程式呼叫系統命令或音訊庫播放： 
    import subprocess

# 背景播放 MP3 音效/背景音樂
subprocess.Popen(["mpg123", "-q", "/home/robot/music/bgm.mp3"])

✅ 優點：可播放長度不限、完整高品質的 MP3 音樂，且不佔用主機內部 Flash 記憶體！

方案 C：藍牙通訊外接裝置 (Bluetooth Bridge)

EV3 主機僅作為控制器，當觸發條件成立時，透過藍牙發送訊號給電腦或手機，由電腦/手機上的 Python/App 播放高品質 MP3 音效。
