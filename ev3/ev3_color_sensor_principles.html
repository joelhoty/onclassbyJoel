1. 核心概念剖析 (Core Concepts)

EV3 顏色感應器（LEGO Part #45506）並非影像感光相機，而是由一顆單像素矽光電二極體 (Photodiode)、RGB 三色發光二極體 (LED) 及專屬微控制器 (MCU + 10-bit ADC) 組成。它藉由調控照明時序，成功在毫秒級瞬間完成光強與色彩判定。

1.1 感應器內部光學與硬體架構

光學結構最關鍵的設計在於「發光腔」與「受光腔」之間的物理遮光壁 (Optical Isolation Baffle)，防止發出的光線在塑膠殼內部直接折射至受光器（光學串擾 Crosstalk）。

  • 1. 如何判斷「光反應強弱」？（靠半導體「內光電效應」）：當反射光子進入矽光電二極體（Silicon Photodiode），只要光子能量大於矽能隙（1.12 eV，涵蓋 400~1050 nm 可見光），每 1 顆光子就會在 PN 接面空乏區激發出 1 對「自由電子-電洞對」。在內建電場分離下形成正比於光子數量的微安培級光電流 I_ph = R(λ) · P_optical，再經跨阻放大器 (TIA) 轉為電壓送給 ADC。
  • 2. 到底有沒有「濾鏡」？：沒有 RGB 彩色分色濾鏡！外層僅有聚集光線的透明環氧樹脂凸透鏡與抑制環境熱干擾的基礎近紅外線衰減配方，對紅、綠、藍可見光無差別全通接收。
  • 3. 既然接收端是「色盲」且無濾鏡，怎麼分辨顏色？：靠「時間同步取樣 (Time-Synchronized Sampling)」！雖然光電二極體只會回報「現在有多亮」，但主控 MCU 同時控制 LED 與 ADC——當 MCU 在第 1 微秒下令「只開紅燈」，此時二極體測到的亮度就 100% 代表紅光反射率；下一微秒「關紅燈、只開綠燈」，測到的亮度就代表綠光反射率。此外，針對矽晶片天生對紅光較敏感、對藍光較遲鈍的特性，韌體內建白平衡權重 (w_R, w_G, w_B) 自動校正。

1.2 動畫一：反射光強度 (Reflected Light Intensity) 原理動態模擬

在反射光強度模式下，感應器只開啟紅色 LED（紅光對黑色碳墨與白色紙張具有最佳吸收與反射對比度）。光子經表面漫反射後部分進入受光孔，光電二極體將光子激發的電子-電洞對轉換為光電流。

1.3 色彩辨識核心機制：時序三色光脈衝掃描 (Sequential RGB Strobe)

受光的光電二極體是「色盲」，它無法直接知道入射光是紅是綠。EV3 的專利智慧在於「時間分割多工照明 (Time-Division Multiplexed Lighting)」：

  1. t1 (紅光脈衝)：僅點亮紅燈，測量此時物體反射的紅光能量 $R$。
  2. t2 (綠光脈衝)：僅點亮綠燈，測量此時物體反射的綠光能量 $G$。
  3. t3 (藍光脈衝)：僅點亮藍燈，測量此時物體反射的藍光能量 $B$。
  4. t4 (環境基底)：熄滅全部 LED，測量純環境光底噪 $V_{amb}$，並自 $R, G, B$ 中即時扣除。
⏱️ 互動動畫：時序微秒級閃爍與示波器波形
當前時序階段：Phase 1: RED LED ON

* 註：真實 EV3 感應器內部時序掃描循環每秒可進行約 1,000 次 (1 kHz)，肉眼看似發出連續白光，但高速攝影機或光電晶體下可見明顯的 R-G-B 交替閃爍。

💡 關鍵釋疑：RGB 光源到底發射幾個設定好的固定顏色？
答案是：硬體光源只發射「3 種」設定好的固定單色光波長（紅光 ~660nm、綠光 ~520nm、藍光 ~465nm）！感應器內部封裝了 3 顆獨立的單色 LED 晶粒，不會直接發出黃光、棕光或紫光。

2. 實作與應用範例 (Practical Examples)

2.1 循線機器人比例控制器 (P-Line Follower)

利用反射光強度對黑白交界的連續漸變特性，以偏差量乘上比例增益 $K_p$ 即時修正轉向速度，消弭傳統二值化 (On-Off) 產生的劇烈左右擺動：

flowchart TD Start(["🚀 程式啟動"]) --> ReadSensor["📡 讀取感應器反射光強度 reflection()"] ReadSensor --> CalcErr["➗ 計算偏差量 error = 50 - current_light"] CalcErr --> CalcTurn["✖️ 計算轉向量 turn = Kp * error"] CalcTurn --> CalcSpeed["⚙️ 計算左右馬達: Left = Base + turn, Right = Base - turn"] CalcSpeed --> SafetyClamp{"⚠️ 是否超出安全功率範圍?"} SafetyClamp -- 是 --> Clamp["🔒 限制速度於 [-100, 100]"] SafetyClamp -- 否 --> RunMotors["🏎️ 驅動馬達前進"] Clamp --> RunMotors RunMotors --> WaitTick["⏱️ 循環等待 10ms"] WaitTick --> ReadSensor
ev3_p_line_follower.py (Pybricks / MicroPython) 
#!/usr/bin/env pybricks-micropython
# =======================================================
# LEGO EV3 比例循線控制器 (P-Controller)
# 原理：以黑線邊界反射強度 50% 為目標基準點進行閉迴路動態校正
# =======================================================

from pybricks.hubs import EV3Brick
from pybricks.ev3devices import Motor, ColorSensor
from pybricks.parameters import Port, Stop
from pybricks.tools import wait

# 1. 硬體初始化
ev3 = EV3Brick()
left_motor = Motor(Port.B)          # 左輪驅動馬達
right_motor = Motor(Port.C)         # 右輪驅動馬達
color_sensor = ColorSensor(Port.S3) # 顏色感應器安裝於 Port 3

# 2. 控制參數設定
TARGET_LIGHT = 50.0  # 目標反射率：黑線(10%)與白底(90%)的中間過渡值
KP = 1.3             # 比例控制增益係數 (依車重與輪徑調諧)
BASE_SPEED = 220     # 直線巡航基準轉速 (deg/s)

ev3.speaker.beep(frequency=1000, duration=150)
print("P-Line Follower Initialized. Tracking Edge...")

try:
    while True:
        # 讀取當前反射光百分比 (0-100)
        current_light = color_sensor.reflection()
        
        # 計算誤差 (Error)
        # 若 current > 50 (偏向白底) -> error < 0 -> turn < 0
        error = TARGET_LIGHT - current_light
        
        # 比例修正量
        turn = KP * error
        
        # 左右輪差速輸出
        speed_left = BASE_SPEED + turn
        speed_right = BASE_SPEED - turn
        
        left_motor.run(speed_left)
        right_motor.run(speed_right)
        
        wait(10) # 100Hz 穩定更新率

except KeyboardInterrupt:
    left_motor.stop(Stop.BRAKE)
    right_motor.stop(Stop.BRAKE)
    print("Program Terminated.")

2.2 自訂 RGB 原始數值色彩判別器 (Custom Euclidean Classifier)

為避免賽場不同墨水印刷材質造成的原廠代號誤判，透過讀取 raw RGB 數值與現場校準之基準中心點計算歐氏距離：

flowchart TD In["📡 讀取原始 rgb() 三維向量"] --> Dict["📚 讀取比賽場地校準色彩庫"] Dict --> Dist["📐 逐一計算歐氏距離 dist = sqrt(ΔR² + ΔG² + ΔB²)"] Dist --> FindMin["🔍 取得距離最小之顏色候選"] FindMin --> CheckThresh{"❓ min_distance < 30.0?"} CheckThresh -- 是 --> Match["🎯 輸出該顏色判定，執行對應指令"] CheckThresh -- 否 --> Unknown["⚪ 判定為未知色彩 (Unknown)"]
custom_rgb_classifier.py 
import math
from pybricks.ev3devices import ColorSensor
from pybricks.parameters import Port
from pybricks.tools import wait

color_sensor = ColorSensor(Port.S3)

# 現場實測校準之標準色中心點 (R, G, B)
CALIBRATED_COLORS = {
    "Black":  (4, 5, 4),
    "White":  (85, 89, 93),
    "Red":    (82, 14, 12),
    "Green":  (15, 68, 22),
    "Blue":   (11, 32, 85),
    "Yellow": (86, 75, 14)
}

DISTANCE_THRESHOLD = 28.0

def classify_color(rgb_sample):
    r, g, b = rgb_sample
    best_color = "Unknown"
    min_dist = float("inf")
    
    for name, (cr, cg, cb) in CALIBRATED_COLORS.items():
        # 計算三維歐氏距離
        dist = math.sqrt((r - cr)**2 + (g - cg)**2 + (b - cb)**2)
        if dist < min_dist:
            min_dist = dist
            best_color = name
            
    if min_dist > DISTANCE_THRESHOLD:
        return "Unknown", min_dist
    return best_color, min_dist

while True:
    rgb = color_sensor.rgb()
    name, dist = classify_color(rgb)
    print("RGB: {} -> Result: {} (Dist: {:.1f})".format(rgb, name, dist))
    wait(200)

3.2 鏡面反射 (Specular) vs. 漫反射 (Diffuse) 的光學陷阱

光學現象 表面特徵 對 EV3 顏色感應器的影響 工程對策與解法
朗伯漫反射 (Diffuse) 消光啞光紙張、粗糙地墊 光線呈半球均勻均向散射，各角度讀數穩定可靠。 常態工作環境，無需特殊修正。
鏡面反射 (Specular Flare) 光滑 PVC 亮面黑膠帶、壓克力板 入射角等於反射角。若感應器嚴格垂直，光束直接強烈彈回，黑色被誤測為亮白色！ 將感應器微幅傾斜 5°~8°，讓鏡面直射光偏離受光孔，僅接收內層漫射光。
環境光飽和 (Saturation) 舞台聚光燈、室外強烈陽光 環境光子數遠超 LED 發射強度，造成 ADC 電平直接拉滿 100% 飽和截波。 加裝深色樂高積木護罩（Shroud）阻隔斜射光。
