1. 核心概念剖析 (Core Concepts)

EV3 顏色感應器（LEGO Part #45506）並非影像感光相機，而是由一顆單像素矽光電二極體 (Photodiode)、RGB 三色發光二極體 (LED) 及專屬微控制器 (MCU + ADC) 組成。它藉由調控照明時序，成功在毫秒級瞬間完成光強與色彩判定。

1.1 感應器內部光學與硬體架構

光學結構最關鍵的設計在於「發光腔」與「受光腔」之間的物理遮光壁 (Optical Isolation Baffle)，防止發出的光線在塑膠殼內部直接折射至受光器（光學串擾 Crosstalk）。

  • 1. 如何判斷「光反應強弱」？（靠半導體「內光電效應」）：當反射光子進入矽光電二極體（Silicon Photodiode），只要光子能量大於矽能隙（1.12 eV，涵蓋 400~1050 nm 可見光），每顆被吸收的光子最多會在 PN 接面空乏區激發出 1 對「自由電子-電洞對」（量子效率 ≤ 1）。在內建電場分離下形成正比於光子數量的微安培級光電流 I_ph = R(λ) · P_optical，再經跨阻放大器 (TIA) 轉為電壓送給 ADC。
  • 2. 到底有沒有「濾鏡」？：沒有 RGB 彩色分色濾鏡！外層僅有聚集光線的透明環氧樹脂凸透鏡（是否另有近紅外線衰減處理，官方未公開），對紅、綠、藍可見光無差別全通接收。
  • 3. 既然接收端是「色盲」且無濾鏡，怎麼分辨顏色？：靠「時間同步取樣 (Time-Synchronized Sampling)」！雖然光電二極體只會回報「現在有多亮」，但主控 MCU 同時控制 LED 與 ADC——當 MCU 在第 1 微秒下令「只開紅燈」，此時二極體測到的亮度就 100% 代表紅光反射率；下一微秒「關紅燈、只開綠燈」，測到的亮度就代表綠光反射率。此外，針對矽晶片天生對紅光較敏感、對藍光較遲鈍的特性，韌體內建白平衡權重 (w_R, w_G, w_B) 自動校正。

1.2 動畫一：反射光強度 (Reflected Light Intensity) 原理動態模擬

在反射光強度模式下，感應器只開啟紅色 LED（紅光對黑色碳墨與白色紙張具有最佳吸收與反射對比度）。光子經表面漫反射後部分進入受光孔，光電二極體將光子激發的電子-電洞對轉換為光電流。

1.3 色彩辨識核心機制：時序三色光脈衝掃描 (Sequential RGB Strobe)

受光的光電二極體是「色盲」，它無法直接知道入射光是紅是綠。EV3 的專利智慧在於「時間分割多工照明 (Time-Division Multiplexed Lighting)」：

  1. t1 (紅光脈衝)：僅點亮紅燈，測量此時物體反射的紅光能量 $R$。
  2. t2 (綠光脈衝)：僅點亮綠燈，測量此時物體反射的綠光能量 $G$。
  3. t3 (藍光脈衝)：僅點亮藍燈，測量此時物體反射的藍光能量 $B$。
  4. t4 (環境基底)：熄滅全部 LED，測量純環境光底噪 $V_{amb}$，並自 $R, G, B$ 中即時扣除。
⏱️ 互動動畫：時序微秒級閃爍與示波器波形
當前時序階段：Phase 1: RED LED ON

* 註：真實 EV3 感應器內部時序掃描循環每秒可進行約 1,000 次 (1 kHz)，肉眼看似發出連續白光，但高速攝影機或光電晶體下可見明顯的 R-G-B 交替閃爍。

💡 關鍵釋疑：RGB 光源到底發射幾個設定好的固定顏色？
答案是：硬體光源只發射「3 種」設定好的固定單色光波長（紅光 ~660nm、綠光 ~520nm、藍光 ~465nm）！感應器內部封裝了 3 顆獨立的單色 LED 晶粒，不會直接發出黃光、棕光或紫光。

1.4 環境光消減（概念說明）

常見做法是在 LED 熄滅時取樣背景光，再從 R、G、B 讀值中扣除，概念上類似相關雙重取樣 (CDS)：R' = max(0, V_R − V_amb)，G、B 同理。EV3 感應器內部是否如此實作官方未公開，此處與 1.3 的「時段 4」皆為示意模型。

2.1 動畫四：循線機器人——黑色軌道左右前進動態判斷模擬 (Dynamic Line-Following Simulation)

💡 核心關鍵：為什麼單一顏色感應器必須追蹤「黑線邊緣 (Line Edge)」而非「黑線正中央」？
單顆顏色感應器只有一個光斑視野。如果直接追蹤「黑線正中央 (10%)」，當車子偏離黑線讀到白色 (85%) 時，因為黑線左右兩邊都是白底，機器人根本無法分辨自己是「偏左」還是「偏右」！
因此，標準循線必將目標設在「黑白交界邊緣 (反射率 ≈ 50%)」。以追蹤黑線左側邊緣（左白、右黑）為例：
• 讀數變亮 (> 50%) ＝ 感應器偏到左方白紙 ➔ 左輪加速、右輪減速（向右轉 ↗ 切回黑線）
• 讀數變暗 (< 50%) ＝ 感應器壓入右方黑線 ➔ 右輪加速、左輪減速（向左轉 ↖ 退回邊緣）

ev3_zigzag_line_follower.py (二值化左右搖擺循線) 
#!/usr/bin/env pybricks-micropython
# =======================================================
# LEGO EV3 二值化開關循線 (Two-State / Zig-Zag Line Follower)
# 原理：以 50% 為門檻進行「非左即右」切換，沿黑線左邊緣鋸齒狀前進
# =======================================================

from pybricks.hubs import EV3Brick
from pybricks.ev3devices import Motor, ColorSensor
from pybricks.parameters import Port
from pybricks.tools import wait

ev3 = EV3Brick()
left_motor = Motor(Port.B)          # 左輪驅動馬達
right_motor = Motor(Port.C)         # 右輪驅動馬達
color_sensor = ColorSensor(Port.S3) # 顏色感應器

THRESHOLD = 50       # 黑白交界門檻值 (%)
FAST_SPEED = 180     # 外側推進輪高速 (deg/s)
SLOW_SPEED = 30      # 內側支點輪低速 (deg/s)

while True:
    reflection = color_sensor.reflection()
    
    if reflection < THRESHOLD:
        # 偵測偏黑 (<50%)：車頭偏右壓入黑線 -> 左輪慢、右輪快 -> 向左轉出黑線
        left_motor.run(SLOW_SPEED)
        right_motor.run(FAST_SPEED)
    else:
        # 偵測偏白 (>=50%)：車頭偏左離開黑線 -> 左輪快、右輪慢 -> 向右轉回黑線
        left_motor.run(FAST_SPEED)
        right_motor.run(SLOW_SPEED)
        
    wait(10)

#!/usr/bin/env pybricks-micropython
# =======================================================
# LEGO EV3 比例循線控制器 (P-Controller)
# 原理：以黑線左邊緣 (左白右黑) 反射強度 50% 為目標基準點進行閉迴路動態校正
# =======================================================

from pybricks.hubs import EV3Brick
from pybricks.ev3devices import Motor, ColorSensor
from pybricks.parameters import Port, Stop
from pybricks.tools import wait

# 1. 硬體初始化
ev3 = EV3Brick()
left_motor = Motor(Port.B)          # 左輪驅動馬達
right_motor = Motor(Port.C)         # 右輪驅動馬達
color_sensor = ColorSensor(Port.S3) # 顏色感應器安裝於 Port 3

# 2. 控制參數設定
TARGET_LIGHT = 50.0  # 目標反射率：黑線(10%)與白底(90%)的中間過渡值
KP = 1.2             # 比例控制增益係數 (依車重與輪徑調諧)
BASE_SPEED = 200     # 直線巡航基準轉速 (deg/s)
MAX_SPEED = 400      # 馬達轉速安全上限 (deg/s)，對應流程圖的限幅步驟

ev3.speaker.beep(frequency=1000, duration=100)
print("P-Line Follower Initialized. Tracking Left Edge...")

try:
    while True:
        # 讀取當前反射光百分比 (0-100)
        current_light = color_sensor.reflection()
        
        # 計算誤差 (Error)
        # 偏白底(current > 50) -> error < 0；偏黑線(current < 50) -> error > 0
        error = TARGET_LIGHT - current_light
        
        # 比例修正量
        turn = KP * error
        
        # 左右輪差速輸出 (追蹤黑線左邊緣：左白右黑)
        # 1. 偏向左方白底 (error < 0, turn < 0) -> 左輪加速(-turn)、右輪減速(+turn) -> 向右切回黑線
        # 2. 偏入右方黑線 (error > 0, turn > 0) -> 左輪減速(-turn)、右輪加速(+turn) -> 向左退回邊緣
        speed_left = BASE_SPEED - turn
        speed_right = BASE_SPEED + turn
        
        # 限制轉速於安全範圍 (-MAX_SPEED ~ +MAX_SPEED)
        speed_left = max(-MAX_SPEED, min(MAX_SPEED, speed_left))
        speed_right = max(-MAX_SPEED, min(MAX_SPEED, speed_right))
        
        left_motor.run(speed_left)
        right_motor.run(speed_right)
        
        wait(10) # 100Hz 穩定更新率

except KeyboardInterrupt:
    left_motor.stop(Stop.BRAKE)
    right_motor.stop(Stop.BRAKE)
    print("Program Terminated.")

2.2 自訂 RGB 原始數值色彩判別器 (Custom Euclidean Classifier)

為避免賽場不同墨水印刷材質造成的原廠代號誤判，透過讀取 raw RGB 數值與現場校準之基準中心點計算歐氏距離：

flowchart TD In["📡 讀取原始 rgb() 三維向量"] --> Dict["📚 讀取比賽場地校準色彩庫"] Dict --> Dist["📐 逐一計算歐氏距離 dist = sqrt(ΔR² + ΔG² + ΔB²)"] Dist --> FindMin["🔍 取得距離最小之顏色候選"] FindMin --> CheckThresh{"❓ min_distance < 30.0?"} CheckThresh -- 是 --> Match["🎯 輸出該顏色判定，執行對應指令"] CheckThresh -- 否 --> Unknown["⚪ 判定為未知色彩 (Unknown)"]
custom_rgb_classifier.py 
#!/usr/bin/env pybricks-micropython
"""
自訂 RGB 歐氏距離色彩分類演算法
說明：讀取原始 (R, G, B) 反射數值，計算與校準樣本點的幾何距離，避免原廠 8 色誤判。
"""

import math
from pybricks.ev3devices import ColorSensor
from pybricks.parameters import Port
from pybricks.tools import wait

color_sensor = ColorSensor(Port.S3)

# 現場實測校準之標準色中心點 (R, G, B)
COLOR_CENTROIDS = {
    "Black":  (3, 4, 3),
    "White":  (88, 92, 95),
    "Red":    (78, 12, 11),
    "Green":  (14, 65, 18),
    "Blue":   (9, 28, 82),
    "Yellow": (85, 78, 15)
}

DISTANCE_THRESHOLD = 30.0  # 超過此距離則視為未知物體

def classify_color(rgb_sample):
    r, g, b = rgb_sample
    best_color = "Unknown"
    min_dist = float("inf")
    
    for name, (cr, cg, cb) in COLOR_CENTROIDS.items():
        # 計算三維歐氏距離
        dist = math.sqrt((r - cr)**2 + (g - cg)**2 + (b - cb)**2)
        if dist < min_dist:
            min_dist = dist
            best_color = name
            
    if min_dist > DISTANCE_THRESHOLD:
        return "Unknown", min_dist
    return best_color, min_dist

while True:
    rgb = color_sensor.rgb()
    name, dist = classify_color(rgb)
    print("RGB: {} -> Result: {} (Dist: {:.1f})".format(rgb, name, dist))
    wait(200)

3.1 鏡面反射 (Specular) vs. 漫反射 (Diffuse) 的光學陷阱

光學現象 表面特徵 對 EV3 顏色感應器的影響 工程對策與解法
朗伯漫反射 (Diffuse) 消光啞光紙張、粗糙地墊 光線呈半球均勻均向散射，各角度讀數穩定可靠。 常態工作環境，無需特殊修正。
鏡面反射 (Specular Flare) 光滑 PVC 亮面黑膠帶、壓克力板 入射角等於反射角。若感應器嚴格垂直，光束直接強烈彈回，黑色被誤測為亮白色！ 將感應器微幅傾斜約 5°~8°（經驗值，請實測調整），讓鏡面直射光偏離受光孔，僅接收內層漫射光。
環境光飽和 (Saturation) 舞台聚光燈、室外強烈陽光 環境光子數遠超 LED 發射強度，造成 ADC 電平直接拉滿 100% 飽和截波。 加裝深色樂高積木護罩（Shroud）阻隔斜射光。

3.2 為何採用「RGB 時序分光」而非「白光 LED + 濾色片」？

比較維度白光 LED + 拜爾濾色片EV3 RGB 時序脈衝掃描
受光單元需多像素感光陣列僅需 1 顆矽光電二極體
硬體成本較高（微透鏡 + 彩色濾光膜）較低（標準光電元件 + 3 色 LED）
反應頻率受限於影像讀出（約 30~60 FPS）可達約 1 kHz 的時序切換
光衰校準白光螢光粉老化導致色溫漂移可分別調整 R、G、B 驅動電流
