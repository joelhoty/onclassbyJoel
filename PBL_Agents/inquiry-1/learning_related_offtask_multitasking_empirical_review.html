🎯 摘要 (Summary)

「學生在 A 課堂看 B 科講義、課本、測驗卷或趕他科作業」在研究上最貼切的標籤是 learning-related yet off-task multitasking（學習相關但偏離當堂課的多工）。它不是單純「滑社群偷懶」，也不是「本課相關的筆記／查資料」；文獻幾乎一律以「是否服務當下這堂課」劃分，因此他科學術工作在分類上屬於 lecture-irrelevant／distractive。

關鍵實證結論：

  1. 很常見：中國大學樣本中，超過八成報告曾在課堂做學習相關的次要任務（含他科作業）；印尼大型問卷約三分之一曾瀏覽他科網站或通訊討論他科作業；美國筆電調查近半數曾在課堂做他課課業。
  2. 多半是策略性分流，不是單純自制失敗：當堂課感知價值／興趣低、他科 deadline／考試緊急時，學生會事先計畫帶哪份作業進教室，並合理化為「不浪費時間」。
  3. 對當堂課有代價：以「模擬他科長答作業」為無關次任務的實驗顯示，注意力與事實／概念保留皆明顯下降；筆電追蹤亦顯示非本課活動比率與成績負相關。
  4. 禁手機治不好這題：紙本講義、下載教材、他科 Word／PDF 都繞得過裝置禁令；較對症的是提高當堂課工具價值與課中 accountability，並在機構層協調評量時程。

1.2 為什麼會發生？實證指出的內外成因

flowchart LR subgraph Internal["內部條件"] V["當堂感知價值／興趣低"] U["他科緊急度／考試壓力高"] B["無聊、聽不懂、過易或過難"] S["情境式自我調節：高利害課才開 SRL"] end subgraph External["外部條件"] D["裝置／紙本教材可得性"] P["同儕規範與示範"] T["講述步調、座位、通知"] A["評量日曆擠在同一週"] end Internal --> Decision["有意識時間配置：改做他科"] External --> Decision Decision --> Beh["課堂看他科講義／寫測驗卷"]

最一致的機制（Deng, Zhou, & Broadbent, 2024；Qian, 2017）：學生會比較當堂課與替代任務的重要性、緊急性與報酬。任務價值越高，off-task 時間越少；低價值課上，改做他科常是刻意選擇，作者甚至提醒不宜一律視為「自我調節失敗」。

質性合理化常見句型：

  • 「不要浪費時間」
  • 「教室有學習氛圍，適合趕學習任務」
  • 「這堂不重要，整堂做自己的事」
  • 「留一隻耳朵聽課，講到重點再回來」
  • 理論上可對應中立化技術的 appealing to higher loyalties（他科更重要）與 condemning the condemners（怪老師無聊／不公）（Han et al., 2025）

1.3 對學習的影響：分類與效應

文獻幾乎不把「學術但非本課」算成有益的 productive multitasking。

次任務對本講注意力／保留證據類型
本課筆記／相關提問中性至正向實驗（如 Mahama 的 lecture-relevant）
他科作業／模擬他科長答負向實驗（Mahama Exp.1 明確模擬 other-course assignment）
社群／簡訊／娛樂負向實驗＋追蹤＋相關
刻意心智漫遊負向（短期 quiz 尤明顯）現場 thought-probe

Mahama（2025）實驗摘要（影音講課、大學部 N=100）：lecture-irrelevant（填寫與講課無關、需長答的校園經驗問卷＝模擬他科作業）組注意力、事實保留、概念保留皆最低；lecture-relevant（筆記）組最高。

🛠️ 2. 實作與應用範例 (Practical Examples)

2.1 盛行率速覽（不可直接互比，題幹不同）

研究樣本與「他科」直接相關的發現
Deng et al., 2024中國三校問卷 n=385；訪談 15>80% 曾從事 learning-related 次任務（含完成他科作業）；45 分鐘課平均約 12.8 分鐘從事與當堂無關活動
Zhou & Deng, 2024問卷 n=543 等「最常做」的 course-unrelated yet learning-related 約 16%；多數曾用手機做他科作業／搜他科資料
Simanjuntak et al., 2022印尼大學生 n=1485瀏覽他科網站 34.61%；通訊討論他科作業 32.18%
Borbone, 2009UNC 筆電使用者子集 n=8149.4% 在課堂做 coursework for other classes
JAOA／骨科醫學生調查, 2014醫學教育脈絡50 分鐘講課中 74% 會讀他科，平均約 23 分鐘；主因含考試時程、講者、興趣

2.2 現場區辨：娛樂分心 vs 他科學術分流

教師若一律用「沉迷手機」解讀，容易誤判課業過載或教學設計問題。

線索較像娛樂／社群較像他科學術分流
時機整學期零星、無聊段落考試週、作業截止前、低利害選修
計畫性通知觸發、習慣性解鎖課前已夾他科講義／預開文件
學生說法FOMO、解悶「這堂用處不大／不浪費時間」
介入含意裝置規範＋習慣／同儕常模課程價值、節奏、評量對齊、跨課負荷

flowchart TD A["輸入：計畫性 / 考試週 / 內容類型"] --> B["規則：entertainment vs academic_triage"] B --> C["輸出：標籤 + 建議槓桿"]

# classroom_offtask_triage_labeler.py
# 獨立小工具：依線索粗分「娛樂分心」與「他科學術分流」
# 不依賴、不修改 classroom_cross_subject_analyzer.py

from dataclasses import dataclass


@dataclass
class Clue:
    planned: bool          # 課前就帶好他科講義／檔案？
    exam_week: bool        # 是否考試週或大截止日前？
    content: str           # "other_course" | "social" | "game" | "mixed"
    low_course_value: bool # 學生自述／觀察：當堂低興趣低利害？


def label(clue: Clue) -> dict:
    """回傳粗分類與建議；僅供討論，非心理診斷。"""
    if clue.content in {"social", "game"} and not clue.planned:
        kind = "entertainment_distraction"
        levers = ["裝置結構化使用", "短講+活動循環", "同儕常模與延遲通知"]
    elif clue.content == "other_course" and (clue.planned or clue.exam_week or clue.low_course_value):
        kind = "academic_triage_other_course"
        levers = ["提高當堂工具價值與產出責任", "內插／抽問提高切走成本", "跨課評量時程協調"]
    else:
        kind = "mixed_or_unclear"
        levers = ["先低干擾近距離提示", "課後短談釐清動機", "避免一開始就道德化"]
    return {"label": kind, "suggested_levers": levers}


if __name__ == "__main__":
    demo = Clue(
        planned=True,
        exam_week=True,
        content="other_course",
        low_course_value=True,
    )
    print(label(demo))

2.5 介入方法比較（應用與限制）

方法應用限制對「他科課業」適配
提升感知課程／活動價值直接對準 Deng／任務價值機制單堂教師能動性受主修、評量權重限制高
主動學習＋短講循環降被動空檔、提高切走成本備課成本；低品質活動仍可能被分流中高
內插／concurrent testing降 TUT／神遊、錨定注意力複製效果量常偏小；多在影片／實驗情境中高
學生 SRL／環境結構化高利害課有效（藏手機、選座、延遲通知）低價值課學生會「關閉」SRL，甚至用 SRL 更有效趕他科中
裝置全面禁止降低可見娛樂手機使用難禁紙本／下載他科；高教可能傷出勤與無障礙低–中
引導式裝置使用增加本課筆記／學術用途難偵測「他科 Word／PDF」中
嚴懲／當眾羞辱短期嚇阻傷關係；對「自覺理性趕工」說服力弱低

🚀 3. 延伸思考與進階主題 (Extensions & Advanced Topics)

  1. 雙結果缺口：現有實驗多量測「本講損失」，幾乎不同時量測「他科作業完成品質／GPA 淨效益」。學生 triage 的「好處」目前停在質性自我報告。
  2. 與手機方案的關係：pbl2 手機管理對娛樂分心較對症；本現象常混紙本與檔案，需要評量節奏與教學設計，而非只靠收手機。
  3. 與既有理論指南的互補：classroom_cross_subject_study_research_and_solutions 強在期望—價值、動機干擾、自我價值等理論敘事與班級經營 SOP；本檔強在 Deng／Simanjuntak／Mahama／追蹤研究的操作性定義與數據。
  4. K–12 vs 高教：多數精準「他科 multitasking」證據來自大學；國高中現場常被升學時程放大，但同題幹的大型量化仍不足。
  5. 倫理：把「看起來沒在聽」一律罰，可能誤傷學生主導活動中的有效投入（課堂 EEG 研究顯示行為觀察與神經注意力指標可能不一致）。
