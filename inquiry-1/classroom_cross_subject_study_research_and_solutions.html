🎯 摘要 (Summary)

在國中、高中職乃至大學的教育現場中，「學生坐在 A 科目的課堂裡，桌下或桌上卻攤開 B 科目的課本、講義或測驗卷埋頭苦讀／趕作業」是極為普遍卻又令授課教師心情複雜的現象。與「上課滑手機、睡覺、聊天」等典型消極分心不同，這類學生表面上仍在從事「高認知投入的學習活動」，因此常自我合理化為「善用時間」或「認真向學」，卻在無形中造成雙重任務認知損耗、課堂互動瓦解與師生信任摩擦。

本文件根據關鍵字檢索國內外教育心理學、認知神經科學與教育社會學文獻，從五大核心研究理論深度剖析此行為的成因機制，並整理出 六大系統化解決方案、Mermaid 決策流程圖、互動式雙任務認知損益模擬器與 Python 診斷工具，以及六大方案應用與限制比較表。

1.2 國內外五大相關學術研究領域深度解析

  1. 期望—價值理論與「機會成本」模型（Expectancy-Value Theory, Eccles & Wigfield, 2000, 2020; Flake et al., 2015）：學生在課堂上持續評估「內在價值、成就價值、工具／效用價值」與「感知機會成本（Opportunity Cost）」。當下一節要考 B 科（短期效用價值極高、不準備的懲罰成本極大），而當前 A 課堂缺乏立即評量或連結時，學生判定「專心聽 A 課的機會成本過高」，便啟動跨科行為轉移。
  2. 動機干擾理論與蔡格尼克效應（Motivational Interference Theory, Fries, Dietz & Schmid, 2008；林玉雯等，2011）：真實校園中學生同時背負多科目標。當有「未寫完的測驗卷」或「下一節要考的單字」時，會引發蔡格尼克效應（Zeigarnik Effect，未完成任務佔據工作記憶張力），形成侵入性思緒與情緒焦慮（動機干擾），迫使學生在當前課堂拿出別科考卷以緩解焦慮。
  3. 認知負荷理論、心流理論與「補習班超前學習效應」（Sweller, 1988; Csikszentmihalyi, 1990; Bray, 2009）：台灣與東亞普及的「影子教育（補習班超前學習）」使部分學生在學校正課感到認知負荷過低（Boredom Channel 無聊通道），覺得重聽基礎觀念是浪費時間；加上單向講述留給視覺與雙手過多空檔，誘發學生拿補習班講義或他科題本自習。
  4. 自我價值保護理論與「補償性掌控感」（Self-Worth Theory, Covington, 1992）：當學生對當前科目 A 嚴重聽不懂（自我效能感極低），盯著黑板會產生羞愧與習得無助感。此時轉而寫自己「算得出來、或只需機械抄寫」的 B 科作業，既能進行自我設障（Self-Handicapping：沒聽懂是因為我在忙別科，不是因為我笨），又能從勾選題目中獲得立即的補償性掌控感（Compensatory Control）。
  5. 升學主義、學科階層化與「隱性課程」（Hidden Curriculum, Jackson, 1968; Apple, 2004）：升學考試將學科無形劃分為「高加權主科」與「非考科／副科」。若體制曾默許「借課考試」或「非考科自習」，隱性課程便教會學生「分數至上」的功利主義，發展出「表面安靜順從、私下時間挪移（Time-Shifting）」的次文化生存策略。

1.3 為什麼「邊聽 A 課、邊讀 B 科」是雙輸？學業多工認知損益數學模型

1. 課堂任務選擇決策不等式（Expectancy-Value Switching Threshold）：

$$\Delta U(t) = \underbrace{\left[ E_B \cdot V_B \cdot e^{\lambda / \tau_{\text{deadline}, B}} \right]}_{\text{科目 } B \text{ 的急迫加權價值}} - \underbrace{\left[ E_A(t) \cdot V_A(t) + P_{\text{detect}} \cdot C_{\text{penalty}} \right]}_{\text{專注科目 } A \text{ 的價值與違規風險}}$$

2. 語音迴路衝突與雙任務學習總產出損耗公式（Baddeley, 2000; Pashler, 1994）：

$$G_{\text{multitask}} = T_{\text{class}} \cdot \left[ \theta \cdot \eta_A (1 - \delta_{\text{switch}}) + (1 - \theta) \cdot \eta_B (1 - \delta_{\text{env}}) \right]$$
⚠️ 實證結論（學業欠債惡性循環 Academic Debt Spiral）：
聽老師講課（語音輸入）與看別科課本／寫考卷（視覺文字轉語音內在默讀 Subvocalization）共用大腦同一個「語音迴路（Phonological Loop）」。在 A 課堂偷寫 B 科考卷，1 小時只能發揮約 0.4 小時的 B 科效率，卻同時毀掉 0.8 小時的 A 科理解；等到 A 科快考試時，又必須在 C 課堂偷補 A 科，陷入「全科都在欠債補破網」的惡性循環！

"""
課堂跨科多工認知損益模擬與動機診斷工具 (Classroom Cross-Subject Multitasking Analyzer)
=====================================================================================
1. 根據工作記憶語音迴路衝突 (Baddeley, 2000) 與任務切換成本 (Pashler, 1994; Leroy, 2009)，
   定量模擬「在 A 課堂看 B 科教材/寫 B 科測驗卷」對比「專注單工學習」的認知吸收率與時間負債。
2. 根據期望價值理論 (Eccles & Wigfield, 2020) 與動機干擾理論 (Fries et al., 2008)，
   針對不同類型的「上課看別科」學生進行精準亞型診斷，並提供教師非對抗式溝通話術與處遇建議。
"""

import argparse
import json
from dataclasses import dataclass, asdict
from typing import List, Dict


@dataclass
class StudyStrategyScenario:
    """定義學生的課堂時間分配與學習策略情境資料結構"""
    name: str                    # 策略情境名稱
    class_minutes: float         # 單節課堂時間 (分鐘)，預設 50 分鐘
    after_school_minutes: float  # 課後預計用於複習/寫作業的基準時間 (分鐘)，預設 50 分鐘
    theta_a: float               # 課堂上分配給當前科目 A 的注意力比例 (0.0 ~ 1.0)
    switch_penalty_a: float      # 因頻繁低頭看 B 科導致 A 科邏輯斷裂的切換懲罰率 (0.0 ~ 0.8)
    env_penalty_b: float         # 在 A 課堂吵雜與防備老師下寫 B 科的環境與語音干擾率 (0.0 ~ 0.7)
    relearn_multiplier: float    # A 科課堂沒聽懂，回家自己看書需要花費的時間倍數 (通常 1.8 ~ 2.5 倍)


@dataclass
class SimulationResult:
    """儲存模擬計算結果之資料結構"""
    scenario_name: str
    effective_a_in_class: float       # A 科在課堂上的實質有效吸收量 (等效專注分鐘數)
    effective_b_in_class: float       # B 科在課堂上偷寫的實質有效完成量 (等效專注分鐘數)
    relearn_debt_a_minutes: float     # A 科因為上課漏聽，課後必須額外花費的重學補洞時間 (分鐘)
    remaining_b_after_class: float    # B 科課後還需要花多少時間才能完成 50 分鐘標準進度 (分鐘)
    total_time_spent: float           # 為達成 A、B 兩科相同標準進度，總共耗費的真實時間 (分鐘)
    net_time_wasted: float            # 相較於「專注單工」，多浪費的淨時間成本 (分鐘)
    combined_retention_score: float   # 固定時間預算下的 A+B 綜合測驗預期得分率 (0 ~ 100%)
